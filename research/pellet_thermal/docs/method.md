# 接口、实现边界和复现

## 本次实现

研究只使用固定几何、稳态、DC3D8 三维纯热单元和常数导热系数。没有机械自由度、
时间历史或 GPU 运算。生产入口仍为 `fuelsim -i case.fsi`。
区域的 `pellet_response = full|exact|surrogate` 分别选择完整有限元、精确凝聚和网络响应；
`surrogate` 必须提供 `pellet_model`，其他两种不接受该字段。

完整有限元调用既有 DC3D8 导热装配。精确凝聚和网络都返回区域表面节点的热残量以及
对全部表面温度的切线矩阵，单位分别为 W 和 W/K。体热源输入单位为 W/m³。
网络不预测温度场，不含间隙传热。三种选择经过同一纯热区域装配接口进入全局求解，
没有新增问题类或对象工厂。

表面由区域内只出现一次的四节点面识别，包括侧面和两个端面。节点按 Exodus 源节点
内部编号升序排列。`surface_nodes.txt` 明确记录零起始编号和坐标。完整模型在每个芯块
实体节点上建立温度方程；另两种只编号表面节点。保留输入 Exodus 的原始几何供表面
识别、间隙积分、模型一致性检查和输出映射使用，求解状态中没有芯块内部温度。
消去的节点在结果文件中的温度为 NaN，不重建内部温度场；消去的实体没有积分点热流。

## 精确凝聚

采用现有 DC3D8 热单元计算完整导热矩阵，并直接积分单位体热源节点载荷。
内部导热矩阵使用普通双精度 Cholesky 分解，一次计算所有右端项；不显式求逆。

```text
K_eff = K_GG - K_GI solve(K_II, K_IG)
f_eff = f_G  - K_GI solve(K_II, f_I)
R_G   = K_eff T_G - q_vol f_eff
```

这里 `f_I`、`f_G` 是单位体热源的节点载荷。精确凝聚的初始化目前采用稠密矩阵，适合
这次小型研究，不据此宣称大网格初始化成本或整体求解速度更低。

凝聚后的一个区域成为一个包含全部表面温度的装配贡献，第一次建立稀疏矩阵时保留全部
表面节点之间的耦合。间隙仍使用既有面到面热接触积分和两侧守恒装配，包壳仍使用 DC3D8。
芯块表面、间隙两侧和包壳同时进入 PETSc 的非线性求解器 SNES，切线包含网络温度块和
间隙两侧的四个温度耦合块。没有顺序单向迭代。

## 数据与训练

`fuelsim_pellet_sample` 是研究数据采集工具，从完整生产输入卡读取网格、材料及求解器，
复用 `SteadyProblem` 和 `solve_steady` 对每个样本求解完整有限元内部平衡。它只在内存中
为训练采样施加表面温度和均匀体热源，不生成或改写 `.fsi` 文件，不运行精确凝聚求解器。
训练采样是离线数据生成；所有端到端回归仍运行受版本控制的完整 `.fsi` 输入卡和生产程序。

第一版训练工具针对所提交的单芯块网格，要求每个表面节点有命名为 `surface_<id>` 的节点集。
采样依次循环均匀温度、轴向梯度、周向一阶变化以及轴向周向组合。组合场还叠加坐标上连续的
高斯函数，形成空间相关的平滑扰动，不使用逐节点独立白噪声。每个样本读取施加 Dirichlet
条件之前的完整有限元热残量，检查 `sum(R_surface) + q_vol * volume` 的绝对值不超过
`1e-9 W`。数据文件记录节点表、体积和网格材料签名。

网络结构为 `27 -> 64 -> 26`：26 个表面温度和一个体热源输入，64 个 tanh 隐藏神经元，
26 个线性输出。训练前先划分 819 个训练样本和 205 个独立保留样本，标准化均值及标准差
仅由训练样本计算。第一阶段研究的是线性热传导，所以将 tanh 初始化在近线性区间，先用
PyTorch 最小二乘拟合输出层，再用 LBFGS 更新网络参数。损失以标准化热残量均方误差为主，
加权 0.1 的相对能量守恒项。不使用精确凝聚矩阵或其切线作为训练标签。

PyTorch 使用 CPU 双精度，`torch.autograd.functional.jacobian` 计算完整温度切线。
该函数的定义见 [PyTorch 官方文档](https://docs.pytorch.org/docs/2.12/generated/torch.autograd.functional.jacobian.html)。
C++ 按每层矩阵乘法和 `1 - tanh(x)^2` 传播解析导数，包含输入及输出标准化的导数。
生产求解不使用有限差分，不链接 PyTorch 或 LibTorch；测试中的有限差分只用于独立验证。

模型为版本化文本文件，依次记录节点数、层数、体积、签名、节点表、输入均值与标准差、
输出均值与标准差、各层尺寸、激活函数、按行存储的权重和偏置。加载时检查维数、有限性、
正标准差、激活函数、末层尺寸及文件结尾。装配时另检查完整芯块连接关系、坐标、源节点编号
和导热系数的 64 位 FNV-1a 签名，以及逐个表面节点编号和坐标。

## 明确限制

当前模型只鉴定所提交的固定八棱柱芯块网格和常数导热系数 3 W/(m K)。改变芯块网格或芯块导热系数
必须重新采样和训练；不支持温度相关导热、瞬态、力学或降维。训练温度及体热源范围记录在
`models/pellet_mlp.training.json`。网络的能量守恒是误差控制，不是解析恒等式，不能用于声明
任意输入或训练范围以外均精确守恒。当前不提供超出训练分布的准确性保证。

表面温度全部保留，C++ 网络没有学习间隙，凝聚区域仍保持输入网格几何但不保留其内部自由度。
本次精确凝聚测试覆盖多组边界温度与热源激励，但所提交的小型生产网格只有一个内部节点，不能
据此宣称大量内部节点时的性能收益或其他几何的网络准确性。
