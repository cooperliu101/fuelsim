# 三维热力耦合重构参考

## 1. 文档状态与目的

本文档记录 2026 年 8 月 12 日基于提交 `ad1f2d2` 完成的只读架构审查和讨论
结论。它用于指导后续三维热力耦合重构，不表示三维功能已经实现、测试或通过
MOOSE 对标。

仓库当前生产能力仍是二维轴对称 RZ（径向—轴向）四节点四边形（Quad4）
热传导与准静态力学。当前行为、数值契约和验收要求仍以 `AGENTS.md`、`docs/theory.md`、
`docs/verification.md` 和验证矩阵为准。本文提出的输入版本、公共接口和三维
验收门槛只有在对应实现和验证落地后，才能成为生产契约。

本次讨论的目标是：在保持 C++17、ADlite、PETSc 和 Exodus 依赖边界不变的
前提下，增加三维笛卡尔坐标（Cartesian 3D）HEX8（八节点六面体）热力耦合，
同时尽量复用现有材料算法、状态事务和求解器流程。

## 2. 总体结论

不把项目重构成“任意维数、任意单元、任意标量类型”的模板框架。建议采用
公共流程加两个具体离散后端：

```text
SteadyProblem / TransientProblem
             |
     公共载荷与时间状态流程
             |
     运行时局部贡献端口
             |
       +-----+------+
       |            |
  RZ Quad4 后端   3D HEX8 后端
  现有具体实现    新增具体实现
       |            |
       +-----+------+
             |
      PETSc 残量与稀疏装配
```

生产问题类型继续只保留 `SteadyProblem` 和 `TransientProblem`。构造问题时根据
输入声明和 Exodus 拓扑显式选择一个具体后端，不增加 `SteadyProblem3D`、
材料对象工厂、运行时单元注册系统或项目自定义模板。

现有 RZ 路径应保持为已经验证的具体后端。三维路径增加新的具体网格、运动学、
体单元核和表面核。两者通过局部贡献和状态事务端口接入同一个 PETSc 求解流程。

现有三个生产库的依赖方向继续保持：三维网格、材料和局部内核进入
`fuelsim_core`，三维 Exodus 拓扑与结果编码进入 `fuelsim_io`，PETSc 类型仍只
出现在 `fuelsim_solver` 实现层。不为三维另建一套求解器库，也不增加新的外部
数值依赖。

## 3. 模块复用分类

### 3.1 可以直接复用

以下职责不解释空间坐标、单元拓扑或张量分量，可以直接保留主体：

| 职责 | 当前主要位置 | 结论 |
| --- | --- | --- |
| 材料参数名称、单位、数值、绑定和签名 | `include/fuelsim/material_functions.hpp`、`src/material.cpp` | 参数元数据和注册表管理可以直接复用。 |
| Norton 蠕变的对数域标量求根 | `src/material.cpp` | 等效应力、剪切模量和时间步上的标量算法与几何无关。 |
| 塑性—蠕变全隐式耦合的标量方程及偏导 | `src/material.cpp` | 标量更新可以成为轴对称与三维本构的公共算法。 |
| 稠密或影子全局状态读取 | `GlobalStateView` | 状态读取方式与单元拓扑无关。 |
| PETSc 会话、向量、矩阵、非线性方程求解器 SNES、线性方程求解器 KSP 和计时 | `src/solver.cpp` | 求解器对象生命周期和失败传播可以保留。 |
| 消息传递接口并行贡献分工和影子自由度收集 | `src/solver.cpp` | 按贡献唯一装配的流程可以保留。 |
| Dirichlet（指定自由度值）约束 | `src/solver.cpp` | 继续使用 `F_i=x_i-g_i` 并只清 Jacobian（残量对自由度的导数矩阵）行。 |
| 稳态加载、缩小载荷增量重试和失败恢复 | `src/solver.cpp` | 流程不依赖几何。 |
| 时间函数、后向欧拉（Backward Euler）时间推进和步长控制 | `src/problem.cpp`、`src/solver.cpp` | 时间控制流程可以复用。 |
| 已提交状态、试探状态、提交和回滚的事务顺序 | `TransientProblem` | 生命周期可以复用，具体历史布局必须由后端提供。 |
| 元素块、节点集和边集的名称及标识 | `include/fuelsim/mesh.hpp` | Exodus 元数据概念与维数无关。 |
| 场量误差计算口径 | `tests/support/moose_field_comparison.*` | 相对二范数、相对绝对峰值和最大逐点相对误差可以复用。 |

### 3.2 需要抽象后复用

以下模块具有可复用的职责，但当前公共类型中仍包含 RZ 假定：

| 模块 | 当前几何耦合 | 建议边界 |
| --- | --- | --- |
| `NonlinearProblem` | 局部贡献固定为 12 个自由度和 `12 x 12` Jacobian | 改为运行时有效长度的贡献端口，具体内核仍使用定长数组。 |
| `DofMap` | 固定三个场 `[T(:), ur(:), uz(:)]` | 提供连续字段区间和热学或力学类别元数据。 |
| 材料属性求值 | 位置输入固定为半径和轴向坐标 | 改为明确的三维参考位置上下文；轴对称后端负责坐标映射。 |
| 材料状态事务 | 固定四个轴对称张量分量和四个积分点 | 事务流程保留，张量布局和积分点数量由具体后端定义。 |
| 源网格和区域提取 | `UnstructuredQuad4Mesh` 固定二维坐标和四节点连接 | 抽出空间维数、拓扑、三坐标、连接关系和集合元数据。 |
| Exodus 读写 | 只接受二维 `QUAD4`，结果固定三个节点场和四分量应力 | 底层文件操作复用，二维和三维分别提供拓扑及结果编码。 |
| 诊断与残量缩放 | 固定三个字段 | 按字段元数据计算各场范数，温度和全部位移分别形成热学与力学尺度。 |
| 完整步与两个半步误差比较 | 固定三个节点场、四分量历史和标量摩擦历史 | 时间控制只编排状态快照；后端比较自己的完整状态。 |

### 3.3 必须新增三维具体实现

以下内容是三维离散本身，不能由现有两节点线单元（Line2）或 Quad4 RZ 代码
增加一个维数参数获得：

- 三维点、八节点体连接、四节点表面连接和三维区域网格；
- HEX8 形函数、三个自然坐标方向的导数、`3 x 3` 几何 Jacobian、八点全积分
  和正体积检查；
- 三维小应变运动学、六分量应力以及三个力学平衡方程；
- 三维稳态热传导、Backward Euler 一致热容和体积热源；
- 三维四节点表面的对流、参考构形压力和全局分量牵引；
- 三维节点场、六分量应力、八个积分点历史的 Exodus 输出和检查点布局；
- 若后续加入有限应变，则新增完整 `3 x 3` 变形梯度、增量运动学、三维转动、
  当前构形梯度、当前体积测度和随动压力（follower pressure）；
- 若后续加入接触，则单独设计三维热接触、机械接触、面边与顶点唯一归属、
  两个切向滑移历史和有限候选包络。

## 4. 两个必须优先解除的硬编码

### 4.1 局部贡献宽度

当前 `include/fuelsim/local_system.hpp` 将所有贡献固定为 12 个自由度。这一假定
已经进入 `NonlinearProblem`、PETSc 残量回调、Jacobian 回调、方向导数检查和
接触贡献装配。

二维 Quad4 RZ 体单元的局部顺序继续保持：

```text
[T0..T3, ur0..ur3, uz0..uz3]
```

三维 HEX8 体单元的局部顺序固定为：

```text
[T0..T7, ux0..ux7, uy0..uy7, uz0..uz7]
```

因此，二维贡献有 12 个局部自由度，三维体贡献有 32 个局部自由度。推荐的
求解器端口满足以下要求：

1. 每个贡献报告自己的有效局部自由度数量。
2. 调用方预分配自由度索引、残量和行优先 Jacobian 缓冲区，避免每次 PETSc
   回调反复分配 `std::vector`。
3. 现有 RZ 内核内部继续使用 12 项定长数组，三维内核内部使用 32 项定长数组。
4. ADlite 自动微分只播种当前贡献的 12 或 32 个局部自由度，禁止按全局自由度
   或最大缓冲容量播种。
5. 不把所有现有局部数组直接扩大为 32 项，以免改变二维自动微分宽度和已验证
   的数值路径。

### 4.2 全局字段布局

当前全局状态采用 field-major 排列，也就是逐场连续存储：

```text
二维：[T(:), ur(:), uz(:)]
三维：[T(:), ux(:), uy(:), uz(:)]
```

`NonlinearProblem` 应向求解器提供每个字段的名称、起止自由度和物理类别。
温度字段属于热学残量组，所有位移字段属于力学残量组。PETSc 求解器据此完成：

- 字段残量范数；
- 固定或自动残量缩放；
- 温度与力学场分裂预条件；
- 最终残量复核；
- Jacobian 方向导数诊断。

求解器不再通过“总自由度除以三”推断节点数和字段编号。

## 5. 具体后端边界

### 5.1 保留轴对称后端

当前 `SpatialAssembly` 的名称看似通用，但它实际保存 `RegionMesh`、
`Quad4RzGeometry`、Line2 压力/牵引/对流核、节点到线段机械接触和线到线热
接触。因此它应被视为 RZ 具体后端，而不是继续加入大量 `dimension == 3`
分支。

现有内部职责可以在重构时明确为：

```text
RzSpatialLayout
RzBoundaryAssembly
RzContactAssembly
RzDiscretization
```

具体名称可在实施设计中调整，但边界应保持清楚：RZ 开放边链、当前构形线段
投影、半开区间所有权和轴对称面积均留在轴对称后端。

### 5.2 新增三维后端

三维后端负责：

```text
Hex8SpatialLayout
Hex8BoundaryAssembly
Hex8Discretization
```

第一个三维里程碑不含接触，因此不需要提前设计一个空泛的通用接触基类。
三维接触实现应在其物理、搜索、历史和稀疏候选契约明确后单独加入。

### 5.3 公共问题类

`SteadyProblem` 和 `TransientProblem` 继续负责：

- 对求解器暴露局部贡献、约束和状态验证；
- 设置时间、载荷因子和受控函数；
- 执行已提交状态、试探状态、提交和回滚；
- 保存和恢复完整状态快照；
- 组织守恒摘要和时间误差控制。

当前公共头文件中直接返回 `RegionMesh`、`Quad4RzGeometry`、
`Quad4RzTransientKernel` 和四积分点历史的访问器会泄漏具体后端。建议将这些
访问器移入内部实现或测试支持，并为结果输出和验证提供不依赖几何的明确查询
端口。

## 6. 材料层建议

材料函数的参数元数据、热物性、温度相关弹性参数、Norton 速率和塑性流动
应力函数可以共用。位置输入建议改成包含 `time` 和三维参考坐标 `x/y/z` 的
具体上下文，不继续把公共材料接口限定为 `radius/axial_coordinate`。

本构内部建议采用具体的六分量三维对称张量，分量顺序固定为：

```text
[11, 22, 33, 12, 23, 31]
```

在笛卡尔基底中，这对应：

```text
[xx, yy, zz, xy, yz, zx]
```

在轴对称局部基底 `(r, z, hoop)` 中，现有状态映射为：

```text
[rr, zz, hoop, rz, 0, 0]
```

这里的剪切分量是张量剪应变，不是工程剪应变。J2（第二偏应力不变量）内积的
三个剪切项都乘 2。
三维客观旋转使用完整 `3 x 3` 转动形成 `R A R^T`。继续保持已提交历史使用
`double`，试探响应使用具体类型 `adlite::Scalar`。

实施时应先证明 RZ 四分量路径映射到六分量公共算法后保持现有材料测试和
MOOSE 结果，再让三维后端使用同一标量求根与六分量流动更新。第一个只包含
小应变热弹性的三维里程碑不需要提前启用三维非弹性历史。

## 7. 网格、输入、输出和检查点

### 7.1 Exodus 源网格

建议让输入输出层读取一个几何无关的源网格，至少保存：

- 空间维数；
- 单元拓扑；
- `x/y/z` 坐标；
- 原始连接关系；
- 元素块、节点集和边集的标识与名称；
- 边集中的父单元和局部边或面编号。

轴对称后端只接受二维 Quad4，三维后端只接受三维 HEX8。两者分别把源网格
连接关系复制到自己的定长数组，并执行拓扑专用校验。三维边集检查必须依据
HEX8 的六个面及其节点方向，不能沿用 Quad4 的四条线边规则。

### 7.2 输入版本

建议在三维生产入口落地时执行一次明确的破坏性迁移，将输入升级为版本 3：

```text
[Case]
  version = 3
  problem = transient
  geometry = cartesian_3d
[]
```

`geometry` 只接受：

- `axisymmetric_rz`；
- `cartesian_3d`。

单元拓扑仍由 Exodus 文件提供，不在输入卡重复声明。现有输入卡一次性迁移到
版本 3 并显式写 `axisymmetric_rz`。按照仓库“不默认提供向后兼容”的约定，
不保留版本 2 解析分支、旧键别名或隐式几何推断。

三维位移字段严格使用 `displacement_x`、`displacement_y` 和
`displacement_z`。二维继续使用 `radial_displacement` 和
`axial_displacement`。在相应能力实现前，三维接触、三维有限应变或三维
非弹性材料输入必须在问题构造前明确报错，不能静默忽略。

输入版本迁移属于待确认的实施决策。本节不改变当前输入版本 2 的生产契约。

### 7.3 结果和检查点

结果层应把底层 Exodus 文件操作与几何专用字段编码分开。二维继续输出三个
节点场、四分量应力和四个积分点；三维输出四个节点场、六分量应力和八个
积分点。

当前检查点格式固定保存四分量历史和四个积分点。三维状态落地时应升级到新的
唯一检查点版本，明确拒绝旧版本，不增加迁移读取器。问题签名必须包含几何、
拓扑、字段布局、张量分量顺序和积分点数量。现有校验和、长度校验、字节序
校验、原子替换、时间和控制器状态逻辑可以复用。

## 8. 建议的实施阶段

### 8.1 阶段 A：只做几何解耦

这一阶段不增加三维物理：

1. 新增运行时局部贡献端口和字段布局元数据。
2. 将现有二维空间装配明确封装为 RZ 后端。
3. 让 PETSc 回调、残量缩放、字段分裂和方向导数检查支持不同贡献宽度和字段数。
4. 将完整状态快照、历史误差比较和守恒汇总的具体布局下沉到后端。
5. 保持现有 RZ 局部自由度顺序、贡献顺序、接触候选选择和输入行为。

验收要求是：完整构建和 CTest 通过，所有现有局部 Jacobian、解析、端到端、
MOOSE 全场比较、检查点以及一个和多个消息传递接口进程等价性保持原门槛，
不得通过放宽门槛完成重构。

### 8.2 阶段 B：最小三维热力耦合

推荐的第一个三维生产范围是：

- 稳态与瞬态；
- HEX8 八点全积分；
- 小应变各向同性热弹性；
- 温度相关热物性、弹性和各向同性热膨胀；
- Backward Euler 一致热容；
- Dirichlet 约束、对流、参考构形压力和全局分量牵引；
- 三维 Exodus 输入、结果输出和检查点；
- 一个和多个消息传递接口进程装配。

这一阶段明确不含：

- 三维接触与摩擦；
- 三维有限应变；
- 三维塑性和蠕变；
- 位移惯性；
- 塑性耗散、蠕变耗散或热弹性效应向热方程反馈的新热源。

这里的“热力耦合”沿用当前项目含义：温度影响材料参数、本征应变和力学响应，
温度与准静态力学在同一个非线性系统中求解；它不自动扩张为尚未定义的双向
能量耦合。

### 8.3 阶段 C：三维塑性和蠕变

在六分量本构和三维状态事务独立验证后，依次增加弹性、J2 塑性、Norton 蠕变
和塑性—蠕变全隐式耦合。复用现有标量求根，但三维流动方向、无迹检查、历史
张量和八积分点提交必须使用三维实现。

### 8.4 阶段 D：三维有限应变

单独增加三维增量运动学、客观旋转、当前构形内力和随动压力。非法变形状态继续
作为物理域错误进入线搜索，或使当前载荷步或时间步失败并缩小增量重试，不得
夹持变形 Jacobian 或当前体积。

### 8.5 阶段 E：三维接触

三维接触是独立算法里程碑。当前二维开放链、节点到线段投影和一个切向滑移
标量不能直接推广。实施前必须明确：

- 热接触采用哪一种面上积分和投影离散；
- 机械接触采用节点到面还是面到面离散；
- 共享面边和顶点的唯一所有权；
- 滑出完整主表面的状态拒绝；
- 两个切向方向的摩擦历史及其客观更新；
- 大滑移可能候选的有限稀疏包络和重建规则。

## 9. 建议的验证矩阵

三维能力不能以“能够编译”或“单个六面体能够收敛”作为完成依据。每一阶段都
至少包含局部自动微分、独立解析或制造解、输入到输出的端到端求解和同网格
MOOSE 对标。

| 阶段 | 局部自动微分检查 | 独立解 | 端到端检查 | MOOSE 对标建议 |
| --- | --- | --- | --- | --- |
| A：几何解耦 | 现有 RZ 自动微分与中心差分门槛保持 | 现有解析测试保持 | 完整二维回归、结果和重启动 | 所有现有误差门槛不变 |
| B：三维热传导 | 32 自由度热残量完整方向导数 | 线性温度补丁、三维制造解、均匀升温和后向欧拉时间收敛 | 稳态、瞬态、Exodus 和检查点 | 同网格节点温度三项误差建议小于 `0.1%` |
| B：三维热弹性 | 温度与三个位移的完整 `32 x 32` Jacobian | 六种常应变补丁、刚体平移和小转动、自由热膨胀、单轴拉伸、表面合力 | 单区域、多区域、各种边界和多进程逐自由度等价 | 温度、三个位移和八积分点六分量应力三项误差建议小于 `0.1%` |
| C：三维非弹性 | 弹性、塑性、蠕变和耦合分支分别检查 | 单轴返回、卸载再加载、Norton 标量根和无迹增量 | 重复回调不提交、接受只提交一次、拒绝完整回滚、精确重启动 | 节点场、等效量和八积分点历史三项误差建议小于 `0.1%` |
| D：三维有限应变 | 增量运动学、客观旋转和 follower pressure 几何切线 | 均匀伸长、刚体旋转、当前体积和表面合力 | 非共轴多步、非法态拒绝和重启动 | 聚合与逐点门槛建议保持现有有限应变 `0.5%` 级别 |

所有新增 MOOSE 对比都必须读取 `verification/moose/` 中由对应 MOOSE 输入生成并
追踪的 `*_mesh.e`，不得在测试中重建等价网格。节点按照原始编号对齐，单元按
Exodus 标识对齐，积分点按照实际参考坐标对齐。

场量比较继续统一输出并约束：

1. 相对二范数误差；
2. 相对绝对峰值误差；
3. 最大逐点相对误差。

最大逐点相对误差只对非零参考值定义。零参考点数量和最大绝对差必须单独输出，
不得加入分母下限。任何门槛都不能在根因未明确时放宽。

涉及 CMake、PETSc 求解层或依赖配置的阶段必须执行仓库规定的 Release、警告视为
错误的完整构建和全部 CTest。并行阶段还必须执行一个和多个消息传递接口进程的
逐自由度等价性及非重复贡献检查。

## 10. 主要风险与控制措施

| 风险 | 后果 | 控制措施 |
| --- | --- | --- |
| 把全部局部数组直接扩大为 32 项 | 改变 RZ 自动微分宽度并扩大回归面 | 使用运行时端口加两种具体定长内核。 |
| 在当前 `SpatialAssembly` 中堆积维数分支 | 网格、边界和接触职责交叉，难以验证 | 明确保留 RZ 后端并新增 HEX8 后端。 |
| 四分量与六分量状态混用 | 时间误差、输出和检查点解释错误 | 固定六分量顺序，签名记录张量和积分点布局。 |
| HEX8 面编号或方向错误 | 压力方向、边界集合和合力错误 | 使用拓扑专用面节点表、父单元外法向和解析合力测试。 |
| 每次回调动态分配 32 自由度工作区 | 三维单元和八积分点放大开销 | 由 PETSc 求解器或后端预分配并复用缓冲区。 |
| 仍使用二维每行非零预估 | PETSc 矩阵动态重分配并降低性能 | 正确性完成后让后端提供稀疏预分配信息。 |
| 把三维接触视为二维接触加一个坐标 | 面边、顶点、双切向历史和候选集合错误 | 将三维接触作为独立里程碑。 |
| 小单元测试通过后宣称三维完成 | 缺少网格、输入、输出和外部参考证据 | 绑定局部、解析、端到端和 MOOSE 四级验收。 |

HEX8 的局部 Jacobian 从 144 项增加到 1024 项，积分点从四个增加到八个。性能
修改必须在正确性验收之后，用固定处理器和固定线程设置进行同机配对测试；不能
从单个小算例外推三维扩展性。

## 11. 实施前需要确认的范围

本次讨论形成的默认建议是：

1. 第一个三维版本同时支持稳态和瞬态。
2. 第一个三维版本只支持小应变各向同性热弹性，不含接触。
3. 三维塑性与蠕变、有限应变和接触分别作为后续里程碑。
4. 三维生产入口落地时将输入一次性升级到版本 3，不提供版本 2 兼容分支。
5. 首版热力耦合不增加惯性或耗散发热等新的双向热源。

开始实施前应再次确认上述范围。若首版同时要求有限应变、塑性—蠕变和三维
摩擦接触，工作量、稀疏结构和验证矩阵都会发生实质变化，不能按最小重构计划
执行。
