# 二维广义平面应变 CPEG8T

生产入口为 `fuelsim -i case.fsi`。输入选择
`geometry = generalized_plane_strain`，每个区域声明 `element = cpeg8t`。
该模型描述两个端平面之间的二维截面，允许共同的厚度伸长和两个弯曲参数，
不包含截面翘曲或扭转自由度。它与一维轴对称 `cax2t_gps` 是不同的几何路径。

## 网格与自由度

Exodus 文件使用标准二维 QUAD8：四个角点和四个边中点都有两个面内位移，
只有四个角点求解温度。不需要额外参考节点，也不需要自定义元素属性。
网格只提供节点、连接关系、block 名称、节点集和边集。

在输入卡中用 `[GeneralizedPlaneStrain]` 定义任意多个 section。每个 section
指定一个或多个 block，并直接设置厚度方向伸长 `u3` 和两个转动参数：

```ini
[GeneralizedPlaneStrain]
  [fuel_section]
    blocks = fuel coating
    initial_thickness = 0.1
    u3 = 0.0001
    rotation_x = 0
    rotation_y = 0
  []
  [clad_section]
    blocks = clad
    initial_thickness = 0.1
    rotation_x = 0
    rotation_y = 0
  []
[]
```

这里 `fuel` 和 `coating` 共用三个截面自由度；`clad` 使用另一组三个自由度。
`clad_section` 省略 `u3`，因此其厚度伸长由平衡方程求解。
显式写 `0` 表示固定为零，省略表示自由；不使用 `free` 字符串。
`initial_thickness` 必填，必须为正，单位为米；`u3` 的单位为米，转动参数为弧度。
初始端平面平行，两个初始转动参数为零。

每个参与计算的 block 必须且只能归属一个 section。共用场节点的相邻 block
必须放在同一 section。通过接触连接、节点相互独立的 block 可以使用不同 section。
每个 section 自动采用全部所属单元的初始面积形心 `(X0,Y0)` 作为伸长基准，
该位置由二次几何的九点积分计算，不是网格节点，也不需要用户额外指定。

瞬态约束可以直接使用 `u3_function`、`rotation_x_function`、`rotation_y_function`
引用 `[TimeFunctions]` 中的函数，实际值为相应数值乘函数值。函数必须与对应数值同时给出；
省略函数时数值保持常量。各 section 的函数独立设置。温度、面内位移和边面载荷
仍写在 `[BoundaryConditions]` 中，截面约束只写在这里。

全局排列为 `[T, ux, uy, u3, rotation_x, rotation_y]`，每一场连续排列，
三个截面场分别按 section 声明顺序排列。局部仍共 23 个自由度：四个温度、
十六个位移和三个截面控制量。当前尚不提供截面集中轴向力或弯矩输入。

结果的温度、面内位移和对应反力仍作为节点变量输出。截面量作为 Exodus 全局变量
输出，前缀为 `section_<名称>_`，后缀包括 `u3`、`rotation_x`、`rotation_y`、
`axial_force`、`moment_x`、`moment_y`、`origin_x`、`origin_y`、`initial_thickness`。
两个弯矩以该 section 的初始形心为基准。section 名称最长 38 个字符，以满足结果名称长度。

在小应变下，厚度应变为
`(u3 + rotation_x*(Y-Y0) - rotation_y*(X-X0))/initial_thickness`。
有限应变下使用当前面内坐标计算厚度，采用增量中间构形应变和客观张量转动。
已接受、当前及中间构形的面积映射，以及已接受和当前厚度必须有效。
非法试探构形会进入求解器的线搜索或缩小时间步重试。

## 材料、热算子与边界

位移采用八节点二次插值，温度采用四角点双线性插值，体积分使用 3×3 Gauss 积分。
材料温度在各积分点插值，不使用四节点轴对称单元的角点配对规则。
材料继续调用现有弹性、热膨胀、塑性和蠕变函数；历史仅在接受时间步后提交。
局部自动微分使用十个运动学量和七个本构量，经闭式节点链组成 23×23 切线矩阵。

热容遵守 Fuelsim 的固定初始质量规则：初始密度乘参考体积，比热取当前温度，
保留一致热容矩阵和比热温度导数，热容对位移的导数为零。
小应变导热使用参考测度；有限应变导热使用中间构形梯度和当前二次几何及当前厚度。
体热源使用四角点双线性几何面积乘初始厚度，小应变取参考面积，有限应变取当前面积。
边中点位移和截面伸长不改变体热源测度；当前角点位移的导数完整进入切线。
这些区别由非仿射几何和单独改变厚度的 Abaqus 探测确认。
`body_acceleration` 接受固定全局 `x y` 加速度，采用参考初始质量装配。

边集支持压力、两个面内分量的牵引、表面热流和对流。
`configuration = reference|current` 选择边长的积分构形；省略时按区域应变形式选择。
机械载荷的厚度同样遵从所选构形；热流和对流始终使用初始厚度。
对流采用温度端点各自的温差及积分形函数权重，温度切线为节点对角形式。
温度边界仅约束角点，位移边界覆盖八个场节点。

`steady` 当前用于小应变热弹性。有限应变或非弹性采用 `transient`；
需要准静态热平衡时可设置 `include_thermal_time_term = false`。
检查点保存全部场值、截面控制量和九个材料点的完整历史。

## 二维热机械接触

每个接触对由 `primary` 和 `secondary` 指定 Exodus 边集，可以独立启用
热传导、力学接触或两者。首轮实现支持无摩擦、面到面、线性罚函数接触。
机械配置使用 `formulation = penalty`、`discretization = surface_to_surface`、
`sliding = finite`。这里的有限滑移表示每次状态验证都在当前二次曲线上重新搜索投影，
并不要求体单元采用有限应变。

力学按从侧节点邻域建立平均间隙约束。每条二次边在三个节点面积区间上分别采用
3、5、3 个等权采样点，以分片线性权函数平均间隙。相邻从侧边共用的节点只有一个
约束，其两侧邻域共同参与平均。法向取当前从侧曲线的法向，并保留在形函数积分
内部；曲边不能先平均法向再统一分配节点力。主侧单元边界附近采用有限范围的
平滑分配，包含相邻主侧节点的耦合。采样公式和独立鉴定见
[平均接触验证](../verification/abaqus/cpeg8t/averaged-contact.md)。

热接触仍按主侧单元端点的法向投影划分积分区间，每段使用三个 Gauss 积分点。
平均权重、法向、投影、平滑范围和热积分边界随位移的导数全部进入一致切线。
每对二次边的两个端点投影方程最多形成五个区间，程序为每对边预留十五个积分位置
及全部候选耦合块。未启用的位置输出严格零，结果字段数量不随滑移改变。
有效主侧投影区间必须连续且互不重叠，端部只积分真实重叠范围；全部失去投影、
区间之间出现空缺、区间重叠或区间内部投影
发生变化时拒绝当前状态。该实现尚不支持有重叠法向投影区间的折角主侧表面。
每个力学约束和热积分点均在主从两侧使用相同测度，保证离散力与热流成对守恒。
小应变和有限应变接触面积均使用从侧初始厚度与当前边长，与原生交互厚度探测一致。
热接触支持现有气隙导热律及间隙、压力、温度相关的仿射导热律。

摩擦、增广拉格朗日约束、节点到面离散和固定初始投影的小滑移方法尚未实现，
对应输入会明确报错。非匹配抛物线接触的节点机械反力和热反力已通过 Abaqus 比较，
跨主侧单元滑移的节点力分布已通过 Abaqus 和四进程比较。
不同截面约束下的非均匀接触 `sections_contact`，以及两个曲边共用从侧节点的
`shared_contact` 均通过原有 Abaqus 门槛。该范围不推广到任意折角或自接触。

接触全局输出先列出按从侧场节点顺序排列的力学平均约束，再列出热积分位置。
力学条目的 `heat_rate` 为零；热条目的 `force` 和 `pressure` 为零。
数量在问题构造时固定，未启用的热积分区间输出严格零。

## 可运行例题与验证边界

完整输入卡位于 `verification/abaqus/cpeg8t/`：
`prescribed.fsi`、`free_controls.fsi`、`finite_prescribed.fsi`、
`contact.fsi` 和 `finite_contact.fsi`。
`sections.fsi` 另外验证两种厚度、不同约束与时间函数，以及自由伸长的解析解。网格生成脚本只生成 Exodus，不生成输入卡。
自动比较读取真实生产程序输出的温度、位移、反力、九点应力、截面控制量和接触量，
不重建内部求解状态。非零量要求相对二范数、相对绝对峰值和最大逐点相对误差
全部小于 0.5%；解析零量单独使用绝对误差，不给相对误差分母加下限。

有限应变下塑性、蠕变及二者同时作用的加载、保持和卸载已经建立生产例题，
全部时间点的场值和分机制历史通过 Abaqus 比较。小应变新增
`inelastic_initial_plastic.fsi`，在第一个增量就激活塑性并持续加载，全部时间点的
分机制历史同样通过。原保持、卸载例题继续保留后向 Euler 解析检查；其显式与隐式
蠕变积分差异仍作为诊断记录，不能把旧例题改记为原生比较通过。
补充验证的具体范围和未通过项见
[验证记录](../verification/abaqus/cpeg8t/coverage.md)。完整证据和运行方式见
[验证说明](../verification/abaqus/cpeg8t/README.md)。
