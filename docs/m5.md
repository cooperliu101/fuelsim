# M5 接触与工程扩展

## M5.1 Coulomb 摩擦

机械接触仍使用当前构形下唯一的 secondary 节点到 primary 线段投影。对
每个已投影节点，当前 primary 线段的单位切向记为 `t`，本步 secondary
位移增量减去投影 primary 位移增量后在 `t` 上的分量记为 `delta_s`。已提交
的弹性切向滑移为 `s_old`，法向和切向罚刚度都取输入 `penalty = k`，因此
弹性预测为：

```text
s_trial   = s_old + delta_s
tau_trial = k * s_trial
tau_limit = mu * pressure
```

当 `abs(tau_trial) < tau_limit` 时节点粘着，`tau = tau_trial`。当预测牵引
超过上限，或已提交滑移节点在上限处继续同向运动时，节点滑移：

```text
tau   = sign(tau_trial) * tau_limit
s_new = tau / k
```

开放接触的切向牵引和弹性滑移为零。切向节点力使用与法向力相同的 secondary
半边面积集总，并按当前 primary 线段形函数向两个 primary 节点分配大小相等、
方向相反的反力，因此径向和轴向方程都离散守恒。

稳态延续求解只在一个收敛载荷增量后提交 `s_new` 与粘滑标志，拒绝的增量不
修改历史。瞬态求解把同一状态并入 committed/trial/commit/rollback、
step-doubling 和检查点事务。检查点格式升为版本 5；版本 4 和更早格式会被
明确拒绝。输入 `mu` 默认是 `0`，该分支不装配切向项，并通过逐项相等测试
约束原无摩擦残量。

局部解析和自动微分验证覆盖粘着、滑移、滑移后反向重新粘着三条分支。
三条分支的自动微分 Jacobian 与中心差分方向导数最大缩放误差分别为
`4.38e-9`、`7.48e-9` 和 `6.01e-9`；切向和法向反力同时满足局部离散守恒。

端到端参考沿用 M1 的 528 节点、460 个 Quad4、1,584 个自由度燃料—包壳
网格、热载荷、材料、罚参数和 20 步加载，只把 MOOSE 接触模型改为
`coulomb` 并设 `mu = 0.3`。最终 11 个接触节点全部承受法向压力，其中 8 个
处于滑移；secondary 切向合力为 `207.371182 N`。相对无摩擦基线，轴向节点
场的相对 L2 改变量为 `5.0871%`，所以该对比确实激活了摩擦。

fuelsim 相对 MOOSE 的最终全场三项最大误差如下；百分数都以对应 MOOSE
全场量为参照，零参考点按验证通用规则单列，不加入分母下限：

| 场量 | 相对 L2 | 相对绝对峰值 | 最大逐点相对误差 |
| --- | ---: | ---: | ---: |
| 温度 | 0.009879% | 0.000422% | 0.086476% |
| 径向位移 | 0.064299% | 0.128467% | 0.386523% |
| 轴向位移 | 0.018266% | 0.026455% | 0.439326% |
| 法向压力 | 0.187221% | 0.318127% | 0.318127% |

四个场量的三项误差都低于本算例 `1%` 门槛。该证据只鉴定当前小滑移候选
范围内的罚接触和规定热膨胀剪切路径；大滑移搜索由下一节独立鉴定，两项证据
不能合并外推为任意大滑移摩擦路径。

## M5.2 完整 primary 链动态搜索

机械接触不再只构造参考最近段及相邻段。问题构造时为每个 secondary 半边
节点与完整 primary 开放边链的每一段建立固定 12 自由度贡献，因此第一次
Jacobian 装配已经预留所有潜在非零位置。每次全局状态验证按当前构形检查全部
投影，选择绝对法向距离最小的有效段；内部顶点继续使用半开区间，等距非相邻
候选按有序段编号确定性选择。残量和 Jacobian 只激活所选段，其余预留贡献为
零，所以 PETSc 的 `MAT_NEW_NONZERO_LOCATION_ERR` 锁定语义和单一工作区保持
不变。节点滑出整条 primary 链时仍作为物理域错误进入线搜索或拒绝时间步。

一般法向局部测试把一个 secondary 节点从参考中段移动到原三段窗口之外。
节点在内部顶点左右只发生一次所有权转移，顶点本身归后一个半开段；顶点两侧
接触力差小于局部力尺度的 `1e-5`，动态选择后的径向和轴向接触反力分别离散
守恒。滑出完整链的状态仍被明确拒绝。

MOOSE 隔离算例使用 402 节点、264 个 Quad4 和 1,206 个自由度。4 mm 宽的
secondary 面径向伸长到 4.23 mm，8 mm 宽的 primary 面使用 128 段；五个
secondary 节点全部保持 `100 MPa` 法向压力，最大活动段编号相对初态前进 2，
因此确实越过旧的最近段加相邻段窗口。接触面法向位移完全控制，将动态搜索和
罚压力与两套 NTS 反力平滑差异隔离；局部测试负责验证未约束反力连续与守恒。
温度、径向位移、轴向位移和压力的相对 L2、相对绝对峰值及最大逐点相对误差
全部低于 `7.8e-13%`，零参考点单列且没有分母下限。

同一输入的 1 rank 与 2 rank 解逐自由度通过 `1e-10` 缩放门槛，并检查每个
贡献只属于一个 rank。20 步不间断瞬态路径与第 10 步检查点恢复后的续算终态
逐自由度完全相同，最大绝对差和缩放差均为 `0`；五个活动段编号和压力也逐项
一致。这证明候选窗口可由 committed 几何确定性重建，无须加入检查点格式。

该证据只覆盖不分叉开放 Line2 链、唯一最近投影和 primary 完整覆盖。闭合面、
自接触、多解几何、mortar 接触以及大滑移与 Coulomb 摩擦同时激活的路径仍未
鉴定。

## M5.3 时间积分可信度默认策略

Backward Euler step-doubling 继续作为显式选择，生产默认保持关闭。开启后
一个控制步通常需要一个全步和两个半步，约为原求解工作量的三倍；更重要的是，
温度、位移、应变历史和应力的绝对容差必须对应具体工况的物理尺度。因此程序
不能用一个通用默认容差替代用户的精度目标。输入指导建议对长时蠕变、塑性累积
和接触状态变化工况先做固定步长全局收敛，再从相对容差 `1e-3` 开始试算并按
全局误差结果收紧。现有固定步长 MOOSE 基线不受这个选择影响。

步长控制器已经约束缩步后的增长：若一个候选步求解失败或因时间误差过大而
缩小，最终接受该步后，下一控制步最多保持最终接受的实际步长，不会立即回到
刚失败的较大步长；再经历一个没有缩步的成功步后才允许按增长因子放大。自动
测试实际触发时间误差缩步，并逐接受步检查这一条件。失败重试仍从同一个完整
committed 状态开始。

全局研究采用现有 34 单元非匹配燃料—包壳接触模型，其中燃料 24 单元、包壳
10 单元和 40 个包壳积分点；将 20 秒升载后继续计算到 100 秒，使接触、J2
塑性和 Norton 蠕变历史都保持活跃。固定步长依次为
`1 s`、`0.5 s`、`0.25 s`，以 `0.125 s` 的 800 步结果为共同参考。下表给出
相对 L2 误差从 `1 s` 到 `0.25 s` 的变化，以及 `0.25 s` 解相对参考的最大
绝对差；相对量的参照是对应 `0.125 s` 全场或全部积分点状态的 L2 尺度：

| 场量 | 相对 L2：1 s → 0.25 s | 0.25 s 最大绝对差 |
| --- | ---: | ---: |
| 温度 | `1.114e-12 → 1.660e-13` | `2.889e-10 K` |
| 径向位移 | `2.756e-5 → 5.994e-6` | `5.217e-11 m` |
| 轴向位移 | `2.886e-5 → 4.583e-6` | `9.897e-11 m` |
| 应力 | `7.350e-5 → 1.071e-5` | `4.035 kPa` |
| 弹性应变 | `3.012e-4 → 4.397e-5` | `4.249e-8` |
| 塑性应变 | `2.118e-2 → 3.290e-3` | `1.344e-6` |
| 蠕变应变 | `4.378e-2 → 6.816e-3` | `1.310e-6` |
| 等效塑性应变 | `2.147e-2 → 3.345e-3` | `1.398e-6` |
| 等效蠕变应变 | `4.379e-2 → 6.821e-3` | `1.337e-6` |

温度绝对差最高只有 `2.005e-9 K`，相对于约 `600 K` 温度尺度为
`3.34e-12`，已经受非线性求解和浮点舍入影响，不用于声称时间收敛阶。其余
八组量都随步长缩小而单调接近参考。用相邻步长解差计算时，应力、弹性应变、
塑性/蠕变历史和轴向位移的两个观测阶在 `0.81–1.19`；径向位移只有
`0.50` 和 `0.60`。该路径包含接触和非弹性分支变化，并非全程光滑，所以证据
支持“代表性长工况收敛”，不支持所有场、任意路径都达到严格一阶的外推。

同一完整回归继续运行 M2.3 固定步长 MOOSE 对比；节点场、压力、总力、平均
状态和 40 个积分点的既有三项误差仍全部低于 `0.1%`，因此本里程碑没有改变
既有 MOOSE 基线或参考文件。

## M5.4 自动罚刚度与增广拉格朗日法向接触

机械接触省略 `penalty` 时，fuelsim 根据接触两侧材料和边界法向网格尺度计算
罚刚度。每个边界相邻 Quad4 的法向尺度取参考平面面积除以边长；每一侧取其
所有边界单元中的最小值。若两侧杨氏模量和法向尺度分别为 `E_p, h_p` 与
`E_s, h_s`，则输入中的无量纲 `penalty_factor` 形成：

```text
k_interface = 1 / (h_p / E_p + h_s / E_s)
penalty = penalty_factor * k_interface
```

这相当于两侧法向单元刚度串联。显式 `penalty` 与 `penalty_factor` 互斥，
因此不会出现一个输入被另一个静默覆盖。M1 网格上的 `h_secondary = 1.03e-4 m`、
`h_primary = 9.5e-5 m` 给出
`k_interface = 5.612722170253e14 Pa/m`；自动结果与该独立计算逐位通过测试。

`formulation = augmented_lagrangian` 为每个 secondary 接触节点保存非负法向
乘子 `lambda`。固定乘子的内层 Newton 求解使用：

```text
pressure = max(lambda - penalty * gap, 0)
lambda_new = max(0, lambda - penalty * gap)
```

内层求解收敛后才更新一次乘子并复用同一个 PETSc 稀疏工作区。外层验收同时
检查物理穿透 `max(-gap, 0)` 和互补约束：对于乘子为正或间隙非正的已捕获
节点，绝对间隙必须小于 `penetration_tolerance`；开放且乘子为零的节点不受
该约束。这样不会把已经分离但仍带正乘子的节点误判为收敛。达到
`maximum_augmented_iterations` 仍未通过时，本次载荷步或时间步被明确归类为
接触约束失败，节点场、载荷因子、积分点历史和接触乘子全部恢复到同一已提交
状态。

乘子加入稳态载荷延续、瞬态 committed/trial/commit/rollback、Backward Euler
step-doubling 和重启动事务。检查点格式升为版本 6；版本 5 及更早文件明确
拒绝。事务测试在人工施加 `2 nm` 穿透后确认乘子更新不会提前推进物理时间，
失败回滚逐项恢复，成功提交后的非零乘子和下一名义时间步可由检查点精确恢复。
局部法向接触测试还同时检查自动微分 Jacobian、中心差分方向导数与两侧反力
守恒。

条件数改进采用一个明确受限的两体切线代理，不将它描述成完整有限元矩阵的
条件数。两侧体刚度均记为 `k_interface`，接触刚度为 `k_c` 时，二维矩阵的
特征值为 `k_interface` 与 `k_interface + 2 k_c`，条件数为
`1 + 2 k_c / k_interface`。高罚刚度 `k_c = 10 k_interface` 的代理条件数为
`21`；增广拉格朗日内层使用 `k_c = 0.25 k_interface` 时为 `1.5`，降低
`92.9%`。该数字只隔离说明法向两体接触切线的刚度影响，不是全局 PETSc
Jacobian 的谱测量或迭代次数缩放结论。

端到端对比沿用 528 节点、460 个 Quad4 和 1,584 个自由度的 M1 网格。
MOOSE 参考使用 `10 k_interface = 5.612722170253e15 Pa/m`，作为离散约束极限；
fuelsim 使用 `0.25 k_interface = 1.40318054256325e14 Pa/m`、`1 nm` 穿透容差
和增广乘子。最终只需一次非零乘子更新，最大穿透为 `0.1278 nm`，占容差的
`12.8%`。fuelsim 相对 MOOSE 约束极限的三项全场误差如下：

| 场量 | 相对 L2 | 相对绝对峰值 | 最大逐点相对误差 |
| --- | ---: | ---: | ---: |
| 温度 | 0.009854% | 0.000539% | 0.086402% |
| 径向位移 | 0.061852% | 0.128362% | 0.343463% |
| 轴向位移 | 0.017512% | 0.025177% | 0.770933% |
| 法向压力 | 0.171695% | 0.251094% | 0.251094% |

四个场量的三项误差都低于对应 MOOSE 全场尺度的 `1%` 门槛。径向位移有
11 个零参考点，轴向位移有 48 个零参考点；这些点的最大绝对差均为零，且
没有加入分母下限。

当前 MOOSE 节点到面接触的原生增广乘子压力没有作为本项已验证参考。诊断中，
以 `0.25 k_interface` 运行时，MOOSE 原生增广压力相对 fuelsim 的相对 L2、
相对绝对峰值和最大逐点相对误差分别为 `8.711%`、`3.91%` 和 `12.72%`；将
罚刚度增至 `1 k_interface` 后，压力相对 L2 和最大逐点误差反而变为
`11.44%` 和 `17.59%`。更低罚刚度配合更紧非线性容差时，MOOSE 在重复增广
更新中达到最大非线性迭代数。问题类替换为推荐的
`AugmentedLagrangianContactFEProblem` 也没有改变结果。该诊断说明当前外部
实现的节点压力不能作为稳定的逐节点乘子预言值；因此本项只声称对高罚刚度
离散约束极限的物理解、事务完整性和受限两体条件数代理通过，不外推为与
MOOSE 原生增广乘子逐节点等价，也不证明任意网格和任意接触路径收敛。
