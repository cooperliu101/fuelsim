# M5 接触与工程扩展

## M5.1 Coulomb 摩擦

机械接触仍使用当前构形下唯一的 secondary 节点到 primary 线段投影。对
每个已投影节点，当前 primary 线段的单位切向记为 `t`，本步 secondary
位移增量减去投影 primary 位移增量后在 `t` 上的分量记为 `delta_s`。已提交
的弹性切向滑移为 `s_old`，法向和切向罚刚度都取输入 `penalty = k`，因此
弹性预测为：

```text
s_trial   = s_old + delta_s
tau_trial = k * s_trial
tau_limit = mu * pressure
```

当 `abs(tau_trial) < tau_limit` 时节点粘着，`tau = tau_trial`。当预测牵引
超过上限，或已提交滑移节点在上限处继续同向运动时，节点滑移：

```text
tau   = sign(tau_trial) * tau_limit
s_new = tau / k
```

开放接触的切向牵引和弹性滑移为零。切向节点力使用与法向力相同的 secondary
半边面积集总，并按当前 primary 线段形函数向两个 primary 节点分配大小相等、
方向相反的反力，因此径向和轴向方程都离散守恒。

稳态延续求解只在一个收敛载荷增量后提交 `s_new` 与粘滑标志，拒绝的增量不
修改历史。瞬态求解把同一状态并入 committed/trial/commit/rollback、
step-doubling 和检查点事务。检查点格式升为版本 5；版本 4 和更早格式会被
明确拒绝。输入 `mu` 默认是 `0`，该分支不装配切向项，并通过逐项相等测试
约束原无摩擦残量。

局部解析和自动微分验证覆盖粘着、滑移、滑移后反向重新粘着三条分支。
三条分支的自动微分 Jacobian 与中心差分方向导数最大缩放误差分别为
`4.38e-9`、`7.48e-9` 和 `6.01e-9`；切向和法向反力同时满足局部离散守恒。

端到端参考沿用 M1 的 528 节点、460 个 Quad4、1,584 个自由度燃料—包壳
网格、热载荷、材料、罚参数和 20 步加载，只把 MOOSE 接触模型改为
`coulomb` 并设 `mu = 0.3`。最终 11 个接触节点全部承受法向压力，其中 8 个
处于滑移；secondary 切向合力为 `207.371182 N`。相对无摩擦基线，轴向节点
场的相对 L2 改变量为 `5.0871%`，所以该对比确实激活了摩擦。

fuelsim 相对 MOOSE 的最终全场三项最大误差如下；百分数都以对应 MOOSE
全场量为参照，零参考点按验证通用规则单列，不加入分母下限：

| 场量 | 相对 L2 | 相对绝对峰值 | 最大逐点相对误差 |
| --- | ---: | ---: | ---: |
| 温度 | 0.009879% | 0.000422% | 0.086476% |
| 径向位移 | 0.064299% | 0.128467% | 0.386523% |
| 轴向位移 | 0.018266% | 0.026455% | 0.439326% |
| 法向压力 | 0.187221% | 0.318127% | 0.318127% |

四个场量的三项误差都低于本算例 `1%` 门槛。该证据只鉴定当前小滑移候选
范围内的罚接触和规定热膨胀剪切路径；大滑移搜索由下一节独立鉴定，两项证据
不能合并外推为任意大滑移摩擦路径。M5.7 另用综合例题直接验证一个规定的
大滑移与 Coulomb 摩擦组合路径。

## M5.2 完整 primary 链动态搜索

机械接触不再只构造参考最近段及相邻段。问题构造时为每个 secondary 半边
节点与完整 primary 开放边链的每一段建立固定 12 自由度贡献，因此第一次
Jacobian 装配已经预留所有潜在非零位置。每次全局状态验证按当前构形检查全部
投影，选择绝对法向距离最小的有效段；内部顶点继续使用半开区间，等距非相邻
候选按有序段编号确定性选择。残量和 Jacobian 只激活所选段，其余预留贡献为
零，所以 PETSc 的 `MAT_NEW_NONZERO_LOCATION_ERR` 锁定语义和单一工作区保持
不变。节点滑出整条 primary 链时仍作为物理域错误进入线搜索或拒绝时间步。

一般法向局部测试把一个 secondary 节点从参考中段移动到原三段窗口之外。
节点在内部顶点左右只发生一次所有权转移，顶点本身归后一个半开段；顶点两侧
接触力差小于局部力尺度的 `1e-5`，动态选择后的径向和轴向接触反力分别离散
守恒。滑出完整链的状态仍被明确拒绝。

MOOSE 隔离算例使用 402 节点、264 个 Quad4 和 1,206 个自由度。4 mm 宽的
secondary 面径向伸长到 4.23 mm，8 mm 宽的 primary 面使用 128 段；五个
secondary 节点全部保持 `100 MPa` 法向压力，最大活动段编号相对初态前进 2，
因此确实越过旧的最近段加相邻段窗口。接触面法向位移完全控制，将动态搜索和
罚压力与两套 NTS 反力平滑差异隔离；局部测试负责验证未约束反力连续与守恒。
温度、径向位移、轴向位移和压力的相对 L2、相对绝对峰值及最大逐点相对误差
全部低于 `7.8e-13%`，零参考点单列且没有分母下限。

同一输入的 1 rank 与 2 rank 解逐自由度通过 `1e-10` 缩放门槛，并检查每个
贡献只属于一个 rank。20 步不间断瞬态路径与第 10 步检查点恢复后的续算终态
逐自由度完全相同，最大绝对差和缩放差均为 `0`；五个活动段编号和压力也逐项
一致。这证明候选窗口可由 committed 几何确定性重建，无须加入检查点格式。

该证据只覆盖不分叉开放 Line2 链、唯一最近投影和 primary 完整覆盖。闭合面、
自接触、多解几何和 mortar 接触仍未鉴定。本节隔离证据本身不覆盖大滑移与
Coulomb 摩擦组合；M5.7 已直接覆盖其规定网格、载荷路径和接触参数，超出该
范围的组合仍未鉴定。

## M5.3 时间积分可信度默认策略

Backward Euler step-doubling 继续作为显式选择，生产默认保持关闭。开启后
一个控制步通常需要一个全步和两个半步，约为原求解工作量的三倍；更重要的是，
温度、位移、应变历史和应力的绝对容差必须对应具体工况的物理尺度。因此程序
不能用一个通用默认容差替代用户的精度目标。输入指导建议对长时蠕变、塑性累积
和接触状态变化工况先做固定步长全局收敛，再从相对容差 `1e-3` 开始试算并按
全局误差结果收紧。现有固定步长 MOOSE 基线不受这个选择影响。

步长控制器已经约束缩步后的增长：若一个候选步求解失败或因时间误差过大而
缩小，最终接受该步后，下一控制步最多保持最终接受的实际步长，不会立即回到
刚失败的较大步长；再经历一个没有缩步的成功步后才允许按增长因子放大。自动
测试实际触发时间误差缩步，并逐接受步检查这一条件。失败重试仍从同一个完整
committed 状态开始。

全局研究采用现有 34 单元非匹配燃料—包壳接触模型，其中燃料 24 单元、包壳
10 单元和 40 个包壳积分点；将 20 秒升载后继续计算到 25 秒，使接触、J2
塑性和 Norton 蠕变历史都保持活跃。固定步长依次为
`1 s`、`0.5 s`、`0.25 s`，以 `0.125 s` 的 200 步结果为共同参考。下表给出
相对 L2 误差从 `1 s` 到 `0.25 s` 的变化，以及 `0.25 s` 解相对参考的最大
绝对差；相对量的参照是对应 `0.125 s` 全场或全部积分点状态的 L2 尺度：

| 场量 | 相对 L2：1 s → 0.25 s | 0.25 s 最大绝对差 |
| --- | ---: | ---: |
| 温度 | `5.716e-4 → 8.303e-5` | `0.1003 K` |
| 径向位移 | `4.545e-3 → 6.630e-4` | `2.300e-9 m` |
| 轴向位移 | `3.930e-3 → 5.727e-4` | `5.868e-9 m` |
| 应力 | `4.878e-3 → 7.094e-4` | `165.9 kPa` |
| 弹性应变 | `5.226e-3 → 7.892e-4` | `5.667e-7` |
| 塑性应变 | `2.118e-2 → 3.290e-3` | `1.344e-6` |
| 蠕变应变 | `2.586e-2 → 3.870e-3` | `5.176e-7` |
| 等效塑性应变 | `2.147e-2 → 3.345e-3` | `1.398e-6` |
| 等效蠕变应变 | `2.586e-2 → 3.874e-3` | `5.342e-7` |

温度在最粗 `1 s` 步长下的最大绝对差为 `0.6904 K`，相对于约 `600 K`
温度尺度为 `1.15e-3`。九组量都随步长缩小而单调接近参考。用相邻步长解差计算时，
温度的两个观测阶为 `0.969275` 和 `0.992252`，九组量的两个观测阶最小值分别为
`0.816876` 和 `0.969136`。该路径包含接触和非弹性分支变化，并非全程光滑，所以证据
支持“代表性长工况收敛”，不支持所有场、任意路径都达到严格一阶的外推。

同一完整回归继续运行 M2.3 固定步长 MOOSE 对比；节点场、压力、总力、平均
状态和 40 个积分点的既有三项误差仍全部低于 `0.1%`，因此本里程碑没有改变
既有 MOOSE 基线或参考文件。

## M5.4 自动罚刚度与增广拉格朗日法向接触

机械接触省略 `penalty` 时，fuelsim 根据接触两侧材料和边界法向网格尺度计算
罚刚度。每个边界相邻 Quad4 的法向尺度取参考平面面积除以边长；每一侧取其
所有边界单元中的最小值。若两侧杨氏模量和法向尺度分别为 `E_p, h_p` 与
`E_s, h_s`，则输入中的无量纲 `penalty_factor` 形成：

```text
k_interface = 1 / (h_p / E_p + h_s / E_s)
penalty = penalty_factor * k_interface
```

这相当于两侧法向单元刚度串联。显式 `penalty` 与 `penalty_factor` 互斥，
因此不会出现一个输入被另一个静默覆盖。M1 网格上的 `h_secondary = 1.03e-4 m`、
`h_primary = 9.5e-5 m` 给出
`k_interface = 5.612722170253e14 Pa/m`；自动结果与该独立计算逐位通过测试。

`formulation = augmented_lagrangian` 为每个 secondary 接触节点保存非负法向
乘子 `lambda`。固定乘子的内层 Newton 求解使用：

```text
pressure = max(lambda - penalty * gap, 0)
lambda_new = max(0, lambda - penalty * gap)
```

内层求解收敛后才更新一次乘子并复用同一个 PETSc 稀疏工作区。外层验收同时
检查物理穿透 `max(-gap, 0)` 和互补约束：对于乘子为正或间隙非正的已捕获
节点，绝对间隙必须小于 `penetration_tolerance`；开放且乘子为零的节点不受
该约束。这样不会把已经分离但仍带正乘子的节点误判为收敛。达到
`maximum_augmented_iterations` 仍未通过时，本次载荷步或时间步被明确归类为
接触约束失败，节点场、载荷因子、积分点历史和接触乘子全部恢复到同一已提交
状态。

乘子加入稳态载荷延续、瞬态 committed/trial/commit/rollback、Backward Euler
step-doubling 和重启动事务。检查点格式升为版本 6；版本 5 及更早文件明确
拒绝。事务测试在人工施加 `2 nm` 穿透后确认乘子更新不会提前推进物理时间，
失败回滚逐项恢复，成功提交后的非零乘子和下一名义时间步可由检查点精确恢复。
局部法向接触测试还同时检查自动微分 Jacobian、中心差分方向导数与两侧反力
守恒。

条件数改进采用一个明确受限的两体切线代理，不将它描述成完整有限元矩阵的
条件数。两侧体刚度均记为 `k_interface`，接触刚度为 `k_c` 时，二维矩阵的
特征值为 `k_interface` 与 `k_interface + 2 k_c`，条件数为
`1 + 2 k_c / k_interface`。高罚刚度 `k_c = 10 k_interface` 的代理条件数为
`21`；增广拉格朗日内层使用 `k_c = 0.25 k_interface` 时为 `1.5`，降低
`92.9%`。该数字只隔离说明法向两体接触切线的刚度影响，不是全局 PETSc
Jacobian 的谱测量或迭代次数缩放结论。

端到端对比沿用 528 节点、460 个 Quad4 和 1,584 个自由度的 M1 网格。
MOOSE 参考使用 `10 k_interface = 5.612722170253e15 Pa/m`，作为离散约束极限；
fuelsim 使用 `0.25 k_interface = 1.40318054256325e14 Pa/m`、`1 nm` 穿透容差
和增广乘子。最终只需一次非零乘子更新，最大穿透为 `0.1282 nm`，占容差的
`12.8%`。fuelsim 相对 MOOSE 约束极限的三项全场误差如下：

| 场量 | 相对 L2 | 相对绝对峰值 | 最大逐点相对误差 |
| --- | ---: | ---: | ---: |
| 温度 | 0.006852% | 0.001194% | 0.058121% |
| 径向位移 | 0.042829% | 0.090532% | 0.225261% |
| 轴向位移 | 0.016926% | 0.023312% | 0.801516% |
| 法向压力 | 0.091399% | 0.132761% | 0.132761% |

通用当前法向使参考网格中竖直的主面按变形后斜率产生轴向接触分量，热接触
积分点也在完整 primary 链上按当前构形选择唯一投影段。轴向位移最大逐点指标
在约 `0.1466 um` 的非零参考值处为 `0.801516%`，绝对差 `1.175 nm`；全部四个
场量的三项误差均低于统一 `1%` 门槛。径向位移有 11 个零参考点，轴向位移有
48 个零参考点；这些点的最大绝对差均为零，且没有加入分母下限。

当前 MOOSE 节点到面接触的原生增广乘子压力没有作为本项已验证参考。诊断中，
以 `0.25 k_interface` 运行时，MOOSE 原生增广压力相对 fuelsim 的相对 L2、
相对绝对峰值和最大逐点相对误差分别为 `8.711%`、`3.91%` 和 `12.72%`；将
罚刚度增至 `1 k_interface` 后，压力相对 L2 和最大逐点误差反而变为
`11.44%` 和 `17.59%`。更低罚刚度配合更紧非线性容差时，MOOSE 在重复增广
更新中达到最大非线性迭代数。问题类替换为推荐的
`AugmentedLagrangianContactFEProblem` 也没有改变结果。该诊断说明当前外部
实现的节点压力不能作为稳定的逐节点乘子预言值；因此本项只声称对高罚刚度
离散约束极限的物理解、事务完整性和受限两体条件数代理通过，不外推为与
MOOSE 原生增广乘子逐节点等价，也不证明任意网格和任意接触路径收敛。

## M5.5 并行影子自由度收集

PETSc 残量和 Jacobian 回调不再用 `VecScatterCreateToAll` 把完整 Newton
试探态复制到每个进程。工作区构造时，每个进程从其连续且唯一的贡献区间逐项
读取 `contribution_dofs`，排序去重后建立全局索引到顺序影子向量的 scatter。
回调中的 `GlobalStateView` 只允许访问该集合，局部 12 自由度状态通过全局索引
查找取得；访问未声明依赖会立即报错，不能静默读取零值。

完整主面链接触搜索比单个接触候选贡献需要更多状态。若某个进程负责同一
secondary 节点的任一候选贡献，它的影子集合会显式扩展到该节点在完整 primary
链上的全部候选 `contribution_dofs`。该进程随后只为自己涉及的 secondary
节点选择唯一最近段并检查失投影；不同进程上的物理域错误仍通过集合通信同步。
这样候选贡献仍各自只装配一次，跨进程切开的候选组也不会因缺少远端段而改变
动态搜索结果。

Dirichlet 约束只把本进程拥有的约束自由度加入影子集合。状态无关残量目前仅在
根进程形成；生产稳态和瞬态实现的该项为空。非线性求解结束后仍执行一次完整
状态收集，以保持现有 committed/trial/commit/rollback、材料历史和输出事务；
删除的是每次残量和 Jacobian 回调的完整收集，不是这一阶段性最终收集。网格、
问题几何、committed 节点状态和材料历史仍在各进程复制，因此本里程碑不是
分布式网格或完全分布式历史存储。

自动验收先用单进程生成参考，再用双进程逐自由度比较稳态接触解、完整主面链
大滑移解，以及瞬态节点态、物理时间、载荷、全部积分点历史和 committed
应力。稳态测试还断言双进程影子自由度总数严格小于旧方案的两份完整状态，
远程影子数大于零，并保留原有无重叠贡献区间检查。12 自由度单单元瞬态算例
的两个进程都因各自边界/体贡献实际需要完整单元状态，所以它只用于历史等价，
不被用来声称状态缩减。

工程规模测量使用 23,010 自由度、20 步 M1 基准，两个进程固定在 CPU 0 和 1，
所有线程环境变量均为 1。旧全量方案每个进程收集 23,010 个值；新方案单进程
最大影子为 12,290 个自由度，两进程合计 23,600 个影子槽，而两份完整状态为
46,020 个槽，减少 `48.72%`。每次回调实际需要远程传输 8,088 个 double，
即 64,704 字节；旧双进程全量收集需要 23,010 个 double，即 184,080 字节，
远程值载荷减少 `64.85%`。

最大进程的持久回调工作区包含两个 double 缓冲区和一组 32 位全局索引，共
245,800 字节；旧方案的两个完整 double 缓冲区为 368,160 字节，按明确计入的
数组下降 `33.24%`。这些数值不包含分配器、PETSc scatter 元数据、矩阵、直接
分解、复制网格或材料历史，不能解释为进程常驻内存降幅。首次/预热内部载荷
路径时间分别为单进程 `27.9611/27.9525 s`、双进程
`10.5659/10.4864 s`；它们不是与修改前提交的配对计时，因此只记录当前运行，
不用于声称性能加速。

## M5.6 工程规模迭代求解验证

手工 M1 基准现在接受 `medium|large` 网格、四种线性求解组合、载荷步数和
是否启用自动分场残量缩放。中等网格沿用 100 个燃料径向单元、16 个包壳
径向单元和 64 个轴向单元，共 23,010 个自由度；较大网格将两侧径向单元
加倍而保持 64 个轴向单元，共 45,630 个自由度。该次测量保持 64 个轴向单元，
所以只比较径向规模变化；它没有提供轴向加密性能或收敛结论。热接触现在允许
同一 secondary 分片的不同积分点在当前构形选择不同 primary 线段，这不再构成
输入限制。

受控测量使用 Release 构建、两个 MPI 进程和 CPU 0、1；OpenMP、OpenBLAS、
MKL 与 NumExpr 线程数均为 1。直接分解使用 MUMPS，迭代组合使用 GMRES。
完整 20 步的首次和预热内部载荷路径结果为：

| 自由度 | 预条件器 | 完成步 | 非线性/线性迭代 | 首次 | 预热 |
| ---: | --- | --- | ---: | ---: | ---: |
| 23,010 | MUMPS 直接分解 | 20/20 | 62/62 | 10.1111 s | 10.0455 s |
| 23,010 | HYPRE | 20/20 | 84/7,010 | 88.0817 s | 87.6334 s |
| 45,630 | MUMPS 直接分解 | 20/20 | 62/62 | 21.2375 s | 21.3292 s |
| 45,630 | HYPRE | 20/20 | 77/2,960 | 85.9042 s | 84.4195 s |

四组末步总残量为 `2.85e-9–3.57e-9`，并通过现有总残量与温度、径向、轴向
分场残量复核。按预热结果，HYPRE 在两个网格上分别耗费直接分解的
`8.72` 倍和 `3.96` 倍时间。径向加密后 HYPRE 线性迭代反而从 7,010 次降到
2,960 次，所以这两个点既不能证明迭代数随规模单调，也不能作为一般强缩放
结论。

23,010 自由度的两步筛查还覆盖块 Jacobi 与乘法场分裂。未缩放时，两者在
第一个载荷步分别累计 1,551 和 2,600 次线性迭代后失败，末次残量为
`0.7590/0.6848`；开启自动分场残量缩放后仍分别在 1,270 和 1,927 次后失败，
末次残量为 `0.9057/0.9058`。HYPRE 的缩放两步筛查从 557 次降到 435 次线性
迭代，但完整 20 步只完成 13 步，末次缩放残量为 `1.41`。因此短筛查改善没有
被写成完整路径建议。

默认 1,584 自由度直接求解还与修改前提交 `9238355` 做了三组同机配对。首轮
基线/候选为 `0.868126/0.878489 s`；后两轮预热中位数为
`0.875107/0.874524 s`，候选快 `0.067%`，远小于单次波动。两者都使用
62 次非线性和 62 次线性迭代，末步残量同为 `7.683024548830e-9`，接触合力
也相同，因此这里只判断默认直接路径没有实质性能或数值回归，不声称加速。

相同 23,010 自由度网格、物理、20 步和单进程直接求解的 MOOSE 运行关闭
CSV、Exodus 和控制台输出，首轮/预热墙钟为 `47.02/46.13 s`。用同一个
`/usr/bin/time` 口径测得 fuelsim 预热墙钟为 `27.04 s`，少 `41.4%`，即
MOOSE/fuelsim 为 `1.71`。这个跨程序比较没有把双进程迭代表与单进程 MOOSE
混在一起。

工程筛查还独立复现了场分裂工作区复用缺陷。原实现每次 `solve` 都向同一个
PETSc 场分裂预条件器重新加入同名温度和力学索引集；23,010 自由度的失败回退
路径会在重复配置后段错误。现在先检查预条件器是否已经是场分裂类型，只在
首次配置时创建索引集。双进程自动回归把同一稳态问题改为两个载荷步，并断言
只构造一个 PETSc 工作区、最终解与单进程直接参考逐自由度一致。工程规模
筛查随后不再崩溃，而是以明确的线性不收敛结果退出。

验证矩阵将本项列为 `measured`，因为大网格计时不属于每次 CTest，也没有
证明任意网格、材料、接触状态或载荷路径上的迭代收敛。当前证据支持在这两个
规模上优先使用直接分解；HYPRE 只说明当前未缩放设置能够完成这两个具体
工况，不说明它比直接分解更快或更节省总内存。完整命令和计时口径记录在
`benchmarks/README.md`。

## M5.7 瞬态有限应变综合例题

完整手工基准把此前分别验证的物理过程放入同一条 6 秒路径。网格包含 150 个节点和
104 个 Quad4 单元：燃料为 6×8，轴向范围为 0 至 5 mm；包壳为 2×28，轴向
范围为 -1 至 6 mm。初始径向间隙为 1 um，两个区域均采用有限应变。包壳底部
位于接触区下方 1 mm，其轴向位移固定为零，避免把固定端和接触端点叠在同一
位置。燃料顶面按分段线性函数平移至 0.6 mm，使接触节点沿当前包壳内表面
跨越多个线段。燃料体积热源、包壳内压和外压分别由独立时间函数控制，基值
依次为 `2e7 W/m3`、`5e5 Pa` 和 `2e6 Pa`。

界面同时启用气隙导热、法向罚接触和 Coulomb 摩擦。fuelsim 使用
`1e12 Pa/m` 法向及切向罚刚度和 `mu=0.002`；包壳使用 J2 线性硬化塑性与
Norton 蠕变的全隐式耦合。热接触积分点在当前构形沿完整 primary 链动态选择
唯一所有线段，使 0.6 mm 滑移中的热源位置随界面运动。完整 6 秒输入卡仍用于
一、二、四进程手工等价性基准。默认 CTest 使用独立输入卡，把相同分段载荷历程
压缩到 1 秒，但保持相同最终热源、压力和 0.6 mm 滑移；它仍使用历史感知的
Backward Euler 时间步加倍误差估计。一个进程运行接受 18 个变化时间步，未拒绝
时间步，最小和最大接受步长为 `0.03125 s` 和 `0.0625 s`，最大归一化误差估计
为 `0.0153718`，并复用一个 PETSc 工作区。RZ 两级窄播种本构自动微分只改变
单元 Jacobian 的浮点求和顺序；少量非线性迭代次数因此跨过基于迭代次数的步长
控制阈值，把单进程接受路径从 26 步调整为 18 步，MOOSE 参考已按新路径的半步
序列重生成。最终 9 个接触节点全部激活并处于滑移状态，全部跨越至少两个
primary 线段；界面热率为 `1.54089 W`，切向合力
为 `0.311120 N`，热接触离散守恒，包壳塑性和蠕变均为非零。

CTest 的 MOOSE 参考使用相同 Quad4 几何、材料、压缩后的载荷函数和最终时间，
机械接触采用传统节点到线段罚接触，不使用 mortar 接触。法向和粘着切向罚刚度
均为 `1e12 Pa/m`，摩擦系数为 `0.002`，`ContactSlipDamper` 将单次非线性迭代的
切向滑移限制为 2 um。内外压力由径向和轴向两个 `ADPressure` 对象共同施加完整
当前法向。MOOSE 时间序列逐项匹配 fuelsim 18 个接受步所保留的两个半步更新。

节点温度、径向位移、轴向位移和接触压力均逐节点配对。三项误差最大值依次为
`0.003273%`、`0.206719%`、`0.012547%` 和 `0.010183%`。224 个包壳积分点按坐标
逐点配对；等效应力、等效塑性应变和等效蠕变应变的三项误差最大值分别为
`0.073094%`、`0.013225%` 和 `0.148170%`。平均等效塑性应变、平均等效蠕变应变和
平均等效应力相对误差为 `0.007576%`、`0.003102%` 和 `0.006992%`。测试没有给
分母添加下限，全部三项指标仍低于 `0.5%`。

独立的 MPI 等价性 benchmark 先由一个进程生成 fuelsim 已提交状态参考，再用
两个和四个进程运行同一输入。它逐项比较物理时间、载荷因子、三个节点场、积分点
弹性/塑性/蠕变张量、两个等效历史量、应力以及摩擦滑移、法向乘子和粘滑状态，
并检查每个进程的贡献区间互不重叠、全过程只构造一个 PETSc 工作区。该小规模
等价性路径固定 OMP、OpenBLAS、MKL 和 NumExpr 为单线程，并使用分布式 MUMPS
直接求解器。两个进程保持与一个进程相同的 97 个
接受步，最大应力和塑性应变绝对差为 `0.1809917 Pa` 和 `3.72567e-12`。

四进程的分布式求和顺序会改变少量非线性迭代次数。迭代数是否跨过基于迭代
次数的步长控制阈值，会使四进程采用 97 或 98 个接受步；两条路径都没有时间
误差拒绝，最大归一化时间误差均为 `0.0147908`。以下记录较保守的 98 步终态
相对一个进程参考的温度、位移、应变历史和应力最大绝对差分别为
`3.2460e-4 K`、
`1.4632e-11 m`、`2.9492e-9` 和 `242.35 Pa`。验收门槛分别为 `1e-3 K`、
`1e-10 m`、`1e-8` 和 `1e3 Pa`；它们仍比输入中的对应绝对时间误差尺度严格
一个至四个数量级。接触滑移和法向乘子通过连续量门槛，粘滑布尔状态逐位一致。
该结果证明本算例的 1、2、4 进程终态数值一致性。进一步采用分布式 MUMPS
直接求解器、关闭场文件输出、固定处理器核心和所有数值库单线程后，首次墙钟
时间分别为 `17.54 s`、`19.99 s` 和 `18.28 s`。保持 97 个接受步的三次预热
中位数分别为 `17.23 s`、`20.04 s` 和 `18.32 s`，对应双进程和四进程加速比
为 `0.860` 和 `0.941`；也就是分别比单进程慢 `16.31%` 和 `6.33%`。四进程
另有一次 98 步预热运行耗时 `20.21 s`，没有混入等工作量中位数。

因此，这个 150 节点、104 单元的小算例没有多进程加速。分布式装配和 MUMPS
通信开销大于单元装配节省；该负结果不能外推到更大网格。为缩短默认回归时间，
这组一、二、四进程长路径不注册为 CTest，只保留手动 benchmark。计时命令、
全部样本、首次/预热口径和完整状态最大差见 `benchmarks/README.md`。

## M5.8 三维 Hex8 瞬态综合例题

本例题是 M5.7 的三维圆柱版本，并采用三向二倍加密网格作为综合性能基准。
已追踪的 Exodus 网格由实心圆柱芯块和独立环形包壳组成，包含 1,617 个独立
区域节点、1,152 个 Hex8 单元和 6,468 个温度—位移自由度。芯块半径为
`4.12 mm`、长度为 `5 mm`，截面使用 80 个四边形、轴向使用 8 层，共有
801 个节点和 640 个 Hex8 单元。包壳名义内半径为 `4.1235 mm`、外半径为
`4.692 mm`、长度为 `7 mm`，径向使用 2 层、周向使用 16 段、轴向使用
16 层，共有 816 个节点和 512 个 Hex8 单元。包壳比芯块上下各伸出
`1 mm`，两者均采用有限应变。完成周向错位后，144 个机械接触节点的最小
初始投影间隙仍为 `2.036 um`。

芯块外表面有 128 个 Quad4 面和 144 个接触节点，包壳内表面有 256 个
Quad4 面和 272 个节点。包壳网格绕圆柱轴旋转 `0.1°`，用于解除接触节点
恰好位于两个 primary 面公共棱上的退化投影；旋转不改变圆柱中心、半径或
物理加载。轴向网格非匹配，
芯块顶面施加至 `0.6 mm` 的位移，包壳顶面施加至 `20 um` 的位移。燃料体积
热源、包壳内压、外压和两项轴向位移采用相互独立的分段线性时间函数。

界面同时启用当前构形热接触、`1e10 Pa/m` 节点到面机械罚接触和 `mu=0.002`
的 Coulomb 摩擦。包壳采用 J2 线性硬化塑性与 Norton 蠕变的全隐式耦合；内外
压力均使用完整当前法向和当前表面测度。20 个 `0.05 s` Backward Euler 时间步
只构造一次 PETSc 工作区。终态 144 个接触节点全部激活，116 个处于滑移
状态，144 个节点改变过 primary 面所有权。界面热流严格离散守恒，热接触率、
法向合力、摩擦合力、塑性应变和蠕变应变均非零。

fuelsim 与一个进程、一个线程的 MOOSE 参考按 Exodus 参考坐标唯一配对节点和
单元，避免依赖两个读取器的内部编号。各量的相对 L2、相对绝对峰值和最大逐点
相对误差依次为：温度 `0.000938%`、`0.0000003%`、`0.004630%`；X 位移
`0.000416%`、`0.000482%`、`0.010724%`；Y 位移 `0.000418%`、
`0.000485%`、`0.010724%`；Z 位移 `0.000005%`、`0%`、`0.006697%`；
接触压力 `0.001933%`、`0.000646%`、`0.005130%`；等效应力 `0.000610%`、
`0.001167%`、`0.001348%`；等效塑性应变 `0.000622%`、`0.001187%`、
`0.001373%`；等效蠕变应变 `0.001009%`、`0.001185%`、`0.003621%`。
全部三项指标均低于 `0.5%`。测试不增加分母下限；圆柱轴线上理论为零的 X、Y
位移明确归入零参考点，其最大绝对差分别为 `6.98e-16 m` 和 `4.84e-16 m`。

关闭控制台和场文件输出、固定处理器 0，并把 OMP、OpenBLAS、MKL 和 NumExpr
都限制为一个线程后，先各完成一次不计入样本的完整运行。随后 fuelsim 墙钟为
`343.47 s`，MOOSE 墙钟为 `777.90 s`。本算例上 fuelsim 快 `2.2648` 倍，
墙钟时间低 `55.85%`。由于单次运行需要数分钟，这里报告的是单次预热后观测，
不是三次中位数。fuelsim 比较运行使用 75 次非线性迭代和一个 PETSc 工作区。
计时环境把 Conda MOOSE 环境的 `bin` 目录放在 `PATH` 首位，`mpicxx` 可用，
表达式即时编译成功。这只是当前 6,468 自由度、单进程直接求解算例的配对观测，
不能外推为工程规模渐近性能或并行扩展性结论。该长算例只保留手动 benchmark
可执行文件，不注册到默认 CTest；完整复现命令见 `benchmarks/README.md`。

双进程优化后，运行贡献不再按数量平分，而按 Hex8 体积分、热接触、机械接触
和面边界核的工作量选择连续分界。M5.8 的两个区间为 `[0,664)` 和
`[664,2688)`，保持唯一、无重叠和完整覆盖。三维接触稀疏图只为每个
secondary 面—primary 面组合保留一个 32 自由度代表；四个热积分点和四个机械
面节点的运行贡献仍全部存在，只是不再重复声明完全相同的预分配块。局部
Jacobian 向 PETSc 装配时省略结构性全零行列，但完整候选图和动态接触搜索不变。

相同 MUMPS 直接分解器、固定处理器和单线程数值库下，正式入口各测量三次。
单进程墙钟为 `104.37/104.03/103.83 s`，双进程为 `64.43/64.87/65.40 s`；
中位数分别为 `104.03 s` 和 `64.87 s`，加速比 `1.6037`，双核并行效率
`80.1834%`。双进程完整 MOOSE 对标仍通过全部 `0.5%` 三指标门槛，内部求解
时间为 `59.434407 s`，首次设置为 `1.716526 s`。该结果只证明当前 M5.8
网格、20 步路径、两进程和当前硬件上的强扩展，不外推到更多进程或其他网格。

四进程优化保持 MUMPS 直接分解，不改用迭代预条件器。单进程也明确选择 MUMPS，
因此比较两端使用相同分解器和 SCOTCH 排序；内部 PETSc 自由度改为节点优先，
公共解和检查点仍保持场优先。精确局部 Jacobian 图省略结构性全零块，四个连续
贡献区间为 `[0,346)`、`[346,692)`、`[692,1038)` 和 `[1038,2688)`。
三次完整 MOOSE 对标的一进程内部总求解时间为
`73.479816/73.504522/73.741511 s`，四进程为
`24.965830/25.082956/24.926659 s`；中位数加速比为 `2.944205`，四核求解阶段
效率为 `73.6051%`，超过 `70%` 目标。纯非线性求解阶段中位数效率为
`75.6576%`。

相应生产进程墙钟中位数为一进程 `77.86 s`、四进程 `30.29 s`，端到端效率
为 `64.2621%`；Exodus 读取和每个进程复制的问题构造不在内部求解计时中，因此
这一固定开销单独报告，不声称端到端效率超过 `70%`。四进程相对一进程的最大
温度差为 `4.43e-10 K`，最大位移差为 `2.52e-12 m`，最大容差占用比为
`0.02491`；全部 MOOSE 三指标门槛继续通过。
