# 空间后端与状态所有权重构

## 基线与迁移边界

本次基线为 `417cead3c16528acae3f55cefdde67119a88e097` 加任务开始时的工作区修改。
原有修改包括分区提交、三维接触、求解器与单元计算的改动，必须保留。
构建使用独立的 `build-spatial-refactor`，测试不重新生成外部程序参考。

公开的 `SteadyProblem`、`TransientProblem` 和 `NonlinearProblem` 保持原契约。
私有 `SpatialBackend` 隔离贡献映射、稀疏结构、影子自由度、合法性检查、局部求值、
控制更新和后端状态事务。Cartesian 后端继续承载 HEX8/HEX20，纯热后端继续承载
四种纯热单元。虚调用发生在贡献边界，不进入材料点循环。

实际调用关系为 `SteadyProblem/TransientProblem → SpatialProblemStorage → SpatialBackend
→ ThermalBackend/RadialBackend/Rz4Backend/Rz8Backend/PlaneBackend/CartesianBackend → SpatialAssembly`。
`spatial_backend.hpp` 只声明通用协议和时间状态；`spatial_backends.hpp` 集中声明私有具体
后端及原有只读视图。六个实现文件保留各自局部求值、材料更新、蠕变率查询和区域统计。
`spatial_backend_common.*` 保留真正共用的诊断合并、分区同步与张量统计助手。

## 状态所有权

通用存储唯一拥有已接受节点解、前一接受节点解、时间、载荷、活动时间步参数和
守恒诊断结果。具体后端拥有本类型的材料历史与待提交缓冲；接触历史仍由其装配
对象拥有，后端协调材料和接触更新。纯热后端没有机械材料历史。

求解器提供的局部贡献向量仅按该贡献的自由度映射读取。已接受节点解是完整的
全局向量；分区求解器的影子状态只包含 `required_state_dofs` 声明的依赖，不能
用于遍历整个问题的提交和输出。残量与切线求值不发布任何已接受状态。

提交先准备材料、接触和诊断，完成原有分区同步与验证后再发布。快照拥有其数据，
通过问题身份拒绝其他实例的恢复请求。`TransientCommittedState` 继续作为检查点
和快照的数据传输结构，不能作为所有后端的运行时材料容器。

具体后端通过只读引用使用通用时间状态；持有该状态的存储不可移动，避免引用失效。
材料历史的已接受容器与待提交容器均由相应后端持有。后端还持有待提交接触解、接触
历史和活动时间步的增广乘子恢复数据。残量求值只借用已接受数据，不复制全局解。

四种持有机械接触历史的装配路径增加 `prepare_contact_state` 与 `publish_contact_state`。
前者沿用原接触计算循环，后者只交换已经准备好的容器。原 `commit_contact_state`
仍供稳态提交和内部调用使用，复用同一准备与发布实现，没有第二套接触公式。
瞬态的 `prepare_time_step` 先准备材料和接触，再将失败标记与原诊断、材料数据放入
原有一次分区同步。全部成功后通过不抛异常的容器交换发布接触、材料、节点和诊断。
求解器的分区提交接口与归约缓冲区顺序不变。

不同后端的储热、机械功、耗散、活跃材料点与构形测度保持原算法和遍历顺序。
共同的节点反力合并可以共用，名称相似的积分公式不能据此统一。

## 私有访问和兼容性

`BackendAccess` 保留输出、检查点和内部测试需要的具体只读视图；具体类型识别
集中在这个边界。求解器不接触后端材料历史类型。检查点继续使用版本 22、原字段
顺序及物理模型签名；后端类名、地址与文件路径不参与签名。

固定元数据与动态接触保持各自的缓存、分区和候选集合。普通时间、载荷和 Newton
更新不改变 `discretization_identity`。本轮不改变 MPI 数据分布。

纯热与一维轴对称继续报告固定贡献元数据；其他路径继续以是否存在接触决定缓存
策略。三维路径继续使用其专用贡献分区和状态相关稀疏结构，其余路径保留原区间
划分。一维轴对称仍拒绝分区提交。求解器继续根据 `required_state_dofs` 收集所需
影子自由度，没有改成收集完整全局状态。四节点轴对称的固定数组只在具体后端内
转换，通用接口仍支持可变大小贡献。

具体只读视图使用检查类型的转换；不匹配的访问会拒绝，不再解引用空后端指针。
为允许这种明确失败，私有 `BackendAccess` 的视图函数不再声明 `noexcept`。
公开问题构造函数、`NonlinearProblem`、输入输出字段和检查点序列化均未因此改变。

## 未来组合位置

当前后端抽象隔离整问题实现，不代表已经支持混合拓扑或代理模型。未来芯块代理
贡献、实体包壳贡献及界面贡献应在区域算子或组合装配层共同实现可变大小的
`contribution_dofs`、局部残量和 Jacobian，以及稀疏模式、分区和影子自由度协议。
PETSc 仍接收同一个全局残量与矩阵。未来还需实现共享自由度布局、界面物理、
代理状态的提交恢复及候选耦合结构；本轮不预建空模型类或注册系统。

## 事务可靠性收尾（2026-09-19）

本轮基线是已提交的 `640644f`，不是上一轮未提交工作区。基线使用独立的
`build-transaction-hardening`，实际 430 项测试全部通过。下文更新此前“原有一次
分区同步”的协议描述，保留上面的历史验收记录。本轮没有改变物理公式、单元或
接触离散、外部参考、检查点版本及序列化顺序。

分区提交分为本地准备、失败一致确认、成功同步与发布三个阶段。节点合法性检查、
诊断向量和已接受节点解的复制、后端材料及接触准备、材料点指针列表构造、通信
缓冲区分配与填充都在同一个外层异常捕获范围内。后端内部已捕获的错误继续通过
原有两个失败标记传递。准备完成的进程在数据交换入口先归约这两个标记；更早失败
的进程直接参加同一次归约，无须分配材料或诊断通信缓冲区。用于确认失败的两个
`double` 在问题构造时分配，失败分类和 `exception_ptr` 保存不分配字符串。

任何进程报告准备失败时，所有进程一起抛出域错误或运行错误，不再进入数据交换。
只有所有进程准备成功，才进行原有历史和诊断数据归约。交换之后的守恒诊断仍可能
分配约束标记向量，因此在发布前再进行一次失败一致确认。成功路径共三次归约，
准备失败路径只有一次；这增加了两次小型状态归约，没有增加完整节点场、材料历史
或接触历史的深复制。四节点轴对称和三维材料缓冲继续在构造时分配；径向、八节点
轴对称和平面后端保留原有每步 `_staged = _histories`，第一次准备分配容量，之后
依赖标准容器容量复用。本轮没有引入分配器或新的历史仓库。原有通信数据缓冲仍
按步构造；新增两个数值的确认缓冲按问题复用。通信包装的 `std::function` 在当前
实现中可能增加一次小型目标对象分配，但也在失败捕获范围内；没有执行分配次数
检测，不能把未增加大容器复制等同于零新增分配。

最后一次确认成功后，接触、材料、节点和残量容器只执行标准容器 `swap`，守恒量、
时间和载荷只作标量赋值，活动状态清理只销毁普通数值容器。这些发布操作不抛出
C++ 异常，也不重新计算物理量。失败时已接受数据不发布，活动时间步仍允许调用
原有回滚。增广接触仍通过活动步快照恢复乘子；本轮没有改变其迭代算法。
通信回调本身必须直接进入 collective（所有参与进程共同调用的通信操作），不能
先执行可能失败的应用层分配。进程被操作系统终止、MPI 通信器失效或回调违反该
契约不属于可由此应用层事务恢复的故障。

`fuelsim_mpi_transaction_prepare_failure` 真正由 `mpiexec -n 2` 启动，超时为 90 秒。
它复用完整 B5.23 有限滑移、摩擦、塑性和蠕变输入，先正常推进到 0.2 秒，再只在
rank 1 注入节点准备、材料准备、接触准备、通信缓冲准备、最终诊断或非法节点
布局故障。材料和接触故障点位于真实准备完成之后。分配失败由私有测试钩子抛出
`std::bad_alloc` 模拟，不是耗尽机器内存；钩子没有生产输入选项。
每个场景检查两个进程都失败、通信次数符合协议、回滚前后的完整已接受检查点
逐字节不变，并重新求解、提交，与无故障续算逐字节比较。检查点写入器禁止活动步
写入，因此测试把已接受数据导出到独立的非活动问题来检查回滚前内容，不修改被测
问题。原有单进程分区模拟、贡献唯一归属、影子自由度及多进程等价测试全部保留。

时间误差现在通过私有 `SpatialBackend::accumulate_time_error` 分派。公共层只负责
节点场和结果合并；纯热后端不增加历史项。径向、四节点轴对称和八节点轴对称沿用
原有活跃材料点与接触误差计算顺序；平面和三维后端负责自己的笛卡尔材料历史。
三维新增比较全局坐标中的弹性切向滑移和累计切向滑移，使用已有位移绝对容差；
法向乘子使用应力历史绝对容差。滑动状态或基底初始化标记不一致时，接触误差直接
为无穷大，要求拒绝这个时间步、缩小步长重试。

接触方向来自当前面参数切向和有主从定义的法向；有限滑移用保存的旧基底分解历史，
再在当前基底中客观转运。不同面参数定向不能被当作全局唯一的切向符号。误差比较
保留有向法向，并用 `t ⊗ t` 比较第一切向的直线方向，因而 `t` 与 `-t` 的符号
翻转不产生伪误差。滑移已经是全局向量，直接比较，不再按局部坐标分量比较。
方向量无量纲，使用现有应变历史绝对容差和相对容差归一化，与滑移误差取最大值；
不把方向差与以米计量的滑移放进同一个范数。未初始化的方向数组不参与连续量比较。
本轮只改变误差度量，不改变接触基底构造、历史转运或提交的任何公式。

`fuelsim_cartesian_contact_time_error` 检查相同历史、两种滑移、乘子、滑动标记、
初始化标记、有向法向、切向转动与等价符号翻转，并从同一真实已加载状态执行
整步和两个半步。它是内部状态契约测试，复用原有完整输入，不生成或改写输入卡。
时间步 0.04、0.02、0.01 秒的接触误差分别为 2.221416753、1.015909215、
0.225377255；总误差分别为 23.795691846、6.756795071、2.095662681。
因此接触项随细化降到一以下，但最细步的材料等其他项仍可能要求继续细化。
这个例题是罚函数接触，真实乘子误差为零；非零乘子差异由同一真实历史布局的
快照测试单独验证，不能将其表述为新增三维增广接触能力。
