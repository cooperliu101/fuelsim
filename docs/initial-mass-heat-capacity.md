# 初始质量热容实验及回退

> 本文保留先前实验与回退历史。当前已按用户要求重新采用固定初始质量热容，并增加加速度体力入口，见[当前规则](density-mass-and-gravity.md)。下文“当前”均指本历史记录形成时的版本。

2026-09-13 已按用户允许的范围回退固定初始质量热容。当前生产实现恢复各型号
经过 Abaqus 2018 原生算例识别的热容规则：小应变使用参考构形，有限应变使用
当前构形的对应节点权重或一致积分，密度和比热在当前温度、当前时间及参考
位置求值。热容的温度导数和有限变形几何导数均保留。

```text
R_capacity_i = integral_current(N_i * rho(T) * cp(T) * (T_new-T_old)/dt dV_current)
```

这里的积分按各单元原有离散规则计算，详见[理论说明](theory.md)。密度填写
常数时，上式不会自动把该值更新成 `rho_initial/J`，不能宣称热容中的质量
随体积变化保持不变。综合输入仍保留用户要求的初始单值密度，没有重新加入
密度温度表；B5.44 为 2000 kg/m³，初温 300 K。

回退依据来自相同编译器和依赖的历史版本复算。仅恢复旧热容并保持 B5.44
初始常密度，节点 16 在 400000 s 的热反力误差从 1.768725% 降为 0.021392%。
但位移最大逐点误差仍约 0.699%，说明该力学差异需要独立处理。
完整复算数据见[回退对照](../verification/abaqus/b544_diagnosis/rollback_comparison.md)。

回退同时恢复原生热反力比较，删除固定质量的派生参考转换、专用自动检查器
和只服务该语义的材料接口。保留三维当前体积热源统计修复、正确的二次单元
积分规则以及新鉴定的 C3D8RT 体内力修正。检查点版本升至 21，拒绝版本 20，
避免读取采用固定初始质量热容的旧求解状态。

提交 `f0afa00` 中的固定质量实验、解析测试和
[储热结果表](../verification/initial_mass_heat_capacity_results.tsv)作为历史记录保留。
其结果只证明当时实现满足参考质量积分，不代表当前生产规则，也不能代替
Abaqus 原生全场验收。相关历史运行记录中的“全部通过”还受后来发现的节点
热反力比较器漏检影响，不能沿用为当前资格。

当前 B5.44 的实际误差及完整验收见
[初始密度验证报告](../verification/abaqus/b544_initial_density_validation.md)。
