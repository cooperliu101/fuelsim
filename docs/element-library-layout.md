# elements 按单元类型组织

本次重构以 `5f587e3` 为基线，覆盖整个单元库、生产调用方、测试与构建配置。
原先按几何、运动学、装配、诊断拆分的 `src/detail` 已取消。

八种体单元分别拥有型号头文件、实现和测试。轴对称与三维共用计算分别集中在
`cax_common` 与 `c3d_common`，单型号辅助函数留在本型号实现中。同一界面类型
的边界与接触合并为 `line2_rz`、`line3_rz`、`quad4_face`、`quad8_face`。
轴对称与三维材料计算集中在 `material.cpp`，材料函数仍由 `material_functions`
维护。共用范围决定函数归属，不要求各型号共用相同数量的函数。

公共坐标并入 `element_types.hpp`；轴对称、三维材料类型并入 `material_types.hpp`；
接触面积规则并入 `contact_types.hpp`；界面专用参数随对应界面维护。没有保留
旧头文件转发层或旧接口别名。四个家族的类型头文件仅包含数据定义；几何构造
与主体使用的三维逐点变形检查由型号头文件提供，共用实现声明保持私有。
仅由一个实现文件使用的 CAX8 积分点评估放在匿名命名空间中。

C3D8 原独立诊断入口及其结构删除。生产能量统计使用正常历史更新返回的新旧
体积与增量转动，不额外执行诊断调用。试探历史仍由主体统一接受或丢弃。
验证使用的几何和热场重建迁入测试支持，采用独立的普通双精度实现；体积、转动、
输入不变性与非法构形检查直接约束正常单元结果。

专用测试移至对应型号文件，界面检查移至对应界面测试；共用函数按实际调用方
保留。CAX8 两个型号原先重复执行的同一二次边界检查改为单独执行一次，没有
删除其中的断言。验证矩阵同步更新测试归属和源码路径，参考数据与误差门槛不变。

完整目录和调用约定见 [单元库说明](../elements/README.md)。

## 验证结果

最终主体构建成功，统一入口 `ctest --test-dir build -j4 --output-on-failure`
通过 281/281 项测试。单元库独立构建成功，13/13 项测试通过。原有测试按型号和
界面重新分配后，按内容核对的 104 行局部数值指标与重构前逐字一致；该比较只
覆盖已有测试状态和打印精度，不代表所有输入逐位一致。

22 个公共头文件和 3 个私有头文件均通过仅提供单元库与 ADlite 包含目录的
C++17 单独包含编译检查。临时副本中的五类违规被源码检查正确拒绝：恢复
`detail` 目录、跨型号调用、公共接口引用私有头文件、生产代码引用测试支持，
以及轴对称界面包含三维表面接口。

`elements` 文件总数从 97 减少到 62：公共头文件从 30 减少到 22，生产实现及
私有头文件从 46 减少到 19；测试按八种体单元与四种界面组织。未修改物理输入卡、
外部参考数据或误差门槛；外部对标使用已有参考，没有重新运行 Abaqus/MOOSE，
也没有进行性能提升评估。
