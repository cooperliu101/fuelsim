# 工程验证矩阵与适用边界

fuelsim 的“已验证”只表示仓库中存在可重复执行的测试、明确的判据和追踪的
证据文件，不表示完成核安全软件鉴定。机器可读的唯一索引是
`verification/verification_matrix.tsv`，`fuelsim_verification_matrix_tests`
会检查矩阵模式、必需能力行、CTest 名称以及每个证据文件是否存在且非空。
坐标、弱式、材料、接触、时间事务和求解器结构的统一说明见
[`docs/theory.md`](theory.md)；本文件继续作为证据等级、实际门槛和适用边界
的发布说明。

## 轴对称 Abaqus 首要参考

轴对称 B7.0—B7.9 采用 Abaqus CAX4T 四节点温度—位移耦合单元，覆盖小应变、
有限应变、热机械接触、蠕变、塑性以及蠕变与塑性同时作用。十个轻量算例均通过
实际生产程序执行，所有已定义的非零场三项相对误差必须小于 0.5%。节点场、
积分点张量和历史变量按全部接受时间点比较；接触另检查压力、间隙、逐节点法向力、
总法向力及传热量。原有 MOOSE 特殊加载和非共轴历史作为补充覆盖保留。
具体指标、零参考量规则及有限应变适用边界见
[轴对称 Abaqus 验证记录](../verification/abaqus/b7_rz_validation.md)。

B8.0 和 B8.1 增加可变形非匹配环形网格上的摩擦验证，分别覆盖小应变和有限应变，
要求正向滑动、反向运动后重新粘着和反向滑动。B8.1 还要求接触节点跨越至少两条
primary 线段。全部接受时间点的材料场、支承反力、压力、间隙、切向牵引、累计滑移、
接触力向量和合力使用同一个 0.5% 门槛，见
[轴对称摩擦与有限滑移验证记录](../verification/abaqus/b8_rz_friction_validation.md)。

CAX4RT 的十六个生产算例覆盖 CAX4T 已有的小应变、有限应变、热机械接触、
蠕变、塑性及两者同时作用，并覆盖摩擦、大滑移与检查点历史。额外的热算子算例
检查非均匀温度、毫米尺度、倾斜单元和局部节点顺序。所有比较继续使用严格的
0.5% 三项相对误差门槛，详见 [CAX4RT 验证记录](../verification/abaqus/b9_cax4rt_validation.md)。

## 证据等级

- `verified`：有自动 CTest，并且验收判据和参考文件均进入 Git；
- `qualified`：有自动 CTest，但某项门槛尚未达到项目目标；必须明确记录例外，
  不能写成完全验证；
- `measured`：按受控环境运行的性能观测，不作为每次 CTest，也不外推为缩放
  结论；
- `limitation`：明确未实现或未鉴定的边界，是发布证据的一部分，不能省略。

任何门槛放宽或 `verified -> qualified` 变更都必须先定位物理、离散或参考量
口径原因，并同时记录实际误差、绝对差和适用边界；原因未明时不得用放宽门槛
掩盖回归。

所有 fuelsim-to-MOOSE 全场误差使用相对 L2、相对绝对峰值和最大逐点相对
误差。参考值为零的点不构造相对误差，而是另外报告数量和最大绝对差。矩阵中
M0、M1 和 M3.3 的门槛为 `1%`；M2.1、M2.2 和 M3.1 的门槛为 `0.1%`。
M2.3 已改用与 fuelsim secondary-side STS 弱式一致的 MOOSE mortar gap heat
transfer 参考，并把验证屈服点移离分支切换面。全部节点温度/位移、接触压力、
总接触力、平均状态以及 40 个积分点的等效应力、塑性和蠕变应变现在统一使用
`0.1%` 门槛；当前最差项是积分点塑性应变最大逐点相对误差 `0.086612%`。
具体实际数值由对应 CTest 输出，不能只凭构建成功宣称通过。

## Abaqus C3D8T 新算例契约

`verification/abaqus/c3d8t_validation_contract.tsv` 逐项登记所有已注册的
Abaqus C3D8T 测试，并由 `fuelsim_verification_matrix_tests` 与 CTest 注册表
交叉检查。现有的算子识别和存量路径保留明确的适用边界；以后新增的 C3D8T
算例不能再登记为这种范围受限的测试。

每个新增的非接触算例必须比较所有接受时间点，而不是只比较终态。节点量必须
包括温度、三个位移、热反力和三方向机械反力；每个积分点必须包括三方向热流、
六分量应力、六分量张量应变和所有活跃历史变量。接触算例还必须逐接触输出位置
比较开度、压力、两个滑移分量和接触力，并比较界面合力、力矩和力心。基础热力
和材料路径使用 `0.1%` 门槛，综合有限应变路径可使用 `0.5%`；接触量只有在
离散差异已经定位并把实际误差及适用边界写入证据后，才能采用更高的 qualified
限定门槛。所有场继续使用相对 L2、相对绝对峰值和最大逐点相对误差。参考值为
零的点只报告数量和相同物理单位下的最大绝对差，不增加分母下限。

B5.5、B5.8 和 B5.9 已满足上述非接触完整场契约。B5.10 至 B5.18 已覆盖所有
接受时间点、完整节点场、应力、应变和活跃材料历史，但其现有 Abaqus 积分点
文件没有导出空间均匀温度路径的热流，因此仍被登记为存量材料路径，而不是新的
完整场模板。B5.21 和 B5.22 也没有覆盖双向滑移、力矩及力心，不能作为未来
完整接触算例的替代证据。B5.23 是新增的完整接触路径：它保存全部二十个接受
时刻的完整节点场、积分点热流与本构历史、接触场和综合能量量。验收只使用两套
程序中离散含义一致的完整矢量、积分点历史、接触合力、合力矩和力心；这些量的
相对 L2、相对绝对峰值和最大逐点相对误差均满足既定门槛。Abaqus 专有恢复的
节点接触量、积分点热流和摩擦耗散继续输出，但不冒充同一离散量。

## 统一回归验收

CTest 只保留一个轻量套件。B5.24 和 B5.25 参数扫描以及 B5.27 的网格、时间步和
罚刚度扫描保留为手动验证资料，不再重复注册为自动测试；B5.27 中等网格继续提供
工程尺度全场对标。规定环境中的候选提交执行：

```bash
fuelsim_toolchain_prefix="${CONDA_PREFIX}"
fuelsim_dependency_root="$(cd .. && pwd)/fuelsim-dependencies"

env \
  PATH="${fuelsim_toolchain_prefix}/bin:/usr/local/bin:/usr/bin:/bin" \
  PKG_CONFIG_PATH="${fuelsim_toolchain_prefix}/lib/pkgconfig" \
  cmake -S . -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_COMPILER="${fuelsim_toolchain_prefix}/bin/c++" \
  -DCMAKE_PREFIX_PATH="${fuelsim_dependency_root}/adlite-0.2.1" \
  -DSEACASExodus_DIR="${fuelsim_dependency_root}/exodus-2024-06-27/lib/cmake/SEACASExodus" \
  -DFUELSIM_WARNINGS_AS_ERRORS=ON
cmake --build build --parallel 4
ctest --test-dir build -j4 --output-on-failure
```

CTest 为每个用例固定 OpenMP、OpenBLAS、MKL 和 NumExpr 各为一个线程；这会传递给
每个 MPI 进程，避免小规模回归算例因每个进程创建整机大小的 OpenMP 线程组而变慢。
即使调用者使用 `ctest -j`，两个 MPI 进程的用例也会彼此串行；这只约束测试资源，
不改变生产程序的线程设置。性能测量仍必须显式固定 CPU 和全部线程环境变量。

固定依赖的首次安装、检测器配置和持续集成执行器变量见
`docs/reproducible-build.md`。

涉及性能的候选还必须按 `benchmarks/README.md` 固定 CPU 和全部线程环境变量，
完成 1,584 DOF 配对计时以及 23,010 DOF、20 步工况。MPI 沙盒初始化失败需在
沙盒外复现；不能跳过并行测试后仍声明发布验收通过。

## 当前工程适用边界

当前版本是燃料棒性能分析的基础有限元求解器，适合继续承载经过独立验证的
物理模型，但不是完整的燃料性能产品。边界包括：

- 支持 2D 轴对称 RZ Quad4 和 3D 笛卡尔 HEX8 体单元；两种区域均可选小应变或
  MOOSE 默认增量 Taylor 有限应变。轴对称接触使用 Line2 边，三维接触使用
  Quad4 面；两者均支持热接触、机械罚接触和 Coulomb 摩擦；
- 材料只有线性温度斜率热弹性、通用 J2 线性硬化塑性、Norton 蠕变及其
  全隐式耦合；斜率采用 AD 活跃求值，但尚无 UO2/包壳温度、燃耗、辐照
  相关的工程关联；
- 当前有限应变塑性—蠕变采用 MOOSE 默认 Taylor 分解和开启的历史客观旋转；
  局部旋转测试覆盖弹性、塑性和蠕变张量，M4.1 覆盖近共轴 PCMI，M4.2
  覆盖有限应变 follower pressure，M4.3 覆盖畸变 4 单元、100 步、约
  `25.5°` 的非共轴反向路径，以及并存的当前构形压力/分量牵引。任意转角、
  任意路径和一般网格仍未鉴定；当前分量牵引方向固定为全局 R 或 Z，不是
  随法向转动的任意矢量 follower law；
- 瞬态有限应变按 committed 构形增量更新；稳态有限应变没有材料历史，每个
  延续载荷步都从 `F_old=I` 对总变形做一次 Taylor 更新，不适用于主方向随
  稳态载荷步旋转的路径依赖材料问题；
- 尚无裂变气体释放、棒内气压与气体组分演化、芯块致密化/肿胀/开裂/重定位、
  包壳辐照生长/肿胀、氧化腐蚀、冷却剂通道或功率—燃耗历史模型；
- 接触为罚接触或法向增广拉格朗日接触，可选 Coulomb 摩擦与气隙导热；自动
  罚刚度按两侧材料和法向网格尺度计算，增广形式已对 MOOSE 高罚刚度约束极限
  鉴定，但尚未证明与 MOOSE 原生节点乘子压力逐项等价。摩擦已经鉴定规定的小滑移
  热膨胀路径，尚无粘结、脱粘、接触热阻经验关联、压力相关导热、辐射或
  燃料碎块之间的三维运动。机械接触已动态搜索完整开放 primary 链；无摩擦 HEX8
  有限滑移平均表面约束滑出时自然释放并贡献零残量，其余路径仍拒绝失投影状态。
  M5.7 已用 MOOSE 传统节点到线段接触覆盖轴对称
  大滑移与摩擦同时激活，B4.1 使用 C3D8 四点表面离散覆盖当前构形跨面搜索、
  双切向摩擦历史和小应变/有限应变区域，B4.2 进一步用 Abaqus 的逐增量参考覆盖
  0.35 弧度法向旋转、双切向滑动、反向卸载和再粘着；B4.3 用二十个相同增量覆盖
  `18.8442%` 当前面积变化、`2.72727%` 法向转动比、明确累计滑移、当前合力、力矩和
  力心。B4.4 在两个切向方向采用独立的 `4×4` primary 和 `3×2` secondary 面划分，
  六个平面 secondary 子区以不同初始间隙形成部分开闭，并在有限滑移中经过六个
  primary 面和一个四面公共顶点；正向指定的全部三项 Abaqus 误差均远低于 `1%`。
  交换 primary 和 secondary 后，台阶面成为 primary；B4.4 的 31 步受控扰动识别出公共边和
  公共顶点投影的线性平均，以及 C3D8 的 `9/16、3/16、1/16` 节点传力矩阵。实现该算子后，
  交换侧的节点力、开度、恢复压力、合力、力矩和力心都达到舍入误差级一致，两个程序相对
  正向指定的单侧合力偏差均为 `46.3415%`。显示节点压力采用恢复节点力除以节点面积，内部
  约束压力仍严格服从线性罚函数。M5.8 使用实心圆柱芯块和环形包壳覆盖三维
  节点到面接触、热传递和摩擦。两个综合路径的节点场、压力和材料状态量都通过统一
  `0.5%` 门槛；加密后的 M5.8 是手动长 benchmark，不注册到默认 CTest；
  M5.8 在固定处理器、数值库单线程和相同 MUMPS 直接分解器下各测量三次；四进程
  相对单进程的内部总求解时间中位数为 `24.965830 s` 和 `73.504522 s`，四核
  求解效率为 `73.6051%`。对应端到端墙钟中位数为 `30.29 s` 和 `77.86 s`，
  效率为 `64.2621%`，固定输入和问题构造开销单独报告；
- 已对代表性稳态热问题、非均匀 Backward Euler 热瞬态和罚接触分别自动检查
  空间网格、时间步和罚参数收敛；J2 独立证据包含单调加载、弹性卸载和再加载

- 检查点已覆盖小应变 PCMI 和非零变形、旋转塑性—蠕变历史的有限应变续算，

- 当前验证工况是小型或中型基准，不能替代独立代码审查、网格/时间步收敛、
