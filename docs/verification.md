# 工程验证矩阵与适用边界

fuelsim 的“已验证”只表示仓库中存在可重复执行的测试、明确的判据和追踪的
证据文件，不表示完成核安全软件鉴定。机器可读的唯一索引是
`verification/verification_matrix.tsv`，`fuelsim_verification_matrix_tests`
会检查矩阵模式、必需能力行、CTest 名称以及每个证据文件是否存在且非空。

## 证据等级

- `verified`：有自动 CTest，并且验收判据和参考文件均进入 Git；
- `qualified`：有自动 CTest，但某项门槛尚未达到项目目标；必须明确记录例外，
  不能写成完全验证；
- `measured`：按受控环境运行的性能观测，不作为每次 CTest，也不外推为缩放
  结论；
- `limitation`：明确未实现或未鉴定的边界，是发布证据的一部分，不能省略。

任何门槛放宽或 `verified -> qualified` 变更都必须先定位物理、离散或参考量
口径原因，并同时记录实际误差、绝对差和适用边界；原因未明时不得用放宽门槛
掩盖回归。

所有 fuelsim-to-MOOSE 全场误差使用相对 L2、相对绝对峰值和最大逐点相对
误差。参考值为零的点不构造相对误差，而是另外报告数量和最大绝对差。矩阵中
M0、M1 和 M3.3 的门槛为 `1%`；M2.1、M2.2 和 M3.1 的门槛为 `0.1%`。
M2.3 已改用与 fuelsim secondary-side STS 弱式一致的 MOOSE mortar gap heat
transfer 参考，并把验证屈服点移离分支切换面。全部节点温度/位移、接触压力、
总接触力、平均状态以及 40 个积分点的等效应力、塑性和蠕变应变现在统一使用
`0.1%` 门槛；当前最差项是积分点塑性应变最大逐点相对误差 `0.086612%`。
具体实际数值由对应 CTest 输出，不能只凭构建成功宣称通过。
M4.1 有限应变 PCMI 使用统一 `0.5%` 门槛；温度、径向/轴向位移、接触压力，
以及逐积分点等效应力、等效塑性应变和等效蠕变应变的三项误差必须全部通过。
M4.2 follower pressure 对全部节点的温度、径向位移和轴向位移同样使用统一
`0.5%` 门槛，并要求局部当前构形合力、AD Jacobian、父单元四边法向测试
通过；MOOSE 端到端同时覆盖外径 `right`、内径 `left` 和端面 `top`。
M4.3 对畸变 4 单元网格的全部 100 个接受步进行逐单元历史比较。每个单元先
对四个积分点按参考 RZ 体积加权平均，再按时间和 Exodus 单元 ID 对齐，共
比较 400 个单元—时间行；最大极分解转角约 `25.5°`，并同时施加当前构形
压力和分量牵引。MOOSE 参考用径向和轴向两个 `ADPressure` 对象表达倾斜
内表面的完整当前法向。节点场、两个等效历史量，以及应力、弹性应变和总
非弹性应变的 L2/峰值使用统一 `0.5%` 门槛。三个张量的相对 L2 为
`0.000525%/0.000537%/0.000483%`；换向低应力点的最大逐点相对误差为
`0.5324%/0.5324%/0.4467%`，仅前两项采用显式 `0.6%` qualified 门槛，
不增加分母下限；对应最大绝对误差及位置也自动输出。
同一验收还分别隔离弹性、塑性、蠕变、耦合材料和 pressure/traction，并用
四节点完全受控的单单元材料算例确认非共轴历史更新达到接近舍入误差的一致。
纯蠕变隔离路径在应力过零处的最大逐点相对误差为 `3.6755%`，单独使用
`4%` qualified 门槛；其相对 L2 仅 `0.000369%`，最大绝对差为 `0.165 MPa`。
该路径还以 MOOSE 的 900 个节点—时间状态重放 fuelsim 生产材料事务。共享
状态应力的相对 L2 为 `5.15e-8%`、最大逐点相对误差为 `0.000602%`，其余
历史量最大逐点误差不超过 `0.000210%`；聚合量和逐点门槛分别为
`1e-6%/0.001%`。MOOSE 状态在 fuelsim 自由力学方程上的最大相对残量为
`0.001419%`，门槛为 `0.002%`。这组证据将 qualified 例外定位为独立平衡
路径在低应力过零点的相对误差放大，而非已复现的 Norton 更新错误。
全部 16 个材料点的塑性/蠕变迹漂移分别限制为 `7e-6/2e-7`。
M5.1 在 M1 的 528 节点、460 单元和 1,584 自由度网格上增加
`mu = 0.3` 的 Coulomb 摩擦。最终 11 个接触节点中 8 个滑移，secondary
切向合力为 `207.371182 N`；相对无摩擦基线，轴向节点场的相对 L2 改变量为
`5.0871%`，说明对比确实激活了摩擦。相对 MOOSE 的温度、径向位移、轴向
位移和法向压力三项误差中，最差值分别为 `0.086476%`、`0.386523%`、
`0.439326%` 和 `0.318127%`，都低于各自 MOOSE 全场尺度的 `1%` 门槛。
M5.2 在 402 节点、264 单元和 1,206 自由度的水平接触面上验证完整 primary
链动态搜索。五个 secondary 节点全部承受 `100 MPa` 压力，外缘从 4 mm
移动到 4.23 mm，最大活动段编号前进 2。温度、径向位移、轴向位移和压力的
三项误差最高约为 `7.8e-13%`；1 rank/2 rank 逐自由度等价通过，检查点续算
与不间断路径的最大绝对差和缩放差均为 `0`。
M5.4 在 M1 的 528 节点、460 单元和 1,584 自由度网格上验证自动罚刚度与
增广拉格朗日法向接触。两侧材料和法向网格尺度给出的串联界面刚度为
`5.612722170253e14 Pa/m`。fuelsim 内层使用其 `0.25` 倍，MOOSE 参考使用其
`10` 倍作为离散约束极限；最大穿透为 `0.1278 nm`，占 `1 nm` 容差的
`12.8%`。温度、径向位移、轴向位移和法向压力三项误差中的最差值分别为
`0.086402%`、`0.343463%`、`0.770933%` 和 `0.251094%`，均低于对应 MOOSE
全场尺度的 `1%`。高罚刚度与中等罚刚度增广内层的两体切线条件数代理分别为
`21` 和 `1.5`；它只说明隔离的法向两体刚度，不代表完整有限元 Jacobian 的
谱条件数。MOOSE 原生节点到面增广压力会随罚刚度明显变化，在本环境中未形成
稳定的逐节点乘子参考，因此没有把它列为已验证对标；具体诊断误差和边界记录
在 `docs/m5.md` 与 `verification/moose/README.md`。
M5.5 用单进程/双进程稳态接触、大滑移接触和瞬态材料历史等价性约束回调影子
自由度收集。23,010 自由度基准的双进程最大影子为 12,290，两进程影子槽总数
从旧全量方案的 46,020 降为 23,600，减少 `48.72%`；每次回调远程 double
数量从 23,010 降为 8,088，字节载荷从 184,080 降为 64,704，减少
`64.85%`。明确计入的最大持久回调数组从 368,160 字节降为 245,800 字节，
减少 `33.24%`；该口径不包含矩阵、直接分解、PETSc 元数据、复制网格、
committed 状态和材料历史，不作为进程常驻内存结论。

## 发布验收

规定环境中的候选提交至少执行：

```bash
env \
  PATH=/home/cooper/miniforge/envs/moose/bin:/usr/local/bin:/usr/bin:/bin \
  PKG_CONFIG_PATH=/home/cooper/miniforge/envs/moose/lib/pkgconfig \
  cmake -S . -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_COMPILER=/home/cooper/miniforge/envs/moose/bin/c++ \
  -DCMAKE_PREFIX_PATH=/tmp/adlite-fuelsim-install \
  -DSEACASExodus_DIR=/home/cooper/.local/exodus-2024-06-27/lib/cmake/SEACASExodus
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

涉及性能的候选还必须按 `benchmarks/README.md` 固定 CPU 和全部线程环境变量，
完成 1,584 DOF 配对计时以及 23,010 DOF、20 步工况。MPI 沙盒初始化失败需在
沙盒外复现；不能跳过并行测试后仍声明发布验收通过。

## 当前工程适用边界

当前版本是燃料棒性能分析的基础有限元求解器，适合继续承载经过独立验证的
物理模型，但不是完整的燃料性能产品。边界包括：

- 仅支持 2D 轴对称 RZ、Quad4 体单元和 Line2 边；区域可选小应变或
  MOOSE 默认增量 Taylor 有限应变，没有 3D 或非轴对称载荷；
- 材料只有线性温度斜率热弹性、通用 J2 线性硬化塑性、Norton 蠕变及其
  全隐式耦合；斜率采用 AD 活跃求值，但尚无 UO2/包壳温度、燃耗、辐照
  相关的工程关联；
- 当前有限应变塑性—蠕变采用 MOOSE 默认 Taylor 分解和开启的历史客观旋转；
  局部旋转测试覆盖弹性、塑性和蠕变张量，M4.1 覆盖近共轴 PCMI，M4.2
  覆盖有限应变 follower pressure，M4.3 覆盖畸变 4 单元、100 步、约
  `25.5°` 的非共轴反向路径，以及并存的当前构形压力/分量牵引。任意转角、
  任意路径和一般网格仍未鉴定；当前分量牵引方向固定为全局 R 或 Z，不是
  随法向转动的任意矢量 follower law；
- 瞬态有限应变按 committed 构形增量更新；稳态有限应变没有材料历史，每个
  延续载荷步都从 `F_old=I` 对总变形做一次 Taylor 更新，不适用于主方向随
  稳态载荷步旋转的路径依赖材料问题；
- 尚无裂变气体释放、棒内气压与气体组分演化、芯块致密化/肿胀/开裂/重定位、
  包壳辐照生长/肿胀、氧化腐蚀、冷却剂通道或功率—燃耗历史模型；
- 接触为罚接触或法向增广拉格朗日接触，可选 Coulomb 摩擦与气隙导热；自动
  罚刚度按两侧材料和法向网格尺度计算，增广形式已对 MOOSE 高罚刚度约束极限
  鉴定，但尚未证明与 MOOSE 原生节点乘子压力逐项等价。摩擦已经鉴定规定的小滑移
  热膨胀路径，尚无粘结、脱粘、接触热阻经验关联、压力相关导热、辐射或
  燃料碎块之间的三维运动。机械接触已动态搜索完整开放 primary 链，滑出
  整条链仍会拒绝当前状态；大滑移与摩擦同时激活的路径尚未鉴定；
- 已对代表性稳态热问题、Backward Euler 热瞬态和罚接触分别自动检查空间
  网格、时间步和罚参数收敛；J2 独立证据仍以单调加载和卸载为主，每个新增
  工程工况仍必须执行自己的收敛研究；
- 时间积分只有一阶 Backward Euler；可选 step-doubling 同时控制温度、位移、
  应力及全部塑性/蠕变历史的局部时间误差。100 秒 PCMI 已对九组状态完成
  `1/0.5/0.25/0.125 s` 全局研究，但径向接触响应的相邻解差观测阶只有
  `0.50/0.60`；多年蠕变和其他接触路径仍须独立做全局时间步收敛；
- 分场残量有独立诊断和复核；除可选初始残量自动缩放外，用户可给定跨载荷步
  固定的温度和力学残量特征尺度。尺度仍需按具体工况证明，不是通用默认值；
- 多 rank 已分布贡献装配和 PETSc 线性代数，回调只收集本地贡献及接触搜索
  依赖的影子自由度；但网格、问题几何、committed 状态与材料历史仍复制，
  Exodus 仍由各 rank 串行读取，因此内存扩展性尚未完成；
- 检查点已覆盖小应变 PCMI 和非零变形、旋转塑性—蠕变历史的有限应变续算，
  只保证当前严格格式和相同问题签名，不提供跨版本迁移；
- 当前验证工况是小型或中型基准，不能替代独立代码审查、网格/时间步收敛、
  试验数据验证、软件质量保证和法规鉴定。

新增工程物理时，必须先在矩阵中增加 `verified` 行或扩展现有行，绑定输入卡、
参考网格/结果、局部 AD 切线、解析或独立代码对标和明确门槛；在证据齐全前应
标为 `qualified` 或 `limitation`，不能用“计划支持”描述为当前能力。
