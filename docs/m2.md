# M2.1、M2.2 与 M2.3 设计说明

2026-09-09：本文中的轴对称 MOOSE 对比属于历史记录，对应外部例题及专用
检查实现已删除。材料与时间状态功能继续保留，当前验收范围见验证矩阵。

M2 在已验证的 STS 热接触和唯一 NTS 机械接触上增加物理时间与积分点历史。
生产接口使用 `TransientProblem`、`Quad4RzTransientKernel` 和自由函数
`solve_transient`；任意数量的命名区域共享同一状态事务。实现没有材料工厂、
运行时 Kernel 注册或项目自定义 C++ 模板。

## M2.1 瞬态状态

热方程使用参考构形上的一致热容矩阵和 Backward Euler：

```text
R_T_i =
  integral[
    N_i*rho*cp*(T_new-T_old)/dt
    + k(T_new)*grad(N_i).grad(T_new)
    - N_i*q_volume
  ] * 2*pi*r*dA
```

力学在每个时间点保持准静态，不包含位移惯性。气隙导热和法向接触使用
当前步温度与位移，界面本身不保存热容。

状态所有权固定为：

```text
solve_transient
  -> 决定 end_time、dt、热源、cutback 和接受/拒绝

TransientProblem
  -> committed nodal state
  -> 各命名区域的 committed Gauss-point state
  -> 当前活动时间步和事务热源

Quad4RzTransientKernel
  -> 只读 committed state
  -> 临时生成 ADlite trial stress/state

PETSc
  -> 只求解当前 Newton 状态，不提交历史
```

一次时间步的事务顺序为：

```text
begin
  -> 从同一 committed 状态执行所有 residual/Jacobian/line-search 回调
  -> SNES 未收敛：rollback，恢复 committed 时间、载荷、nodal/IP 状态
  -> SNES 收敛：在最终解上重算 trial history
  -> commit nodal state、IP state、time 和 heat source
```

积分点 committed 历史始终是 `double`。`adlite::Scalar` 只存在于一次局部
残量或最终状态重算期间，不跨 PETSc 回调保存。

时间控制器支持：

```text
initial_time_step
minimum_time_step
maximum_time_step
growth_factor
cutback_factor
maximum_cutbacks_per_step
load_ramp_time
```

失败尝试的 `SolveResult.state` 只作为诊断，重试初值永远取
`TransientProblem::committed_solution()`。

## M2.2 通用非弹性更新

轴对称张量分量固定为：

```text
[rr, zz, hoop, rz]
```

`rz` 是张量剪应变，内积为：

```text
a:b = arr*brr + azz*bzz + ahoop*bhoop + 2*arz*brz
q = sqrt(3/2 * s:s)
flow_direction = 3/2 * s/q
```

每个材料点保存：

```text
plastic_strain[4]
creep_strain[4]
equivalent_plastic_strain
equivalent_creep_strain
```

### Norton 蠕变

通用等温幂律为：

```text
creep_rate = A * (q/q_ref)^n
```

后向 Euler 局部方程为：

```text
q + 3*G*dt*A*(q/q_ref)^n - q_trial = 0
```

`n=1` 使用闭式解；其他指数令 `q=q_trial*exp(-x)`，在对数域使用带区间
保护的 Newton。局部求解不收敛会明确抛错。隐式根的一致导数通过
`adlite::compose` 接入单元 Jacobian：

```text
dq/dq_trial =
  1 / [1 + 3*G*dt*A*n/q_ref*(q/q_ref)^(n-1)]
```

### J2 塑性

屈服应力采用线性各向同性硬化：

```text
yield = yield_stress + H*equivalent_plastic_strain_old
```

活跃屈服时使用闭式径向返回：

```text
delta_p = (q_trial-yield)/(3*G+H)
q_new = q_trial - 3*G*delta_p
```

卸载或 `q_trial <= yield` 时历史不变。

### 塑性—蠕变耦合

`norton_creep_j2_plasticity` 在同一个材料点和时间步内同时更新两套历史，
不是先塑性后蠕变的一次性算子分裂。首先求只有蠕变时的候选应力：

```text
q_creep + 3*G*dt*A*(q_creep/q_ref)^n = q_trial
```

如果 `q_creep <= yield_old`，塑性不活跃，直接采用 creep-only 解。否则
两个增量共同满足：

```text
q_trial = q + 3*G*(delta_p + delta_c)
delta_c = dt*A*(q/q_ref)^n
q = yield_old + H*delta_p
```

对于 `H>0`，消去塑性增量后得到另一个 Norton 形式的单调标量根：

```text
w = H/(3*G+H)
B = yield_old + w*(q_trial-yield_old)
K = 3*G*w

q + K*dt*A*(q/q_ref)^n = B
```

`H=0` 时直接令 `q=yield_old`，剩余非弹性增量分配给塑性。塑性和蠕变
增量共用 `1.5*s_trial/q_trial` 流动方向，因此两套应变都保持无迹。

标量根以 `q=B*exp(-x)` 在对数域求解，不显式构造可能超出 `double` 的
幂律系数。最终应力、塑性增量和蠕变增量的隐式导数分别通过
`adlite::compose` 接回 `q_trial`，方向变化继续由 ADlite 自动线性化。
等效应力范数使用嵌套 `adlite::hypot`，避免直接平方和的提前上溢或下溢。

### 有意保留的限制

一次 `IsotropicInelasticMaterial` 只能选择：

```text
elastic
norton_creep
j2_plasticity
norton_creep_j2_plasticity
```

燃料区和包壳区可以独立选择模型，也可以在任一区域的同一积分点启用耦合。
当前参数是算法验证参数，不是 UO2、MOX、Zircaloy 或其他具体材料的标定
模型。

当前提供相对 `reference_temperature` 的线性 AD 活跃参数斜率，用于验证
温度链式切线；它们不是工程材料关联。暂不实现：

- Arrhenius、辐照、燃耗、孔隙率或快中子通量关联；
- Arrhenius、分段表格或经试验标定的温度相关屈服、硬化和蠕变关联；
- 非线性硬化、运动硬化和一般非共轴多步大转动的端到端鉴定；
- 非共轴的多个塑性面或多个黏塑性机制；
- 裂变气体、重定位、开裂或真实材料失效判据。

区域可选择 `strain = finite`，此时材料更新使用与 MOOSE 默认一致的增量
Taylor 应变和 Rashid 转动，弹性、塑性与蠕变历史在步末执行客观旋转，力学
内力在当前构形装配。M4.1 对齐 MOOSE 默认开启旋转的近共轴 PCMI；独立局部
测试覆盖分机制张量旋转，M4.3 进一步逐步对比约 `25.5°` 的非共轴反向路径。
MOOSE 仅旋转其总非弹性张量，因此端到端分机制证据采用总张量加两个等效
标量；当前 M4.3 已扩展为畸变四单元、100 步、约 `25.5°` 并含当前构形
压力/分量牵引的路径，但任意转角和任意路径仍不能由单个工况外推。

## M2.3 PCMI 回归

PCMI 算例不增加新的本构模型，而是把 M2.1 的瞬态热力耦合、M1 的 STS
热接触与 NTS 机械接触，以及 M2.2 的塑性—蠕变耦合放入同一个端到端
载荷路径。燃料保持弹性，体积热源在 20 个 `1 s` 时间步内线性增加到
`2e8 W/m^3`；燃料热膨胀闭合 `1 um` 初始径向间隙，然后对包壳施加载荷。

包壳高度为 `10.020 mm`，比 `10.000 mm` 的燃料高 `20 um`，因此热膨胀后
所有 5 个燃料表面节点仍有唯一有效投影。包壳热膨胀系数在本算法回归中
设为零，用于隔离芯块热膨胀驱动的 PCMI；这不是包壳真实材料假设。

同参 MOOSE 算例采用同一份 Exodus Quad4 RZ 网格、Backward Euler 时间步、
与 fuelsim conservative secondary-side STS 对齐的 MortarGapHeatTransfer、
面积归一化 node-face 罚接触，以及 creep-first 的
`ADComputeMultipleInelasticStress`。回归比较全部 53 个 Exodus 节点的
温度、径向位移和轴向位移，包壳体积平均等效应力与等效塑性/蠕变应变，
全部 5 个从面节点的压力以及总接触力。每个非零参考场统一计算相对 L2、
相对绝对峰值和最大逐点相对误差；精确零参考点不参与逐点相对除法，另行
报告其数量和最大绝对差。

全部节点温度、径向/轴向位移、接触压力、总力和平均材料量的三项门槛均为
`<0.1%`。当前节点场最大项为径向位移最大逐点相对误差 `0.070356%`，接触
压力最大项为 `0.040336%`。

燃料接触面由 4 条边组成，包壳接触面由 5 条边组成，二者轴向节点不重合；
完整网格包含 53 个节点和 34 个 Quad4。分布回归另外覆盖包壳
`10 element x 4 QP = 40` 个积分点。MOOSE 使用
`ADMaterialRealAux::selected_qp` 抽取每个 Gauss 点的 von Mises 应力、
等效塑性应变和等效蠕变应变，同时保存 `elem_id`、`qp_id` 和物理坐标。
CTest 直接读取这些追踪的原生 CSV，不在 C++ 中复制参考数值。
MOOSE 的局部 QP 次序 `[--, +-, -+, ++]` 在比较前重排为 fuelsim 的
`[--, +-, ++, -+]`；坐标还必须在 `1e-12 m` 内一致。等效应力的 L2/峰值/
逐积分点等效应力、塑性应变和蠕变应变也统一使用 `<0.1%` 三指标门槛；当前
最差项为塑性应变最大逐点相对误差 `0.086612%`。
测试同时报告最大绝对/相对误差所在的包壳局部单元及积分点。

## 运行与验收

构建后运行：

```bash
./build/fuelsim -i \
  verification/fuelsim/transient_fuel_cladding_pcmi.fsi
```

该输入卡使用 20 个 `1 s` 时间步把热源线性增加到目标值，燃料保持弹性，
包壳选择耦合 Norton—J2。算例在包壳积分点产生非零塑性和蠕变历史，只
证明算法和状态管理可以在接触问题中共同工作，不代表真实反应堆瞬态。

CTest 分别检查：

- 瞬态单元 AD Jacobian 和一致热容矩阵；
- `T=600+t` 的均匀绝热解析解；
- `T(r,t)=T0+A*r^2+B*t+C*t^2` 非均匀制造解的二阶空间和一阶时间收敛；
- J2 闭式返回、卸载、无迹性和 AD 切线；
- Norton 线性解析根、非线性局部方程、无迹性和 AD 切线；
- 耦合应力平衡、屈服一致性、两套无迹历史和材料点/单元 AD 切线；
- `A=0`、强蠕变不屈服、`H=0`、近零硬化和极端应力尺度退化分支；
- residual/Jacobian 回调不修改 committed history；
- commit、rollback、PETSc 工作区复用和同点双历史端到端演示；
- `verification/moose/` 中七个独立 MOOSE 参考，包括 J2 卸载—再加载的
  30 步原生历史和完整 PCMI 回归。

所有 MOOSE 对比均读取完整节点场：温度、径向位移和轴向位移使用三项误差，
存在接触时压力也使用同样三项误差。M2.1 的两个精确全零位移参考场改用
绝对 L2、绝对峰值和最大绝对逐点误差 `<1e-12 m`，不构造没有定义的相对
误差。M2.3 的节点场、压力和逐积分点分布现在全部使用 `<0.1%` 门槛。
输入、结果快照、版本和复现命令见 `verification/moose/README.md`。
