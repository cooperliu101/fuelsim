# M2.1 与 M2.2 设计说明

M2 在已验证的 M1 双网格、STS 热接触和唯一 NTS 机械接触上增加物理时间
与积分点历史。M1 稳态接口保持不变，M2 使用具体的
`M2Problem`、`Quad4RzTransientKernel` 和 `M2TimeStepper`，没有材料工厂、
运行时 Kernel 注册或项目自定义 C++ 模板。

## M2.1 瞬态状态

热方程使用参考构形上的一致热容矩阵和 Backward Euler：

```text
R_T_i =
  integral[
    N_i*rho*cp*(T_new-T_old)/dt
    + k(T_new)*grad(N_i).grad(T_new)
    - N_i*q_volume
  ] * 2*pi*r*dA
```

力学在每个时间点保持准静态，不包含位移惯性。气隙导热和法向接触使用
当前步温度与位移，界面本身不保存热容。

状态所有权固定为：

```text
M2TimeStepper
  -> 决定 end_time、dt、热源、cutback 和接受/拒绝

M2Problem
  -> committed nodal state
  -> fuel/cladding committed Gauss-point state
  -> 当前活动时间步和事务热源

Quad4RzTransientKernel
  -> 只读 committed state
  -> 临时生成 ADlite trial stress/state

PETSc
  -> 只求解当前 Newton 状态，不提交历史
```

一次时间步的事务顺序为：

```text
begin
  -> 从同一 committed 状态执行所有 residual/Jacobian/line-search 回调
  -> SNES 未收敛：rollback，恢复 committed 时间、载荷、nodal/IP 状态
  -> SNES 收敛：在最终解上重算 trial history
  -> commit nodal state、IP state、time 和 heat source
```

积分点 committed 历史始终是 `double`。`adlite::Scalar` 只存在于一次局部
残量或最终状态重算期间，不跨 PETSc 回调保存。

时间控制器支持：

```text
initial_time_step
minimum_time_step
maximum_time_step
growth_factor
cutback_factor
maximum_cutbacks_per_step
heat_source_ramp_time
```

失败尝试的 `SolveResult.state` 只作为诊断，重试初值永远取
`M2Problem::committed_solution()`。

## M2.2 通用非弹性更新

轴对称张量分量固定为：

```text
[rr, zz, hoop, rz]
```

`rz` 是张量剪应变，内积为：

```text
a:b = arr*brr + azz*bzz + ahoop*bhoop + 2*arz*brz
q = sqrt(3/2 * s:s)
flow_direction = 3/2 * s/q
```

每个材料点保存：

```text
plastic_strain[4]
creep_strain[4]
equivalent_plastic_strain
equivalent_creep_strain
```

### Norton 蠕变

通用等温幂律为：

```text
creep_rate = A * (q/q_ref)^n
```

后向 Euler 局部方程为：

```text
q + 3*G*dt*A*(q/q_ref)^n - q_trial = 0
```

`n=1` 使用闭式解；其他指数令 `q=q_trial*exp(-x)`，在对数域使用带区间
保护的 Newton。局部求解不收敛会明确抛错。隐式根的一致导数通过
`adlite::compose` 接入单元 Jacobian：

```text
dq/dq_trial =
  1 / [1 + 3*G*dt*A*n/q_ref*(q/q_ref)^(n-1)]
```

### J2 塑性

屈服应力采用线性各向同性硬化：

```text
yield = yield_stress + H*equivalent_plastic_strain_old
```

活跃屈服时使用闭式径向返回：

```text
delta_p = (q_trial-yield)/(3*G+H)
q_new = q_trial - 3*G*delta_p
```

卸载或 `q_trial <= yield` 时历史不变。

### 塑性—蠕变耦合

`norton_creep_j2_plasticity` 在同一个材料点和时间步内同时更新两套历史，
不是先塑性后蠕变的一次性算子分裂。首先求只有蠕变时的候选应力：

```text
q_creep + 3*G*dt*A*(q_creep/q_ref)^n = q_trial
```

如果 `q_creep <= yield_old`，塑性不活跃，直接采用 creep-only 解。否则
两个增量共同满足：

```text
q_trial = q + 3*G*(delta_p + delta_c)
delta_c = dt*A*(q/q_ref)^n
q = yield_old + H*delta_p
```

对于 `H>0`，消去塑性增量后得到另一个 Norton 形式的单调标量根：

```text
w = H/(3*G+H)
B = yield_old + w*(q_trial-yield_old)
K = 3*G*w

q + K*dt*A*(q/q_ref)^n = B
```

`H=0` 时直接令 `q=yield_old`，剩余非弹性增量分配给塑性。塑性和蠕变
增量共用 `1.5*s_trial/q_trial` 流动方向，因此两套应变都保持无迹。

标量根以 `q=B*exp(-x)` 在对数域求解，不显式构造可能超出 `double` 的
幂律系数。最终应力、塑性增量和蠕变增量的隐式导数分别通过
`adlite::compose` 接回 `q_trial`，方向变化继续由 ADlite 自动线性化。
等效应力范数使用嵌套 `adlite::hypot`，避免直接平方和的提前上溢或下溢。

### 有意保留的限制

一次 `IsotropicInelasticMaterial` 只能选择：

```text
elastic
norton_creep
j2_plasticity
norton_creep_j2_plasticity
```

燃料区和包壳区可以独立选择模型，也可以在任一区域的同一积分点启用耦合。
当前参数是算法验证参数，不是 UO2、MOX、Zircaloy 或其他具体材料的标定
模型。

暂不实现：

- Arrhenius、辐照、燃耗、孔隙率或快中子通量关联；
- 温度相关屈服、硬化或蠕变系数；
- 有限应变、旋转更新、非线性硬化或运动硬化；
- 非共轴的多个塑性面或多个黏塑性机制；
- 裂变气体、重定位、开裂或真实材料失效判据。

## 运行与验收

构建后运行：

```bash
./build/fuelsim_m2
```

默认演示使用 20 个 `1 s` 时间步把热源线性增加到目标值，燃料选择通用
Norton，包壳选择耦合 Norton—J2。该算例在同一包壳积分点产生非零塑性和
蠕变历史，只证明算法和状态管理可以在接触问题中共同工作，不代表真实
反应堆瞬态。

CTest 分别检查：

- 瞬态单元 AD Jacobian 和一致热容矩阵；
- `T=600+t` 的均匀绝热解析解；
- J2 闭式返回、卸载、无迹性和 AD 切线；
- Norton 线性解析根、非线性局部方程、无迹性和 AD 切线；
- 耦合应力平衡、屈服一致性、两套无迹历史和材料点/单元 AD 切线；
- `A=0`、强蠕变不屈服、`H=0`、近零硬化和极端应力尺度退化分支；
- residual/Jacobian 回调不修改 committed history；
- commit、rollback、PETSc 工作区复用和同点双历史端到端演示；
- `verification/moose/` 中五个独立 MOOSE 参考。

MOOSE 对标门槛为温度、位移、应力、等效塑性应变和等效蠕变应变相对误差
均小于 `0.1%`。输入、结果快照、版本和复现命令见
`verification/moose/README.md`。
