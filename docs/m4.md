# M4 工程数值基础与有限应变

本阶段不增加新的燃料或包壳经验模型，而是提高长工况和后续真实材料关联的
数值可靠性。生产默认仍为 PETSc Newton BASIC 全步；一次 BASIC 求解失败时，
fuelsim 可从该次调用的原始初值自动用 BT 回溯重试，BT 仍失败才交给稳态载荷
二分或瞬态 cutback。输入卡可用 `backtracking_fallback = false` 禁用该恢复层。
两次尝试复用同一 PETSc 工作区，并在输出中记录尝试数、是否使用回退以及
BASIC 的失败类别。

## AD 活跃的温度相关材料参数

热弹性、Norton 和 J2 参数可选用相对 `reference_temperature` 的线性斜率：

```text
property(T) = property_ref + property_temperature_coefficient
                              * (T - reference_temperature)
```

`E(T)`、`nu(T)`、`alpha(T)`、Norton 的 `A(T)`、`q_ref(T)`、`n(T)`，以及
J2 的屈服应力和硬化模量都直接以 `adlite::Scalar` 求值。塑性、蠕变和耦合
局部隐式根的参数偏导通过隐函数关系回传到温度，因此全局 Jacobian 不丢失
材料参数的温度链式项。运行中若线性关系越过物理定义域会报告 domain error，
由 BT 或 cutback 恢复，不做隐式夹持。

这些线性斜率用于验证 AD 活跃属性接口，不代表任何 UO2 或锆合金标定模型。
当前热应变定义仍为 `alpha(T)*(T-reference_temperature)`；若未来输入平均热
膨胀系数、瞬时热膨胀系数表或经验积分形式，必须作为明确的新材料关联实现。

## 分场残量复核

每次求解记录温度、径向位移和轴向位移三个方程组的初始与最终 L2 范数。
PETSc 给出正收敛原因后，除总残量外还逐场复核绝对门槛或相对降低门槛；因此
热力单位混合不会让某一场在总范数中被完全掩盖。相对降低门槛由
`residual_reduction_tolerance` 控制，默认 `1e-6`。
温度方程和两个力学方程另有默认 `1e-8 W` 与 `1e-4 N` 的绝对门槛；总残量
绝对门槛由三个分场门槛合成。这样不会把瓦特和牛顿强行解释为同一物理尺度，
用户仍应针对具体问题设置有意义的平衡容差。

`field_residual_scaling = true` 可把每一温度行按初始温度残量尺度、两个力学
行按共同初始力学残量尺度缩放，并对残量和 Jacobian 行采用相同因子。该功能
默认关闭：由当前迭代残量自动生成的尺度会随载荷步改变，在 PCMI 接触启动
附近可能改变非线性路径。默认路径只启用逐场诊断和收敛复核；正式工程材料
更适合后续增加由用户给定、量纲明确且跨步固定的特征尺度。

## Backward Euler 时间误差控制

`time_error_relative_tolerance > 0` 时启用 step-doubling：从同一完整 committed
状态分别计算一个全步和两个半步，以两个半步解作为接受解，并按温度、径向
位移和轴向位移的归一化 L2 差估计误差。任一分场估计大于 1 就恢复节点、
时间、载荷和全部积分点历史并缩步重试。误差控制内部的所有求解继续复用一个
PETSc 工作区；Newton 步长控制使用三次内部求解中的最大迭代数，而总工作量
仍按三次求解累计报告。

自动回归包含：8/16/32 径向单元实心圆柱空间收敛，观测阶约 1.77 和 1.80；
Backward Euler step-doubling 相对细步参考将温度误差由约 `9.13e-3` 降至
`1.17e-3`；三档接触罚参数使最大穿透从约 `2.11e-7 m` 单调降至
`6.01e-8 m`。这些是代表性数值证据，不替代每个生产工况自己的网格、时间步
和罚参数敏感性研究。

M2.3 的 qualified 门槛也按已有误差余量收紧：径向峰值/逐点为
`0.125%/0.27%`，接触压力三项为 `0.11%`，塑性积分点 L2/峰值/逐点为
`0.15%/0.29%/0.305%`，其余积分点门槛见验证矩阵与 M2 说明。

## M4.1 轴对称有限应变几何非线性

每个区域通过必填的 `strain = small|finite` 独立选择运动学。有限应变分支
在参考积分点计算轴对称变形梯度：

```text
Frr = 1 + ur,R      Frz = ur,Z
Fzr = uz,R          Fzz = 1 + uz,Z
Fhoop = 1 + ur/R
```

瞬态步内先由 committed 构形形成增量变形梯度
`Fhat=F_new*inverse(F_old)`。与 MOOSE 默认 `TaylorExpansion` 相同，令
`Cinv_I=inverse(Fhat)*inverse(Fhat)^T-I`，总应变增量取二阶展开：

```text
strain_increment = -0.5*Cinv_I + 0.25*Cinv_I*Cinv_I
```

增量转动使用 MOOSE 的 Rashid 近似。材料在中间构形执行原有 J2/Norton
全隐式返回映射，随后以该转动客观旋转 Cauchy 应力以及弹性、塑性和蠕变
张量历史；等效塑性和等效蠕变标量不变。当前构形梯度由
`F^-T*Grad(N)` 得到，力学残量使用 Cauchy 应力和完整当前测度：

```text
dv_current = 2*pi*(R+ur)*detJ_reference*det(F_rz)*w
```

热传导、体热源和 Backward Euler 一致热容仍在参考构形积分。有限应变试探
态若出现 `det(F_rz)<=0`、`Fhoop<=0` 或当前半径非正，会抛出 domain error，
交给 PETSc 线搜索或时间步拒绝机制处理，不做数值夹持。有限应变区域的
pressure 使用当前半径、当前线段法向和当前表面测度，是 follower load；
小应变 pressure 与所有分量 traction 继续使用参考构形。

局部证据包括均匀径向/轴向伸长的 Taylor 增量和当前测度解析解、非零
committed 构形的增量变形检查、畸变 Quad4 弹性残量的 AD/中心差分方向
导数、活跃塑性—蠕变有限应变单元切线，以及弹性/塑性/蠕变张量的独立
客观旋转与无迹不变量测试。
`transient_finite_strain_pcmi.fsi` 使用与 M2.3 相同的 53 节点、34 Quad4、
燃料 4 段对包壳 5 段非匹配网格。MOOSE 参考只设置
`strain = FINITE`，故自动选择默认增量有限应变、Taylor 分解和开启的历史
旋转；其余热、接触、材料和 20 个 `1 s` 时间步保持一致。

最终全场三项误差如下，列顺序为相对 L2、相对绝对峰值和最大逐点相对误差：

| 场量 | 相对 L2 | 相对绝对峰值 | 最大逐点相对误差 |
| --- | ---: | ---: | ---: |
| 温度 | 0.00976% | 0.00081% | 0.04262% |
| 径向位移 | 0.08346% | 0.11552% | 0.23659% |
| 轴向位移 | 0.02026% | 0.02409% | 0.06706% |
| 接触压力 | 0.04483% | 0.00811% | 0.09192% |
| 包壳 QP 等效应力 | 0.01157% | 0.03237% | 0.03237% |
| 包壳 QP 等效塑性应变 | 0.13111% | 0.26622% | 0.28277% |
| 包壳 QP 等效蠕变应变 | 0.07113% | 0.18378% | 0.18378% |

最大误差是等效塑性应变的最大逐点相对误差 `0.28277%`，所有指定项均低于
统一的 `0.5%` 门槛。总接触力相对误差为 `0.000663%`，5 个 secondary 节点
均成功投影并处于接触状态。

历史张量客观旋转已有独立局部测试，但该 PCMI 路径仍接近共轴，不能单独
外推为一般非共轴多步大转动的端到端鉴定。

## M4.2 当前构形 follower pressure

`Line2RzPressureKernel` 复用边界相邻 Quad4 的 12 个局部自由度。小应变区域
使用参考半径和参考法向，有限应变区域则在每次残量调用中由当前端点计算
半径以及“法向乘线 Jacobian”，因此压力方向、RZ 周长和表面长度均随位移
更新，ADlite 自动给出完整几何刚度。

局部测试覆盖当前构形合力解析式和 AD/中心差分方向导数。端到端
`steady_finite_follower_pressure.fsi` 在单个 RZ Quad4 外表面施加 `10 GPa`
压力，并与 MOOSE 默认 `ADPressure(use_displaced_mesh=true)` 比较全部 4 个
节点。径向位移三项误差不超过 `2.71e-10%`，轴向位移三项误差不超过
`8.46e-10%`；参考零值节点数量和最大绝对差也单独输出。

## M4.3 非共轴多步有限转动

`transient_noncoaxial_finite_strain.fsi` 使用 MOOSE 生成并追踪的单个环形
RZ Quad4。底边固定，顶边在 50 个 `0.1 s` 步中依次经历轴向拉伸、径向
剪切、轴向反向、剪切反向和再次拉伸。正向剪切阶段 `gamma=0.8`、轴向伸长
`10%`，极分解转角约 `20.85°`；耦合 J2 塑性和 Norton 蠕变在整个路径中
保持活跃。

MOOSE 输入只设置 `strain = FINITE`，不覆盖 Taylor 分解或 Rashid 转动。
`fuelsim_m43_noncoaxial_finite_strain_moose_tests` 在每个接受步比较 QP0 的
应力、弹性应变、客观总非弹性应变、等效塑性应变和等效蠕变应变，并在终态
比较全部节点。三项误差中的最大值是等效蠕变应变最大逐点相对误差
`0.000486%`，其余量低至 `1e-6%` 以下，全部通过统一 `0.5%` 门槛。

MOOSE 默认只旋转 `stress`、`elastic_strain` 和
`combined_inelastic_strain`；具体径向返回模型输出的 `plastic_strain` 与
`creep_strain` 不随有限转动旋转。因此端到端对标使用客观的总非弹性张量和
两个分机制等效标量，fuelsim 分别旋转的塑性/蠕变张量由独立局部测试验证。
Rashid 近似并非机器精度正交，本路径中 fuelsim 与 MOOSE 一致的累计历史迹
漂移约 `4.9e-6`，自动门槛为 `<1e-5`；每一步返回映射增量仍保持无迹。

这项证据鉴定的是上述单元素、约 `21°` 的规定路径，不能外推到任意转角、
任意路径或任意网格。
