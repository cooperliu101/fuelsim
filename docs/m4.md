# M4 工程数值基础与有限应变

本阶段不增加新的燃料或包壳经验模型，而是提高长工况和后续真实材料关联的
数值可靠性。生产默认仍为 PETSc Newton BASIC 全步；一次 BASIC 求解失败时，
fuelsim 可从该次调用的原始初值自动用 BT 回溯重试，BT 仍失败才交给稳态载荷
二分或瞬态 cutback。输入卡可用 `backtracking_fallback = false` 禁用该恢复层。
两次尝试复用同一 PETSc 工作区，并在输出中记录尝试数、是否使用回退以及
BASIC 的失败类别。

## AD 活跃的温度相关材料参数

热弹性、Norton 和 J2 参数可选用相对 `reference_temperature` 的线性斜率：

```text
property(T) = property_ref + property_temperature_coefficient
                              * (T - reference_temperature)
```

`E(T)`、`nu(T)`、`alpha(T)`、Norton 的 `A(T)`、`q_ref(T)`、`n(T)`，以及
J2 的屈服应力和硬化模量都直接以 `adlite::Scalar` 求值。塑性、蠕变和耦合
局部隐式根的参数偏导通过隐函数关系回传到温度，因此全局 Jacobian 不丢失
材料参数的温度链式项。运行中若线性关系越过物理定义域会报告 domain error，
由 BT 或 cutback 恢复，不做隐式夹持。

这些线性斜率用于验证 AD 活跃属性接口，不代表任何 UO2 或锆合金标定模型。
当前热应变定义仍为 `alpha(T)*(T-reference_temperature)`；若未来输入平均热
膨胀系数、瞬时热膨胀系数表或经验积分形式，必须作为明确的新材料关联实现。

## 分场残量复核

每次求解记录温度、径向位移和轴向位移三个方程组的初始与最终 L2 范数。
PETSc 给出正收敛原因后，除总残量外还逐场复核绝对门槛或相对降低门槛；因此
热力单位混合不会让某一场在总范数中被完全掩盖。相对降低门槛由
`residual_reduction_tolerance` 控制，默认 `1e-6`。
温度方程和两个力学方程另有默认 `1e-8 W` 与 `1e-4 N` 的绝对门槛；总残量
绝对门槛由三个分场门槛合成。这样不会把瓦特和牛顿强行解释为同一物理尺度，
用户仍应针对具体问题设置有意义的平衡容差。

`field_residual_scaling = true` 可把每一温度行按初始温度残量尺度、两个力学
行按共同初始力学残量尺度缩放，并对残量和 Jacobian 行采用相同因子。该功能
默认关闭：由当前迭代残量自动生成的尺度会随载荷步改变，在 PCMI 接触启动
附近可能改变非线性路径。默认路径只启用逐场诊断和收敛复核；正式工程材料
更适合后续增加由用户给定、量纲明确且跨步固定的特征尺度。

## Backward Euler 时间误差控制

`time_error_relative_tolerance > 0` 时启用 step-doubling：从同一完整 committed
状态分别计算一个全步和两个半步，以两个半步解作为接受解，并按温度、径向
位移和轴向位移的归一化 L2 差估计误差。任一分场估计大于 1 就恢复节点、
时间、载荷和全部积分点历史并缩步重试。误差控制内部的所有求解继续复用一个
PETSc 工作区；Newton 步长控制使用三次内部求解中的最大迭代数，而总工作量
仍按三次求解累计报告。

自动回归包含：8/16/32 径向单元实心圆柱空间收敛，观测阶约 1.77 和 1.80；
Backward Euler step-doubling 相对细步参考将温度误差由约 `9.13e-3` 降至
`1.17e-3`；三档接触罚参数使最大穿透从约 `2.11e-7 m` 单调降至
`6.01e-8 m`。这些是代表性数值证据，不替代每个生产工况自己的网格、时间步
和罚参数敏感性研究。

M2.3 的 qualified 门槛也按已有误差余量收紧：径向峰值/逐点为
`0.125%/0.27%`，接触压力三项为 `0.11%`，塑性积分点 L2/峰值/逐点为
`0.15%/0.29%/0.305%`，其余积分点门槛见验证矩阵与 M2 说明。

## M4.1 轴对称有限应变几何非线性

每个区域通过必填的 `strain = small|finite` 独立选择运动学。有限应变分支
在参考积分点计算轴对称变形梯度：

```text
Frr = 1 + ur,R      Frz = ur,Z
Fzr = uz,R          Fzz = 1 + uz,Z
Fhoop = 1 + ur/R
```

面内左 Cauchy-Green 张量为 `b=F*F^T`，`rr/zz/rz` 应变取
`0.5*log(b)`，环向应变取 `log(Fhoop)`。2x2 对称矩阵对数用解析特征值表达式
实现，并以 `adlite::hypot` 计算特征值间距；接近重根时使用解析极限，避免
为运动学引入第三方线性代数库。当前构形梯度由 `F^-T*Grad(N)` 得到，力学
残量使用 Cauchy 应力和完整当前测度：

```text
dv_current = 2*pi*(R+ur)*detJ_reference*det(F_rz)*w
```

热传导、体热源和 Backward Euler 一致热容仍在参考构形积分。有限应变试探
态若出现 `det(F_rz)<=0`、`Fhoop<=0` 或当前半径非正，会抛出 domain error，
交给 PETSc 线搜索或时间步拒绝机制处理，不做数值夹持。压力和牵引目前仍是
参考构形 dead load，不是 follower load。

局部证据包括均匀径向/轴向伸长的对数应变和当前测度解析解、畸变 Quad4
弹性残量的 AD/中心差分方向导数，以及活跃塑性—蠕变有限应变单元切线。
`transient_finite_strain_pcmi.fsi` 使用与 M2.3 相同的 53 节点、34 Quad4、
燃料 4 段对包壳 5 段非匹配网格。MOOSE 参考改用 `strain = FINITE`、
`decomposition_method = EigenSolution` 和
`perform_finite_strain_rotations = false`；其余热、接触、材料和 20 个 `1 s`
时间步保持一致。

最终全场三项误差如下，列顺序为相对 L2、相对绝对峰值和最大逐点相对误差：

| 场量 | 相对 L2 | 相对绝对峰值 | 最大逐点相对误差 |
| --- | ---: | ---: | ---: |
| 温度 | 0.00976% | 0.00081% | 0.04262% |
| 径向位移 | 0.08055% | 0.11100% | 0.22822% |
| 轴向位移 | 0.02138% | 0.02557% | 0.06487% |
| 接触压力 | 0.04471% | 0.01060% | 0.09059% |
| 包壳 QP 等效应力 | 0.01105% | 0.03096% | 0.03096% |
| 包壳 QP 等效塑性应变 | 0.12522% | 0.25467% | 0.27087% |
| 包壳 QP 等效蠕变应变 | 0.06951% | 0.17985% | 0.17985% |

最大误差是等效塑性应变的最大逐点相对误差 `0.27087%`，所有指定项均低于
统一的 `0.5%` 门槛。总接触力相对误差为 `0.00098%`，5 个 secondary 节点
均成功投影并处于接触状态。

该证据不能外推到一般非共轴大转动：fuelsim 当前没有把 committed 塑性和
蠕变应变张量随有限转动客观旋转，MOOSE 对标也明确关闭了该旋转。增加一般
大转动本构前必须补历史旋转、刚体转动客观性及非共轴加载的独立测试。
