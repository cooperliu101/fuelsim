# 独立温度求解

输入卡在 `[Case]` 中选择 `physics = thermal`，每个区域显式选择 `dcax4`、
`dcax8`、`dc3d8` 或 `dc3d20`。入口仍为 `fuelsim -i case.fsi`。
省略 physics 保持原有热力耦合模式；也可显式写 `physics = thermomechanical`。

第一版在固定 Exodus 几何上求解稳态或瞬态传热，不计算位移、应力或非弹性历史。
轴对称使用完整的 `2*pi*r` 测度。区域材料只定义 `[thermal]`；不接受弹性、
本征应变、塑性、蠕变、区域 strain、重力或机械边界条件。

| 单元 | 几何 | 网格 | 温度节点 | 体积分 |
|---|---|---|---|---|
| dcax4 | axisymmetric_rz | QUAD4 | 全部四节点 | 2×2 |
| dcax8 | axisymmetric_rz | QUAD8 | 全部八节点 | 3×3 |
| dc3d8 | cartesian_3d | HEX8 | 全部八节点 | 2×2×2 |
| dc3d20 | cartesian_3d | HEX20 | 全部二十节点 | 3×3×3 |

一个模型只使用一种网格拓扑。相邻区域共用 Exodus 源节点时，共用同一个温度
未知量。二次单元的中间节点温度是独立未知量，其定温、热流、对流和界面传热
均使用完整的二次温度插值。现有热力耦合单元的角点温度插值规则不变。

## 热离散和状态

DCAX4 和 DC3D8 按 Abaqus 默认规则采用节点集总热容。DCAX4 节点权重为
`integral(N_i*dV_reference)`；DC3D8 使用与角点配对的高斯点参考积分权重。
密度在节点初始温度求值，比热和温度变化率在
当前节点求值；热容切线只保留节点对角项，并包含比热的温度导数。
DCAX8 和 DC3D20 使用一致热容矩阵，积分点温度由全部温度节点插值，比热在
当前积分点温度求值。四种型号均采用初始密度乘参考体积的固定初始质量。
后向欧拉热容使用 `rho_initial*cp(T)*(T-T_old)/dt`，没有改写成焓差。
DCAX4 的导热系数使用与高斯点配对的角点温度，导热系数温度导数只连接到
该角点；温度梯度仍使用完整形函数梯度。其余三种型号的导热系数及温度导数
使用积分点插值温度。原生依据见[扩展验证](../verification/thermal/extension.md)。

比较范围见[纯热验证说明](../verification/thermal/README.md)。这些纯热规则
不改变现有热力耦合型号的离散。

纯热装配只建立温度自由度及温度切线。局部热物性使用宽度一的 ADlite 温度
导数，再经形函数形成节点切线；不按全局未知量播种。PETSc 求解、贡献划分、
稳态加载、后向欧拉时间推进以及一个整步与两个半步的误差估计继续使用现有
工作流。纯热模式只比较温度场的时间误差。失败后恢复温度、时间、热源和诊断。

纯热检查点使用现有版本 22 的序列化结构，力学历史集合为空；新增物理模式、
单元类型、热边界与界面参数进入模型签名，因此不能用热力耦合检查点恢复纯热
模型。固定残量缩放在纯热模式只要求 temperature_residual_scale；耦合模式仍
要求温度和力学尺度成对给出。

## 边界和界面

支持定温、给定向内热流、对流、区域体热源及现有时间表。固定几何下参考与
当前表面相同。边界使用三点线积分或 3×3 面积分。未指定热边界的表面为绝热。

`[Contact]` 可只定义 `[thermal]`，使用固定几何上的面到面传热。
每个从侧积分点沿从侧法向投影到主侧候选面，至多选择一个候选；共用边界处不
重复计入积分点。没有有效投影时，问题构造明确失败。界面贡献对主从两侧使用
同一个积分测度，因此离散热流守恒。二次主侧和从侧都使用中间节点温度。
三维二阶面使用八个正权重节点邻域，先平均两侧完整二次温度插值和间隙，
再计算导热律与平均温差。邻域采用已有 QUAD8 采样规则，面积比例为角点
1/24、中间节点 5/24，并乘各采样点的真实表面测度。跨主侧面时先合并共享
节点贡献，平均温度导数完整进入切线。轴对称边和三维一阶面的原积分规则不变。

支持现有 gas_gap 或不依赖接触压力的 affine 导热律及其温度导数。
压力相关导热、机械接触、变形更新、界面移动、摩擦生热、辐射、相变潜热、
各向异性导热和移动介质对流均不在第一版范围内。

原生界面对比覆盖一、二阶轴对称匹配边、轴对称直边 2:1 非匹配划分、
固定气隙、二阶轴对称瞬态，以及三维一阶和畸变二阶匹配面。具体几何、
误差及离散识别见 `verification/thermal/contact.md`。局部测试另覆盖跨主侧面的
二阶邻域守恒和温度切线，不能据此声称任意曲面非匹配接口均已通过 Abaqus 对比。

## 输出与使用

Exodus 输出真实节点温度、受约束节点热反力、每个积分点的热流和坐标。
轴对称输出的 x、y 分量分别表示径向和轴向，z 分量为零。
纯热模式不输出位移和应力。瞬态工程历史提供区域最高温度、热源、储热、表面与
界面热流、定温热反力以及整体热平衡。两个半步被接受时，热率采用时间平均。

非匹配和曲面传热、独立温度相关比热、磁盘重启、多材料守恒与解析收敛的
具体通过范围见 [五项验证扩展](../verification/thermal/studies.md)。

完整可运行输入卡位于 `verification/thermal/`。例如：

```bash
fuelsim -i verification/thermal/dc3d20_transient.fsi
fuelsim -i verification/thermal/dcax8_contact.fsi
```
