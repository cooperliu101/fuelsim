# Abaqus 四节点轴对称单元热膨胀温度的独立探测

2026-09-07 原生计算确认：CAX4T 使用四节点算术平均温度，CAX4RT 使用
轴对称体积平均温度。不能把前者概括为所有一阶温度—位移耦合单元的规则。

## 探测设计

两份完整输入 `expansion_small.inp`、`expansion_finite.inp` 分别关闭和开启
几何非线性。每份包含一个 CAX4T 和一个 CAX4RT 单元，节点独立、几何重合，
所有位移均约束为零。几何节点按局部顺序为 `(1,0)`、`(2.1,0.1)`、
`(1.9,1.2)`、`(0.9,1)`，单位 m。材料的杨氏模量为 1 MPa，泊松比 0.25，
线膨胀系数为 1e-5/K，均为常数；不含塑性、蠕变或接触。

初始温度为 600 K。四个阶段依次仅将局部节点 1、2、3、4 设为 700 K，
其余节点设为 600 K。每阶段只有一个时间增量，温度直接规定，避免由热求解
误差或温度相关材料物性干扰反推。每阶段算术平均温度均为 625 K。

完全约束、各向同性热膨胀时三个正应力相等，剪应力为零，解析关系为：

```text
σ = -E α (T有效 - 600)/(1 - 2ν)
T有效 = 600 - σ/20
```

从弹性应变 `T有效 = 600 - ε弹性,rr/α` 独立反推可得到相同结果。
分析脚本同时检查两份原生输入和提取器散列、成功结束标志、全部节点温度与
零位移、应力各向同性，以及应力与弹性应变反推的一致性。

## 原生结果

下表在小应变与启用几何非线性的探测中相同；CAX4T 的四个材料积分点也相同。

| 单独升温的局部节点 | 算术平均温度/K | 轴对称体积平均温度/K | CAX4T 反推温度/K | CAX4RT 反推温度/K |
| --- | ---: | ---: | ---: | ---: |
| 1 | 625 | 622.272092559 | 625 | 622.272092559 |
| 2 | 625 | 629.236485139 | 625 | 629.236485139 |
| 3 | 625 | 627.540893676 | 625 | 627.540893676 |
| 4 | 625 | 620.950528626 | 625 | 620.950528626 |

CAX4T 三个正应力始终为 -500 Pa。CAX4RT 第一个阶段为 -445.441851187 Pa，
已可明显区分两种假设；四个阶段一起识别出完整的温度权重。

轴对称体积测度为 `dV = 2πr detJ dξ dη`，采用独立 3×3 Gauss 积分计算
`w_i = integral(N_i*dV)/integral(dV)`，得到：

```text
w = [0.222720925593457, 0.292364851386395,
     0.275408936764413, 0.209505286255735]
```

CAX4T 对应的识别权重为 `[0.25, 0.25, 0.25, 0.25]`。40 条材料点与阶段
记录中，相应假设的反推温度偏差均小于 1e-10 K，另一假设的最大偏差为
4.236485139 K。`comparison.tsv` 保留逐材料点结果，不用显示为零的舍入误差
声称数学上无限精度相同。

## 复现与边界

`run.ps1 -DestinationDirectory <输出目录>` 直接复制完整输入，用 Windows
Abaqus/Standard 3DEXPERIENCE R2018x 单处理器和完整输出精度计算；使用
仓库已有的 `../extract_b7_rz.py` 提取原生节点和材料点数据。本目录保存
输入、CSV、状态/消息文件和运行记录。`python analyze.py` 只读参考并计算
解析权重与误差，不求解有限元问题，也不生成输入卡。`SHA256SUMS` 约束本
目录的资料，并同时记录相邻原生提取器的散列。

这次有限应变探测的实际位移为零，所以当前体积与参考体积一致。它证明启用
几何非线性后仍有上述两类不同平均规则，但不能单独鉴定大变形后的体积平均
究竟使用哪种构形。常数膨胀系数的结论也不替代温度相关膨胀系数的独立探测。
单元中心插值温度与四节点算术平均温度在数值上完全等价，本试验不区分这两种
等价实现方式。不将本结论直接推广到三维八节点或其他一阶单元。

当前 Fuelsim 的 CAX4T 与 CAX4RT 已分别使用上述两种平均规则，本次无需
修改热膨胀算法。源码中“所有一阶单元使用算术平均”的过宽注释已收窄到 CAX4T。
