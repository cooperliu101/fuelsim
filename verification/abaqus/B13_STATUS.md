## 可复现文件与比较口径

- `b13_<组别>_<单元>.inp` 和对应 `_mesh.inc` 是 Abaqus 输入。
- `../fuelsim/transient_b13_<组别>_<单元>.fsi` 是完整的 Fuelsim 生产输入卡。
- `run_b13_pcmi.ps1` 在独立 Windows 临时目录运行 Abaqus，每次使用一个 CPU。
- `extract_b13_pcmi.py` 从 Abaqus 结果数据库提取完整时间历程。
- `_nodes.csv` 保存温度、两个位移分量、支承反力及热反力。
- `_points.csv` 保存四分量应力、弹性应变、塑性应变、蠕变应变、两个等效非弹性应变、积分点位置和体积。
- `_contact.csv` 保存节点接触压力、间隙、剪切应力、滑移和接触力。
- `_run.txt` 记录 Abaqus 版本、完成时间及输入和提取器散列值；参考文件列入 `SHA256SUMS`。

新检查程序逐时间步比较温度、位移、应力及各应变历史、压力、间隙、法向力；
含摩擦的一组还比较剪切应力、滑移和切向力。八节点单元使用恢复后的节点接触应力。
支承反力和规定温度边界的热反力已纳入验收。积分点位置和体积目前仅提取，
尚未纳入检查程序的外部比较指标。

误差同时输出整体相对二范数、相对峰值和最大逐点相对误差；张量剪切分量使用
张量内积权重。严格为零的参考值另检查绝对差值，不引入相对误差分母下限。
约束明确规定为零的位移分量先分别验证两侧绝对误差，再按解析零值处理。
极小非零参考值可能放大逐点百分比，但不能把全部零参考差异归为浮点噪声。
逐材料点诊断已确认，接触建立时 Abaqus 显式蠕变可因步初应力为零而给出
严格零增量，Fuelsim 隐式更新则因步末应力非零而产生实际蠕变。下表整体
误差仍表明存在实质差异，不能通过移除这些样本宣称通过。

## 已确认的差异与待处理项

1. Abaqus 对时间变化的体热源按时间区间平均；新 Fuelsim 输入卡已显式采用相同口径。
2. CAX4T 热膨胀使用四角点温度的算术平均值，其他材料物性仍在积分点求值。
   从 Abaqus 位移和弹性应变可反推这一温度；修正后 small/CAX4T 的应力整体误差
   从约 44.9% 降至约 0.783%；继续改为 NTS 热接触后为约 0.400%。
   局部非均匀升温解析解、历史更新及方向导数检查已通过。
   此规则与 [Abaqus 全耦合热应力分析文档](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEANLRefMap/simaanl-c-couptempdisp.htm)
   关于一阶单元使用单元常温度计算热膨胀的说明一致。
   后续畸变单元逐节点升温的独立原生探测确认：CAX4T 为算术平均，CAX4RT
   为轴对称体积平均；不能仅由“单元常温度”推断两者权重相同。当前实现
   已分别采用这两种规则，本次确认不改变综合例题的通过状态。证据与边界见
   [热膨胀温度鉴定](thermal_expansion_probe/README.md)。
3. 初次迁移中 Fuelsim 使用面到面热接触和节点到面机械接触；Abaqus 输入使用节点到面接触。
   对 small/CAX8RT 单独把 Abaqus 改为面到面接触时，温度最大差值从约 4.367 K
   降至约 0.110 K，但节点法向力的整体差异增大，因此不能只改 Abaqus 接触类型
   就宣称热机械离散均已一致。这项隔离实验不作为正式参考。
4. 用户已要求删除 `AGENTS.md` 中原有轴对称接触规定，并重新探测、首先实现
   Abaqus 的 node-to-surface。已增加可选 NTS 热接触并应用于全部十二张输入卡；
   四个独立 [B14 探测例题](B14_NTS.md) 通过 0.1% 门槛。八节点 small/finite
   温度整体误差降至约 0.000008%，但接触压力和非弹性历史尚未全部达标。
5. 本轮已独立鉴定并修正 CAX4T 的节点对角热容、导热系数角点温度、有限应变
   热传导整体体积比及增量中间构形梯度、当前构形体热源。三个 B15 探测通过。
   三个 CAX4T 原生参考的导热系数表温度间距由 2 K 缩至 0.2 K；物理函数及
   所有网格、材料、载荷和时间步不变。finite/CAX4T 的最大逐点误差为
   0.00652364%，全部指标通过。其余九套原生参考未细化。
6. 固定残量尺度解决了两项 CAX4T 的初始力学残量接近零时的求解停滞。
   直接采用回溯线搜索后，两项八节点完整综合计算分别约 42 s 和 32 s 完成；
   这是当前测试运行时间，仅用于解释原先的超时，不是与 Abaqus 的速度对比。
7. small/CAX4T 的原生日志从显式蠕变积分开始，之后可能切换为隐式；Fuelsim
   当前始终为后向欧拉隐式积分，按用户要求保留。integrated/CAX4T 已按用户
   要求在 Abaqus 正式输入中设置 `SMOOTH=0`，关闭接触平滑。其应力整体误差
   为 6.06231e-7%，所有场最大逐点误差为 0.000110656%，全部通过。
