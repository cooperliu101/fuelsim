# Fuelsim CAX4T 配对角点材料温度修正

本次根据 [Abaqus 原生探测](README.md)修改 Fuelsim CAX4T 的力学材料取温。
弹性模量、泊松比、塑性和蠕变参数使用配对角点温度；热膨胀仍使用四角点
算术平均温度。小应变和有限应变均修改，材料参数及其他单元的取温规则保持原定义。

## 算法及导数

Fuelsim 四个 Gauss 积分点按 `(-,-),(+,-),(+,+),(-,+)` 排列，与本地四角点
顺序相同。材料输入从 `sum(N_i*T_i)` 改为 `T_q`；空间位置仍为材料积分点。
对应温度链从 `dT_material/dT_i=N_i` 改为 `delta_qi`。

运动学仍使用六分量局部自动微分，本构仍使用四应变分量加温度的五分量播种，
最终闭式组装完整 12×12 切线。平均应变、平均面内应力、平均环向应力及其
跨积分点导数继续保留，不扩大到整单元自由度播种。

热膨胀通过独立的平均温度链计算，平均温度对每个温度自由度的导数为 `1/4`。有限
应变的旧材料温度同步改为已接受的对应角点温度，保留新旧平均热应变之差。
这避免只修改当前温度而使后续增量使用不一致的旧热应变。

导热系数原本已经采用角点温度，热容原本已经在节点取物性和温度变化率，
这些数值规则未改。热传导梯度继续由节点温度插值形成。塑性与蠕变耗散仍为
诊断量，本次没有新增耗散发热。

全局装配、已接受历史、稳态应力输出均复用同一 CAX4T 局部入口；瞬态输出、
检查点和恢复读取已接受历史，没有另外一套需要改动的材料取温算法。

## 局部验证

独立单元库完成完整构建，`ctest --test-dir build-elements -j4 --output-on-failure`
通过 **17/17**。新增 CAX4T 检查使用四个不同角点温度和两个加载增量，覆盖：

- 从应力和弹性应变反推 E 与 nu，分别排除插值温度取值。
- 同一积分点上塑性和蠕变同时产生增量，逐参数检查初始屈服应力、硬化斜率、
  蠕变系数和应力指数；每个参数替换为插值温度值时都必须产生可分辨差异。
- 随温度变化的热膨胀系数仍使用平均温度，并正确累计有限应变历史。
- 四个温度列与中心差分比较，残量调用与切线调用结果一致，已接受历史不可变。

CAX4T 和 CAX2T_GPS 的原始局部检查输出见 [local_checks.txt](local_checks.txt)。

| 路径 | 温度列最大相对差分误差 | 门槛 |
| --- | ---: | ---: |
| 小应变弹性 | 8.85616e-8 | 2e-7 |
| 小应变塑性与蠕变耦合 | 2.13262e-8 | 2e-7 |
| 有限应变弹性 | 3.03613e-8 | 2e-7 |

该专门材料温度检查关闭储热项，使小的导热温度导数不被大储热残量的差分
消减掩盖；已有耦合事务测试继续检查完整节点热容与混合方向导数，门槛不变。

CAX2T_GPS 继续使用插值材料温度，因此它与 CAX4T 的跨单元运动学投影检查
限定为不随温度变化的 E 和 nu，保留非均匀温度及温变平均热膨胀。其自身的

`1.330e-15` 和 `8.109e-16`，均通过原门槛。

## 生产入口对比

八张完整静态输入通过实际 `fuelsim -i <case.fsi>` 运行：小应变/有限应变
弹性、小应变/有限应变初始屈服应力、小应变/有限应变硬化斜率，以及有限应变
蠕变系数与指数。全部节点和四个材料积分点的接受增量参与比较，非零场分别
检查相对 L2、相对绝对峰值和最大逐点相对误差，门槛为 0.1%；物理零量另行
检查绝对误差。

弹性和塑性使用原生鉴定的已有六份参考。蠕变新增两份完整原生输入
`production_creep_coefficient_finite.inp` 与 `production_creep_exponent_finite.inp`：
统一从 600 K、零位移开始，首个 0.1 s 增量达到既定四角温度和 0.1 mm 轴向
伸长，随后保持至 1 s，蠕变从首增量启用。两程序均使用后向欧拉。
原鉴定参考的禁用蠕变预加载及两段步长路径保持不变，不拿它们直接作为生产
路径的全历史参考。新参考的原生计算已经成功完成。

八个生产对比全部通过，共比较 **304 个材料点时刻样本**及相同数量的节点
时刻样本。下表分别取各算例所有非零验收场的最大值，单位均为百分比。
原始检查器输出见 [production_checks.txt](production_checks.txt)。

检查范围为温度、非零位移、三个正应力和弹性应变分量，以及启用机制的三个
非弹性应变分量、等效历史和逐步增量。每个塑性或蠕变材料点在每个增量均须
实际激活。固定位移、剪切和未激活机制另用 SI 绝对门槛检查，位移为
`1e-13 m`、应力为 `1e-4 Pa`、应变为 `1e-13`，均通过。

这些探测规定全部节点温度和位移，鉴定的是材料参数取温及本构历史，不单独
鉴定自由热瞬态和自由位移的平衡求解。初始状态会应用零时刻温度约束，因此
两程序的初始温度也一致。弹性换温在固定接受时刻一致；不据此声称时间步
内部的连续温度插值路径也已鉴定。塑性、蠕变耦合及平均热膨胀的温度切线
另外由上述局部检查覆盖。

可在仓库根目录重现生产对比：

```bash
ctest --test-dir build -j4 -R '^fuelsim_cax4t_material_' --output-on-failure
```

如需重新生成两个新增蠕变原生参考，在 Windows PowerShell 中运行；脚本
逐字复制完整输入卡，不修改材料和加载定义：

```powershell
./verification/abaqus/cax4t_material_temperature_probe/run.ps1 -Cases production_creep_coefficient_finite,production_creep_exponent_finite
```

主工程采用 Release、ADlite 0.2.3、原 `moose` 环境 PETSc 和独立 Exodus，
开启 warnings-as-errors，完成 `cmake --build build --parallel 4`。
统一入口 `ctest --test-dir build -j4 --output-on-failure` 的 304 项检查通过；
唯一失败为验证矩阵新增一条后固定计数未同步。将已验证条目数由 186 改为
187 后重新编译检查程序，`ctest --test-dir build -j4 --rerun-failed
--output-on-failure` 通过该项，最终 **305 项全部通过**。修正计数没有改变
物理算法、参考结果或误差门槛。记录见 [regression_checks.txt](regression_checks.txt)。
