## 比较量与接触边界

B10.0、B10.1 和 B10.4—B10.11 比较每个接受时刻的全部节点温度、完整径向和轴向
位移向量、支承反力、底部轴向反力合量，以及九个材料积分点的应力、弹性应变、
塑性应变、蠕变应变和两个等效非弹性历史标量。要求指定的蠕变或塑性机制实际
激活。张量按 `[rr, zz, hoop, rz]` 排列，剪切项以权重 2 进入范数。

B10.2 和 B10.3 另比较节点接触法向力、法向合力、接触间隙、接触传热量和完整
温度、位移及应力场。B10.12 和 B10.13 在所有十个接受时刻比较节点法向力与
切向力的大小、接触间隙、累计切向滑移量、粘着或滑动状态，以及完整场量。
B10.13 还要求至少跨越两条 primary 主面线段，并出现正向滑动、反向滑动和
反向重新粘着。

Abaqus 对二次接触面的 `CPRESS` 接触压力和 `CSHEAR1` 剪切应力做节点恢复。
Fuelsim 通过独立的 `recovered_pressure` 和 `recovered_shear` 输出与其逐节点对比，
并继续检查原始节点接触力、间隙、滑移量和完整场量。恢复压力不能除以或乘以
一致节点面积来推断接触力。B10.2 和 B10.3 的无摩擦闭合接触仍比较原生接触压力。
恢复规则、剪切正负号以及 B10.14 的绝对误差验收范围见
[接触恢复验证记录](b114_cax8t_recovery_validation.md)。

输入中的 `slip_tolerance` 与 Abaqus 一样表示平均 secondary 从面的参考长度比例。
Fuelsim 先对二次边的参考弧长作三点积分，再把该比例换算为最大弹性滑移距离。
摩擦发热在这些例题中关闭。

## 复现与证据

五个受追踪的 Exodus 网格分别用于畸变探针、材料路径、闭合接触、有限滑移和恢复鉴定。
新增的几何生成脚本只生成后三类几何文件和 Abaqus 网格包含文件；每个物理问题
仍由完整、独立的 `.fsi` 和 `.inp` 输入卡定义。参考脚本为每个例题建立独立目录，
要求 Abaqus 状态文件明确报告正常完成后才提取节点、积分点和接触数据。各
`_run.txt` 保存版本、单处理器设置、完成时间及输入和提取脚本校验和。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verification\abaqus\run_b10_rz.ps1 `
  -Cases b100_cax8t_small_probe,b101_cax8t_finite_probe,b102_cax8t_small_contact,b103_cax8t_finite_contact,b104_cax8t_small_coupled,b105_cax8t_finite_coupled,b106_cax8t_small_creep,b107_cax8t_finite_creep,b108_cax8t_small_plastic,b109_cax8t_finite_plastic,b110_cax8t_small_thermal,b111_cax8t_finite_thermal,b112_cax8t_small_friction,b113_cax8t_finite_sliding `
  -DestinationDirectory C:\temp\fuelsim_cax8t_reference
```

```bash
cmake --build build --parallel 4
ctest --test-dir build -j4 -R 'cax8t' --output-on-failure
ctest --test-dir build -j4 --output-on-failure
```

零参考量不使用相对误差分母下限，而是分别检查温度、位移、应力、应变、反力、
间隙和传热量的绝对误差。表中结果只约束这些网格、材料参数和载荷路径，不能替代
其他曲面、网格和时间步的独立收敛研究。
