# 轴对称 node-to-surface 接触识别

2026-09-09 自动测试精简：规定全部位移与温度的接触算子探测按边拓扑各保留
一个代表，即 CAX4T 和 CAX8T。CAX4RT/CAX8RT 与对应完整积分输入在统一
单元名称和文件名后完全一致，不增加独立接触算子覆盖，转为手动识别资料。
四套完整输入与原生参考均保留；两种减缩积分单元与接触的生产组合继续由各自
B13 例题检查。下文四种单元的原始探测结果仍是历史证据。

本次先实现 Abaqus 术语中的 node-to-surface（NTS，节点到面）。四个 B14 生产
例题使用 CAX4T、CAX4RT、CAX8T、CAX8RT，均通过小于 0.1% 的比较要求。
这项结论仅适用于下述接触探测，不代表 B13 的十二个综合例题已经通过。

## 原生探测

Abaqus 3DEXPERIENCE R2018x 使用 `*Contact Pair, type=NODE TO SURFACE`，
保留默认有限滑移。使用不匹配的轴向界面网格，规定全部节点位移和温度，避免
体单元刚度和热算子差异干扰接触离散的识别。四个连续阶段分别为径向闭合、
轴向滑动、斜面或曲面变形，以及越过主表面下端点的小幅反向滑动。
法向罚刚度为 1e12 Pa/m，摩擦系数为 0.2，弹性滑移容差为 0.005，
界面热导为 1000 W/(m² K)，关闭摩擦发热。

原生结果支持以下实现：

1. 热传递在 secondary 温度角点计算。八节点单元的边中节点不传热。
2. 热节点面积沿当前角点连线积分线性形函数。长度 L、端点半径 r0、r1 对应
   `A0=pi*L*(2*r0+r1)/3` 和 `A1=pi*L*(r0+2*r1)/3`。
   曲面探测确认八节点单元的 secondary 边中节点不影响这一热面积。
3. 机械节点面积积分位移形函数；八节点单元使用二次曲线和二次形函数，包含
   边中节点。主表面投影仍使用相应的一次或完整二次几何。
4. 主表面端段外仍可投影和插值。实现使用 Abaqus `EXTENSION ZONE` 默认值
   0.1，即线性局部坐标范围向外延伸 10%；二次边坐标由 [-1,1] 延伸至首端
   -1.2 或末端 1.2。内部相邻段仍保持唯一归属，不重复装配。
5. 输入卡显式设 `slip_tolerance=0.005`，最大弹性滑移为该值乘 secondary
   平均边长；粘着刚度为 `mu*p/maximum_elastic_slip`。不依据误差拟合系数。

端段延伸默认值见 [Abaqus Contact Pair 参数说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEKEYRefMap/simakey-r-contactpair.htm)；
在 secondary 节点计算接触热流的说明见 [Abaqus GAPCON 文档](https://docs.software.vt.edu/abaqusv2025/English/SIMACAESUBRefMap/simasub-c-gapcon.htm)。
上述具体面积和插值规则以本目录保留的 R2018x 原生输出为数值证据。

## 比较结果

2026-09-07 运行完整输入卡，比较每个规定时间点的接触热反力，并在后三个阶段
比较压力、间隙、法向力、剪切应力、切向力及累计滑移。八节点单元的接触压力
和剪切应力使用恢复后的节点输出，与 Abaqus 输出口径一致。

| 单元 | 所有比较场的最大逐点相对误差 | 接触热反力最大逐点相对误差 |
| --- | ---: | ---: |
| CAX4T | 0.0180794% | 1.31e-12% |
| CAX4RT | 0.0180794% | 1.27e-13% |
| CAX8T | 0.0200141% | 2.74e-13% |
| CAX8RT | 0.0200141% | 2.74e-13% |

检查程序同时要求整体相对二范数、相对绝对峰值和最大逐点相对误差均小于
0.1%。严格为零的参考值单独检查绝对差值，不设置相对误差分母下限。
全部规定温度和位移另检查绝对误差。
逐字段数值保存在 `b14_nts_<单元>_comparison.txt`，包含零参考值数量、
最大绝对差值所在点及产生最大逐点误差的实际值与参考值。

体导热系数设为 1e-12 W/(m K)，因此非界面节点只有可忽略的体导热反力。
这些节点分别要求两个程序的热反力绝对值小于 1e-8 W，不将其浮点量级的
相对误差混入接触热流指标；所有界面温度角点仍执行严格相对误差检查。

本例全部自由度受约束。Abaqus 在第一个阶段输出的 CPRESS 为约 1e-6 Pa，
与其 COPEN 约 -1e-6 m 及给定 1e12 Pa/m 罚刚度不符；第二阶段相同间隙
输出约 1e6 Pa。原因尚未完全定位，所以首阶段机械输出不作为有效参考，
不用于推导压力定律；该阶段热反力仍参与检查。后三阶段完整保留机械比较。

## 实现与验收边界

局部检查覆盖当前面积、法向和投影导数，自动微分 Jacobian 与中心差分，
重复残量调用，以及两侧热流和反力守恒。八节点局部检查另独立改变 secondary
边中节点，验证其不会改变 NTS 热面积。

本次未鉴定主表面尖角的 Abaqus 默认平滑规则、超出整个接触面后的自然释放，
或用户指定的其他 `EXTENSION ZONE`。当前超出所有候选范围仍明确拒绝试探状态。
对强曲率二次端段，参数延伸与 Abaqus 实际长度延伸的等价性尚未验证。
因此不能把本次结果外推为 Abaqus NTS 的全部组合行为。

## 复现入口

`b14_nts_<单元>.inp`、其引用的 `b13_small_<单元>_mesh.inc`、三个 CSV 参考、
`_run.txt` 和提取器均通过 `SHA256SUMS` 追踪。`run_b14_nts.ps1` 每次创建独立
Windows 临时目录，以一个 CPU 计算并提取完整历史。`generate_b14_nts_meshes.py`
只创建网格及逐节点边界集合，不生成生产输入卡。

```bash
ctest --test-dir build -j4 -R 'b14_nts_' --output-on-failure
```

CTest 逐字复制提交的 `../fuelsim/transient_b14_nts_<单元>.fsi`，运行实际
`fuelsim -i <case.fsi>`，再使用仅依赖 Exodus 读取的检查程序比较原生参考。
