## 独立热容探测

`nonaffine_capacity/` 使用原有 C3D8T 非仿射输入重新计算。规则参考单元的
一个单位升温率节点，2018 热反力为 518957.86718750023 W；严格初始节点质量
预测为 375000 W；2025 热反力为 380458.15301823016 W。
2025 的 16 个活跃样本与以下候选权重吻合，相对误差不超过 4.22e-15：

`rho_initial*cp*reference_weight_q*(V_current/V_reference)/J_q`。

这里 `J_q` 是真实积分点当前与参考体积之比。此式是从该探测推断的离散规则，
不是对所有单元的通用声明。非仿射变形时局部体积比与整体体积比不同，因而
不能把“使用当前密度”直接等同于“固定每个节点初始质量”。Fuelsim 保留后者。

B5.7 原生输入的初始节点温度为 310 至 450 K，平均为 380 K；原输入密度表
在该温度给出 1920 kg/m³。局部比较程序据此设置初始密度，仍在当前温度计算
比热。残量相对误差为 1.21e-15，切线相对误差为 8.07e-11，原门槛未变。
B5.4 删除了旧的“必须偏离初始质量”断言；直接原生比较门槛保持不变。

## 复现与记录

各子目录的 PowerShell 程序从本目录复制完整原生输入到 Windows 临时目录，
调用 2025 求解并提取 CSV。`production/` 保存批量算例，`gps_1d/` 保存径向算例，
`b13/` 与 `b544/` 保存相应专用运行入口。各运行记录中的 Windows 工作路径
用于追溯原生输出数据库。输入同一性表和本目录 SHA256SUMS 覆盖原生输入、
脚本及提取结果；旧 2018 文件未被替换。

完整 Fuelsim 回归命令为 `ctest --test-dir build -j8 --output-on-failure`。
尚未通过的比较明确记录为 `unverified`，不能据此声称全部有限应变验收完成。

原生执行日志保存在 `run_logs/`。首次批量任务中 B6.1 和 B5.26 缺少辅助文件，
补齐原文件后由 retry 程序成功重算；第一次非仿射探测的提取程序不兼容 Python 3，
转换 CSV 写入模式后重新完成提取。B5.4/B5.7 当时通过 Windows 默认 `abaqus`
入口运行，执行日志确认版本为 2025；保存的运行程序已固定到 `abq2025.bat`。

进一步独立探测已识别四种一阶单元的不同规则，见
[密度与热容实现探测](density_capacity_probe/README.md)。该目录新增了两张专用原生输入，
不属于 input_identity.tsv 中的旧输入重算集合。
