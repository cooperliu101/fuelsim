# B5.23 与 B11.4 的分项容差授权

2026-09-14 用户先要求“后两个按建议实施”，随后要求“b5.23容差放大一点”。
本次仅调整结果比较器。两个 B14 的设置保持不变；生产算法、固定初始质量定义、
物理输入、网格、时间步和原生参考不变。诊断依据见 [四项诊断报告](four_case_diagnosis.md)。

## 当前门槛

| 例题与指标 | 当前门槛 |
|---|---|
| B5.23 节点热反力相对二范数 | <0.5%，不变 |
| B5.23 节点热反力相对峰值 | <1%，本次由 0.5% 调整 |
| B5.23 节点热反力最大逐点相对误差 | <1%，或逐点绝对误差 <0.05 W，沿用上次授权 |
| B11.4 规定状态下节点热反力绝对误差 | <2e-11 W，沿用上次授权 |

B5.23 的峰值特例仅用于该例题的节点热反力。其他例题和其他物理量仍使用各自
原有门槛；每个非零参考样本仍执行相对或绝对条件，不设置分母下限，不删减样本。
零参考、接触量与能量门槛不变。

B11.4 仅匹配 `b114_cax8t_recovery_nodes.csv`，且必须为 `probe` 规定状态绝对
比较模式。其他轴对称例题仍使用原有热反力绝对门槛，其他物理量不受影响。

## 历史结果

仅调整 B5.23 逐点门槛时，完整测试为 311/314 通过，耗时 112.96 秒。
B11.4 已通过；B5.23 仍因相对峰值 0.72853988% 超过当时的 0.5% 而失败。
本次新增的峰值调整针对这一剩余失败。此前记录保存在
[two_case_qualification](two_case_qualification/)，不代表本次调整后的结果。

此前建议遗漏了相对峰值也超过 0.5%，这一说明已经纠正；本次是在用户追加授权后
调整峰值门槛。相对二范数实测 0.26120941%，继续受 0.5% 原门槛约束。

B11.4 最大热反力绝对误差为 1.43067424e-11 W。使用逐字相同的临时节点参考、
但不匹配专项文件名时，比较程序恢复 1e-11 W 默认门槛并按预期失败；证据见
[默认门槛检查](two_case_qualification/b114_default_gate_check.log)。

## 本次验证结果

完整测试使用 `ctest --test-dir build -j8 --output-on-failure`，312/314 通过，
耗时 112.98 秒。B5.23 与 B11.4 均通过；剩余未通过项是 B14 的 CAX4T 和 CAX8T
节点到面热接触例题，未在本次调整范围内。

B5.23 节点热反力相对二范数为 0.26120941%，相对峰值和最大逐点相对误差均为
0.72853988%，满足当前分项门槛。
