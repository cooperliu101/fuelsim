# C3D20RT 中等规模圆柱热力接触例题

本例题由已有 B5.56 C3D20T 输入建立独立的 C3D20RT 输入，保留网格、材料、
载荷、时间步和接触参数。参考程序为实际运行的 Abaqus 2025，生产程序为
`fuelsim -i`。这是手动运行的性能和全字段比较例题，不加入轻量自动测试套件。

## 模型和比较范围

| 项目 | 数量或设置 |
|---|---|
| 二十节点体单元 | 1,152 个，燃料 640 个、包壳 512 个 |
| 位移节点 | 5,969 个，每个节点有三个方向的位移 |
| 温度自由度 | 1,617 个，只在单元角点求解 |
| Fuelsim 耦合自由度 | 19,524 个 |
| 活跃材料积分点 | 每个单元 8 个，共 9,216 个 |
| 接触节点 | 燃料外表面 416 个 |
| 时间离散 | 0 至 1 s，共 20 个 0.05 s 增量 |
| 力学与接触 | 有限应变、面到面有限滑移、库仑摩擦系数 0.002 |
| 直接求解器 | Fuelsim 使用 PETSc 提供的 MUMPS；Abaqus 使用自身稀疏直接求解器 |

上述节点和体单元数量指用户网格。Abaqus 另外生成 3,072 个接触内部节点和
1,024 个接触内部单元，原生 `.dat` 记录总变量数为 23,892，包含内部变量。
字段比较覆盖全部用户网格节点和体单元材料积分点，不把这些内部接触对象
重复计入几何节点或体单元数量。

网格直接复用 `verification/moose/m58_integrated_hex20_mesh.e`。燃料高度 5 mm，
外半径 4.12 mm；包壳从 z=-1 mm 延伸至 6 mm，外半径为 4.692 mm。
圆周由平面单元面逼近，中间节点的位置以网格文件为准。

初始温度为 600 K，包壳外表面温度固定为 600 K。燃料体热源基值为
2e8 W/m³，随既有分段线性函数变化，并按时间区间平均施加。
包壳内、外压力基值分别为 0.5 MPa 和 2 MPa；燃料和包壳顶端轴向位移
在 1 s 分别达到 0.6 mm 和 0.02 mm。包壳同时启用 J2 塑性和 Norton 蠕变。
完整参数、底端约束和载荷历史均在独立输入卡中。

Fuelsim 热容遵守固定初始质量规则。Abaqus 原生热离散保留原样，不能为改善
比较结果改变 Fuelsim 的质量契约。本例题未获任何专门容差授权；其他例题的
`qualified` 状态和例外容差不适用于本例题。

## 提交 `149dea5` 的接触优化

1. 主接触面只从最近有效投影所在面向有圆形区域重叠的相邻面扩展。
   原来的全表面扫描会把闭合圆柱背面的投影也计入，从而产生错误的间隙和传热。
   热接触的局部自由度和切线矩阵同步缩小到实际参与的面；全局稀疏矩阵仍为所有
   潜在接触候选保留位置。
2. 八节点曲面投影先用普通双精度求两个局部坐标，再通过投影方程的隐式导数
   求坐标对节点位置的导数。这样避免在每次局部 Newton 迭代中反复计算自动
   微分，也避免毫米尺度曲面上近零导数的消减误差阻止收敛。投影值的收敛要求未放宽。
3. 先用整个约束的平均参考法向确定一个切向，再投影到各个面，并随曲面变形
   传递。这也避免一个面正对全局坐标轴时产生零切向量。圆柱正、负 x 方向
   34 个节点的相邻面原先选择了相反切向方向，平均后轴向滑移丢失。

前两项修改后、第三项修改前的完整计算显示：累计滑移相对 L2 误差为
28.5704%，切向接触力为 14.3941%。该结果用于定位缺陷，不能作为通过验收的依据。
局部回归分别覆盖毫米尺度投影的残量一致性和导数、无关背面不参与接触、
相邻折面上的轴向滑移及其几何导数。

## 本次误差修正

热接触现在分别计算间隙平均和温度平均。有限滑移时，导热律采用温度角点
对应的机械平均间隙，并沿次接触面的当前法向计算；传热面积和温度积分
仍包含原有的边中点采样。两个平均值的面积导数均进入切线矩阵。

另外，Abaqus 的燃料导热系数表按原公式 `3824/T + 0.61` 加密至 660 K，
覆盖本例题的实际温度范围，并已重新计算全部二十帧参考。两张 Fuelsim
输入卡采用更严格的非线性停止条件，以降低自由节点的未平衡力。
固定初始质量、材料参数、载荷与比较门槛均未改变。指定原生节点历程的
隔离诊断、交叉比较及复现命令见 [误差定位与修正](accuracy_refinement/README.md)。

## 比较方法

`extract.py` 从原生 ODB 提取全部二十帧，而不是只取最终帧：

- 节点参考共 119,380 行，包含温度、位移和反力；角点温度与插值温度分别比较。
- 接触参考共 8,320 行，包含间隙、压力、法向力、切向力、累计滑移和传热量。
- 材料点参考共 184,320 行，包含应力、弹性应变、塑性应变、蠕变应变及等效历史。

材料点对应关系仅由 Abaqus 当前节点坐标重建，再与其原生积分点坐标匹配，
逐单元检查一一对应。Abaqus 工程剪应变除以二后与 Fuelsim 张量剪应变比较。
非活跃的 q8 至 q26 输出必须为 NaN。

`compare.py` 只读取生产 Exodus 和参考 CSV，不调用求解器。标量比较整体相对误差（相对 L2，即差值平方和的平方根除以参考值平方和的平方根）、
相对绝对峰值和最大逐点相对误差；三维向量和六分量张量按现有分组指标比较。
标量峰值为两边最大绝对值之差除以最大参考绝对值；向量与张量峰值为最大
差值范数除以最大参考范数，张量使用按六个独立分量排列的欧氏范数。
逐点相对误差不设置分母下限；零参考单独使用脚本中明确列出的绝对容差。
原始存储值全部保留，包括理论约束为零时 Abaqus 输出的极小非零位移。
ODB 帧时间的 5e-8 s 匹配容差仅处理其单精度时间存储，不影响场值门槛。

`comparison.csv` 同时列出所有帧和最终帧的完整指标、最差样本及其参考值；
`coverage.csv` 逐步记录两种非弹性机制是否在同一个材料点同时产生增量。
比较程序在任何一项不满足严格 0.1% 要求时返回 1，并保留全部指标。

## 复现

在仓库根目录执行生产计算和只读比较：

```bash
env OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  taskset -c 0 build/fuelsim \
  -i verification/fuelsim/transient_c3d20rt_medium_friction.fsi
python3 verification/abaqus/2025/c3d20rt_medium/compare.py \
  verification/fuelsim/transient_c3d20rt_medium_friction_results.e
```

参考重新计算使用 Windows PowerShell，参数为此目录的 Windows 或 WSL UNC 路径：

```powershell
.\run.ps1 -SourceDirectory <本目录>
```

`-ExistingWork <已完成任务目录>` 先核对输入哈希和原生成功状态，再只执行提取。
日常 CTest 不启动 Abaqus。`SHA256SUMS` 保存输入、脚本和压缩参考的哈希，
`provenance.txt` 保存计算环境与输入来源。

性能计算使用两张另行提交的完整 `*_timing` 输入卡，仅关闭场和历史文件输出，
物理输入及时间步保持一致。分别在没有编译、自动测试或其他求解任务时单独计时，固定一个
处理器并将线程数设为 1。Abaqus 运行命令为 `run.ps1 -Timing`；Fuelsim 使用
`transient_c3d20rt_medium_friction_timing.fsi`。外部总耗时与程序内部分析耗时分开记录。
Windows 原生 Abaqus 与 WSL Fuelsim 的环境不同，单次运行只能代表本机本次测量。
