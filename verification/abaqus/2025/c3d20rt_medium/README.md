# C3D20RT 中等规模圆柱热力接触例题

本例题由已有 B5.56 C3D20T 输入建立独立的 C3D20RT 输入，保留网格、材料、
载荷、时间步和接触参数。参考程序为实际运行的 Abaqus 2025，生产程序为
`fuelsim -i`。这是手动运行的性能和全字段比较例题，不加入轻量自动测试套件。

## 模型和比较范围

| 项目 | 数量或设置 |
|---|---|
| 二十节点体单元 | 1,152 个，燃料 640 个、包壳 512 个 |
| 位移节点 | 5,969 个，每个节点有三个方向的位移 |
| 温度自由度 | 1,617 个，只在单元角点求解 |
| Fuelsim 耦合自由度 | 19,524 个 |
| 活跃材料积分点 | 每个单元 8 个，共 9,216 个 |
| 接触节点 | 燃料外表面 416 个 |
| 时间离散 | 0 至 1 s，共 20 个 0.05 s 增量 |
| 力学与接触 | 有限应变、面到面有限滑移、库仑摩擦系数 0.002 |
| 直接求解器 | Fuelsim 使用 PETSc 提供的 MUMPS；Abaqus 使用自身稀疏直接求解器 |

上述节点和体单元数量指用户网格。Abaqus 另外生成 3,072 个接触内部节点和
1,024 个接触内部单元，原生 `.dat` 记录总变量数为 23,892，包含内部变量。
字段比较覆盖全部用户网格节点和体单元材料积分点，不把这些内部接触对象
重复计入几何节点或体单元数量。

网格直接复用 `verification/moose/m58_integrated_hex20_mesh.e`。燃料高度 5 mm，
外半径 4.12 mm；包壳从 z=-1 mm 延伸至 6 mm，外半径为 4.692 mm。
圆周由平面单元面逼近，中间节点的位置以网格文件为准。

初始温度为 600 K，包壳外表面温度固定为 600 K。燃料体热源基值为
2e8 W/m³，随既有分段线性函数变化，并按时间区间平均施加。
包壳内、外压力基值分别为 0.5 MPa 和 2 MPa；燃料和包壳顶端轴向位移
在 1 s 分别达到 0.6 mm 和 0.02 mm。包壳同时启用 J2 塑性和 Norton 蠕变。
完整参数、底端约束和载荷历史均在独立输入卡中。

Fuelsim 热容遵守固定初始质量规则。Abaqus 原生热离散保留原样，不能为改善
比较结果改变 Fuelsim 的质量契约。本例题未获任何专门容差授权；其他例题的
`qualified` 状态和例外容差不适用于本例题。

## 本轮生产代码修改

1. 主接触面只从最近有效投影所在面向有圆形区域重叠的相邻面扩展。
   原来的全表面扫描会把闭合圆柱背面的投影也计入，从而产生错误的间隙和传热。
   热接触的局部自由度和切线矩阵同步缩小到实际参与的面；全局稀疏矩阵仍为所有
   潜在接触候选保留位置。
2. 八节点曲面投影先用普通双精度求两个局部坐标，再通过投影方程的隐式导数
   求坐标对节点位置的导数。这样避免在每次局部 Newton 迭代中反复计算自动
   微分，也避免毫米尺度曲面上近零导数的消减误差阻止收敛。投影值的收敛要求未放宽。
3. 先用整个约束的平均参考法向确定一个切向，再投影到各个面，并随曲面变形
   传递。这也避免一个面正对全局坐标轴时产生零切向量。圆柱正、负 x 方向
   34 个节点的相邻面原先选择了相反切向方向，平均后轴向滑移丢失。

前两项修改后、第三项修改前的完整计算显示：累计滑移相对 L2 误差为
28.5704%，切向接触力为 14.3941%。该结果用于定位缺陷，不能作为通过验收的依据。
局部回归分别覆盖毫米尺度投影的残量一致性和导数、无关背面不参与接触、
相邻折面上的轴向滑移及其几何导数。

## 比较方法

`extract.py` 从原生 ODB 提取全部二十帧，而不是只取最终帧：

- 节点参考共 119,380 行，包含温度、位移和反力；角点温度与插值温度分别比较。
- 接触参考共 8,320 行，包含间隙、压力、法向力、切向力、累计滑移和传热量。
- 材料点参考共 184,320 行，包含应力、弹性应变、塑性应变、蠕变应变及等效历史。

材料点对应关系仅由 Abaqus 当前节点坐标重建，再与其原生积分点坐标匹配，
逐单元检查一一对应。Abaqus 工程剪应变除以二后与 Fuelsim 张量剪应变比较。
非活跃的 q8 至 q26 输出必须为 NaN。

`compare.py` 只读取生产 Exodus 和参考 CSV，不调用求解器。标量比较整体相对误差（相对 L2，即差值平方和的平方根除以参考值平方和的平方根）、
相对绝对峰值和最大逐点相对误差；三维向量和六分量张量按现有分组指标比较。
标量峰值为两边最大绝对值之差除以最大参考绝对值；向量与张量峰值为最大
差值范数除以最大参考范数，张量使用按六个独立分量排列的欧氏范数。
逐点相对误差不设置分母下限；零参考单独使用脚本中明确列出的绝对容差。
原始存储值全部保留，包括理论约束为零时 Abaqus 输出的极小非零位移。
ODB 帧时间的 5e-8 s 匹配容差仅处理其单精度时间存储，不影响场值门槛。

`comparison.csv` 同时列出所有帧和最终帧的完整指标、最差样本及其参考值；
`coverage.csv` 逐步记录两种非弹性机制是否在同一个材料点同时产生增量。
比较程序在任何一项不满足严格 0.1% 要求时返回 1，并保留全部指标。

## 当前完整结果（2026-09-16）

两套程序均完成 20 个时间步。Fuelsim 接受 20 步，没有拒绝时间步或缩小步长重试。
最后一个时间步，两边全部 4,096 个包壳材料积分点都同时产生正的塑性与蠕变增量；
Fuelsim 的 416 个接触节点全部有效，并全部进入摩擦滑动。

**全字段严格 0.1% 比较尚未通过。** 下表均覆盖二十帧，单位为百分数。
完整原始指标见 [comparison.csv](comparison.csv)，覆盖检查见 [coverage.csv](coverage.csv)。

累计滑移从 28.5704% 降至 0.00357593%。修正前的完整指标保存在
[before_tangent_comparison.csv](before_tangent_comparison.csv)。

位移和累计滑移的 100% 最大逐点值分别对应 Abaqus 的 6.86e-37 m 和
4.86e-21 m 原生值；Fuelsim 对应值为零。机械反力最大逐点相对误差为
12,099.51%，其参考范数为 1.35e-13 N，绝对差为 1.64e-11 N。
脚本保留这些原始数值，没有用分母下限掩盖它们。机械反力的整体相对峰值
仍为 0.142392%，零参考最大绝对差为 0.000487153 N，不能只用极小参考值
解释全部反力比较失败。

还存在需要继续查明的有限差异：界面总传热量最大逐点误差为 3.35888%
（0.15 s，参考 0.543103 W，绝对差 0.0182422 W）；燃料应力最大逐点
误差为 2.48135%（0.15 s，参考张量范数约 244,993 Pa，差约 6,079 Pa）。
这些不是机器精度下的零量，不能宣布达标。本轮没有通过隔离探测证明它们
来自热容量、曲面传热或其他某一个离散算子，因此也不把它们归因于已证明的
质量契约差异。

Release 完整构建通过。最终统一回归中 **325/326 项通过，150.74 s**；
唯一失败是新增说明后 `C3D20RT_STATUS.md` 的文件校验值未更新。
同步本次修改的两份说明文档校验值后，校验测试单独重新运行并通过。
全部数值、多进程及文件校验检查现均通过，没有把单项重新运行描述为
整套回归再次执行。统一回归命令如下：

```bash
env OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  taskset -c 0-7 ctest --test-dir build -j8 --output-on-failure
```

完整日志见 [full_ctest.txt](full_ctest.txt)，文件校验重新运行记录见
[reference_hash_ctest.txt](reference_hash_ctest.txt)。本次自动测试包含已有小例题的已授权
专门容差；它不等价于这个新中等规模例题通过严格 0.1% 比较。
新增毫米尺度热投影测试的中心差分相对误差为 5.01e-8，残量带导数与不带导数
调用逐项相同。折面接触、无关背面排除和原有双进程逐自由度等价性测试均通过。
对称和非对称折面接触的中心差分误差分别为 6.15e-9 和 5.76e-8，均低于
原定的 2e-5 门槛。测试面具有唯一最短边，且当前投影远离主面切换位置；
等长最短边处的圆半径取最小值操作本身不可微分，不用于检验唯一导数。

## 修改前后的受控接触计时

原提交 `7a14b9d` 在本中等规模例题的初始接触投影中报错，不能计算有意义的
完整历程加速比，原始输出见 [before_initial_failure.txt](before_initial_failure.txt)。
另用已有六单元首增量例题比较同一构建环境下的旧、新二进制，
完整输入卡和网格逐字复制到隔离目录，保留相同输出。固定 CPU 0、单线程，
两版各预热一次，然后交替测量五次；计时期间没有编译、自动测试或其他求解任务。

| 耗时中位数，秒 | 修改前 | 修改后 |
|---|---:|---:|
| 外部完整进程 | 3.460334 | 2.335864 |
| Fuelsim 内部 | 2.470160 | 1.368581 |

外部耗时减少 **32.50%**，对应 **1.4814 倍**加速，五次均更快。
两版均接受一个增量，执行 14 次非线性迭代、22 次残量计算和 14 次切线计算，
没有缩小步长重试。这是六单元接触首增量的结果，不推广为中等规模加速比。
逐次数据、输入校验和二进制校验分别见 [small_runs.csv](small_runs.csv)、
[small_inputs.sha256](small_inputs.sha256)、[small_executables.txt](small_executables.txt)。

两版结果逐项检查了 1,607 个时间、节点和单元字段数组，有限值与 NaN 位置相同。
最大字段峰值归一化差为 3.89e-9；这是旧、新版本的数值一致性诊断，不替代
Abaqus 的逐点误差验收。完整数据见 [small_field_comparison.csv](small_field_comparison.csv)。

## 中等规模单核计时

最终代码、同一台 Intel Core i9-13980HX 计算机、两边各固定一个处理器、关闭
场与历史文件输出，分别独立运行一次。计时期间没有本任务的编译、自动测试或
其他求解进程。逐项记录见 [medium_timing.csv](medium_timing.csv)。

| 程序 | 外部完整进程，秒 | 程序报告的内部时间，秒 |
|---|---:|---:|
| Fuelsim，WSL2，MUMPS | 412.11 | 410.26 |
| Abaqus 2025，Windows 原生 | 405.75 | 1 |

本次 Fuelsim 外部耗时比 Abaqus 增加 **1.57%**。
这是一次测量，两边操作系统与运行环境不同；没有验证 Windows 与 WSL 逻辑 CPU
编号对应同一个物理核心，因此不能据此推导其他机器或其他规模的固定加速比例。
Abaqus 原生求解进程的实际处理器掩码为 1，证据见
[abaqus_timing_affinity.txt](abaqus_timing_affinity.txt)。

Fuelsim 共接受 20 步，执行 86 次非线性迭代、106 次残量计算和 38 次切线计算，
没有失败重试。打开和关闭结果输出时，最终区域、接触及求解次数共 18 项汇总值
逐字相同，见 [output_mode_comparison.txt](output_mode_comparison.txt)。
Abaqus 同样在全部二十个 0.05 s 增量后到达 1 s，原生状态记录为
[c3d20rt_medium_friction_timing.sta](c3d20rt_medium_friction_timing.sta)。

Fuelsim 内部时间来自 `total_seconds`，Abaqus 内部时间来自 `.dat` 的
`JOB TIME SUMMARY` 中 `WALLCLOCK TIME`。它们各自的计时范围不同，不代替
外部进程计时。带完整字段输出的准确性计算曾与编译或自动测试同时运行，
对应的 `fuelsim_time.txt` 和 `abaqus_time.txt` 只作为运行记录，不用于性能结论。

**当前结论：新中等规模例题可以完整计算并与 Abaqus 逐字段比较，但尚未达到
全部误差小于 0.1% 且快于 Abaqus 的整体要求。** 小接触例题的 32.50%
加速，以及本中等规模测量和误差边界分别报告。

## 复现

在仓库根目录执行生产计算和只读比较：

```bash
env OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  taskset -c 0 build/fuelsim \
  -i verification/fuelsim/transient_c3d20rt_medium_friction.fsi
python3 verification/abaqus/2025/c3d20rt_medium/compare.py \
  verification/fuelsim/transient_c3d20rt_medium_friction_results.e
```

参考重新计算使用 Windows PowerShell，参数为此目录的 Windows 或 WSL UNC 路径：

```powershell
.\run.ps1 -SourceDirectory <本目录>
```

`-ExistingWork <已完成任务目录>` 先核对输入哈希和原生成功状态，再只执行提取。
日常 CTest 不启动 Abaqus。`SHA256SUMS` 保存输入、脚本和压缩参考的哈希，
`provenance.txt` 保存计算环境与输入来源。

性能计算使用两张另行提交的完整 `*_timing` 输入卡，仅关闭场和历史文件输出，
物理输入及时间步保持一致。分别在没有编译、自动测试或其他求解任务时单独计时，固定一个
处理器并将线程数设为 1。Abaqus 运行命令为 `run.ps1 -Timing`；Fuelsim 使用
`transient_c3d20rt_medium_friction_timing.fsi`。外部总耗时与程序内部分析耗时分开记录。
Windows 原生 Abaqus 与 WSL Fuelsim 的环境不同，单次运行只能代表本机本次测量。
