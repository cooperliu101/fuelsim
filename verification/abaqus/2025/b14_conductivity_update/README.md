# B14 体导热系数与 Abaqus 2025 参考更新

2026-09-14 用户授权实施诊断建议。正式 CAX4T、CAX8T 输入在 Fuelsim 和
Abaqus 中同时将体导热系数从 1e-12 改为 1e-6 W/(m K)。接触热导仍为
1000 W/(m² K)，网格、规定温度与位移、四个加载阶段、摩擦和接触参数保持不变。
生产算法没有修改。原量级下的原生热导截断证据见
[独立诊断](../four_case_diagnosis.md)，该历史探测及旧版本结果仍可追踪。

所有界面节点热反力继续使用相对二范数、相对峰值、最大逐点相对误差均小于
0.1% 的门槛。非界面的体导热不再近似为零，因此改为比较 Fuelsim 与 Abaqus
节点热反力之差，绝对误差仍必须小于 1e-8 W。保留全部样本和零参考检查。

力学比较范围与门槛保持不变：第一阶段的原生力学输出仍沿用既有排除约定，
第二至第四阶段比较间隙、压力、剪切、法向力、切向力和滑移，三个相对指标
均小于 0.1%。因此通过结论仅适用于该规定状态识别范围，不扩大为第一阶段
力学或任意接触路径均已验证。CAX4RT/CAX8RT 手动资料保持原设置。

## 原生重算

在 Windows PowerShell 中运行：

```powershell
.\run_b14_nts.ps1 -Cases b14_nts_cax4t,b14_nts_cax8t -DestinationDirectory $PWD.Path -Cpus 8
```

工作目录为 `verification/abaqus/2025/production`。两个任务顺序执行，每个使用
8 核，读取已保存的完整 `.inp`，不生成或改写问题定义。运行记录保存输入及
提取脚本的 SHA256，输出精度为 full；正式节点、材料点、接触结果与完成记录
保存于该 production 目录。日常 CTest 仅读取这些参考，不启动 Abaqus。
