# Abaqus 2025 非均匀变形密度与热容实现探测

2026-09-13 使用 Windows Abaqus 2025 RELr427 完成两次独立原生计算。
以下结论来自输出热反力与独立几何积分的比较，不代表读取了 Abaqus 源码。
本次只识别热容，不修改 Fuelsim 生产质量定义，也不据此推断重力质量或位移惯性。

## 主要结论

四种一阶耦合单元的热容规则并不相同。原有“当前密度乘当前热容权重”
不足以唯一描述其离散，必须区分密度所用的温度与几何修正。

记节点 i 的热容系数为 C_i，热容反力为 C_i*(T_i-T_i_old)/dt。
以下量均可由完整输入和导出的节点位移独立计算：

- rho(T) 为原生输入的密度表，cp(T_i) 为当前节点温度的比热。
- T0_mean 为初始节点温度的算术平均，rho0=rho(T0_mean)。对本次一阶温度插值，
  该平均也等于自然坐标中心的初温，探测不能区分这两种等价实现。
- V0、V 为初始与当前体积，Jbar=V/V0。
- w0_i 为与角点 i 配对的参考 Gauss 权重，J_i 为该 Gauss 点真实当前与参考体积比。
- L_i=integral_current(N_i*dV)，即当前一致热容矩阵的几何行和。
- Fbar=I+u^T*G0，G0 是参考体积平均形函数梯度；JF=det(Fbar)。

| 单元 | 原生数据支持的热容系数 C_i |
|---|---|
| C3D8T | rho0 * cp(T_i) * w0_i * Jbar / J_i |
| CAX4T | rho0 * cp(T_i) * L_i / Jbar |
| C3D8RT | rho(T_i) * cp(T_i) * L_i / JF |
| CAX4RT | rho(T_i) * cp(T_i) * L_i / Jbar |

在本次非均匀初温、分段线性密度表输入中，两个全积分型号的密度取初始平均温度；
两个减缩积分型号的热容密度仍随当前节点温度改变。不能把其中任一规则推广到
所有 Abaqus 2025 单元。比热在四种型号中均按当前节点温度取值。

C3D8T 同时保留整体投影热容权重 Jbar*w0_i 和局部密度修正 1/J_i。
非均匀变形时 Jbar/J_i 不为一，因此节点热容不等于严格初始节点质量乘比热。
CAX4T 则按当前形函数行和重新分配初始总质量，单元总量可以守恒，而每个
节点分配的质量仍会改变。这两个现象必须分开描述。

## 设计与独立复核

每次原生任务含 144 个互不连接的单元、960 个节点，覆盖四种型号、规则与畸变
两种参考形状，以及三种材料：常密度常比热、密度表加常比热、密度表加变比热。
每个几何与材料组合分别激活每个角点的温度基向量。

位移和温度全部指定，热膨胀系数为零，导热系数为 1e-20 W/(m K)，从而直接由
节点热反力识别热容。密度表为 (300 K,2000)、(360 K,1900)、(420 K,1400)、
(480 K,1300)，单位 kg/m³；变比热为 cp=3000+4*(T-300)，单位 J/(kg K)。
分段密度表可区分“先平均温度再求密度”和“先求密度再平均”。

两次任务均经历五个完整单步阶段：原形、非均匀变形 A、保持 A、变形 B、恢复原形。
第一组每阶段仅活跃节点升温 1 K，dt=1 s。独立复核组修改了参考几何、变形幅度
和初温分布，每阶段仅活跃节点降温 2 K，dt=0.25 s。初始温度和所有边界条件均
写在完整 `.inp` 中；运行程序只复制并校验输入，不生成或修改它。

| 型号 | 两组活跃热反力样本数 | 全部样本最大相对误差 |
|---|---:|---:|
| C3D8T | 480 | 5.68e-14 |
| C3D8RT | 480 | 1.15e-13 |
| CAX4T | 240 | 6.66e-14 |
| CAX4RT | 240 | 4.65e-14 |

共 1440 个活跃热反力验证上述完整公式。其余 8160 个节点样本的温度变化率为零，
热反力接近零，见两组 analysis.log 中的 MAX_INACTIVE_RFL。这支持本探测范围内
热容按节点对角分配，而不是一致非对角热容矩阵。每次求解都严格检查五个阶段
各只有一个完整时间增量，避免自适应时间细分改变被测算子。

## 有效热容总质量诊断

只对常密度、常比热组，把不同基向量的热反力除以温度变化率和比热，再求和，
得到热容对应的有效总质量。这不是 Abaqus 结构质量或重力质量的输出。

独立复核组中，该总量相对初始质量的最大变化为：C3D8T 约 1.7814%，
C3D8RT 约 0.17044%；两个轴对称型号的变化均小于 5e-14。
C3D8RT 的差异来自真实体积比与平均变形梯度行列式的不同。
原形恢复后，各型号的常物性有效热容也恢复，不能把本探测解释为质量历史累积。
逐阶段结果见两组 capacity_mass.tsv。

## 复现与证据

在 Windows 分别执行本目录和 validation 目录中的 `run.ps1`，使用固定入口
`C:\SIMULIA\Commands\abq2025.bat`，单个 CPU。原生日志、成功状态、提取字段和
输入哈希均保留；工作目录与版本见各自 provenance.txt。
第一组求解和提取已经成功，但复制一个不存在的空提取日志时报错；检查 Windows
暂存输入与源输入逐字一致后恢复了记录，运行程序现已不要求该可选空日志。

在仓库根目录运行下列命令，仅读取原生记录并做独立形函数积分，不调用 Fuelsim：

```bash
python verification/abaqus/2025/density_capacity_probe/analyze.py
python verification/abaqus/2025/density_capacity_probe/analyze.py --directory verification/abaqus/2025/density_capacity_probe/validation
```

分析使用 NumPy。`initial_density_candidates.tsv` 与 `geometry_candidates.tsv`
保留被排除的候选公式和误差；`identified_predictions.tsv` 保存逐样本完整预测，
`identified_summary.tsv` 保存最大误差。脚本要求完整公式相对误差小于 1e-10，
未活跃节点反力绝对值小于 1e-12 W。

本次未识别二次单元、初始场变量、多材料子积分、密度用户子程序、重力或惯性。
对于当前四种型号，结论已由不同几何、加热/冷却、时间步长以及返回原形的
独立样本复核；仍不应将它表述为所有 Abaqus 版本的统一实现。
