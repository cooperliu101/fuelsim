# CAX4RT、CAX8T、CAX8RT 中等规模有限应变摩擦对比

在三个已有中等规模有限应变算例上增加与 CAX4T 相同的机械摩擦。
生产可执行文件保持不变，没有修改单元或求解器代码；这些算例仍为手动验证资料，
没有加入 CTest。

## 本次结果

下表为预热后两次正式外部耗时的均值，非线性迭代次数在各次运行中保持一致。

| CAX8T | 97.36 s | 112.10 s | 13.15% | 47 / 53 |
| CAX8RT | 61.69 s | 85.88 s | 28.17% | 47 / 52 |

|---|---:|---:|---:|

切向力合计是单侧接触界面带符号局部切向力之和，采用统一的 Abaqus 方向约定。

## 输入与比较范围

三个模型均保持原有 7424 个单元、材料、法向罚刚度 `1e14 Pa/m`、节点到面的
有限滑移接触、热接触与 20 个单位载荷增量。只增加摩擦系数 `mu=0.2` 和
弹性滑移容许比例 `slip_tolerance=0.001`；关闭摩擦生热。
CAX4RT 有 7670 个节点和 23010 个求解自由度，CAX8T/CAX8RT 有 22762 个节点
和 53194 个求解自由度，二次单元的温度仍只在角点求解。

每个增量进行稳态热平衡，将芯块体热源逐步加载到 `2e8 W/m^3`，包壳外侧温度
固定为 600 K。增量之间提交有限应变材料历史与摩擦历史；不含热容项。
精度和计时使用已提交的完整 `.fsi` 输入卡，两者的物理定义相同。

外部精度比较覆盖末态全部节点、活跃材料积分点和接触节点，包含温度、自由位移、
应力、接触压力、间隙、法向力、摩擦牵引、累计滑移、切向力及单侧切向力合计。
相对 L2、相对绝对峰值和最大逐点相对误差继续采用 `0.01%` 门槛；零参考量
独立检查绝对误差，不增加相对误差分母下限。减缩积分单元的预留积分点必须为 NaN。

CAX4RT 使用原始节点牵引；CAX8T/CAX8RT 使用既有的恢复压力和恢复剪切牵引，
与 Abaqus 的二次节点输出规则对应。LINE3 原始切向力和滑移使用 primary 边的
局部切向；本界面的 Abaqus 切向约定与其相反，因此比较前固定乘以 `-1`。
恢复剪切牵引在生产输出中已执行该方向转换，检查不再重复转换。
该规则来自 `line3_rz.cpp` 的切向定义和 `rz8_contact.cpp` 的恢复方向约定，
不是按计算误差拟合符号，也没有取绝对值掩盖方向差异。报告中的力合计统一采用
Abaqus 的符号；各型号诊断文件同时保存 Fuelsim 原始符号。

Fuelsim 保存初始状态和 20 个增量的输出；Abaqus 本次只保存末态场。
因此外部精度结论是末态全场比较，不声称完成两套程序逐增量全场比较。
逐增量接触节点数、滑动节点数和切向力作为 Fuelsim 独立诊断保存。

## 性能方法与验证

全部精度指标通过后才开始正式计时。固定逻辑 CPU 0、一个 MPI 进程、一个线程，
Fuelsim 使用 MUMPS 直接求解器，Abaqus 使用单处理器直接求解。
每套程序、每个型号先预热一次，再正式运行两次；计时输入关闭结果文件输出，
各次求解串行进行，不与编译或测试同时运行。性能表使用正式外部时间均值，
内部求解时间和 Abaqus `JOB TIME SUMMARY` 分开保存在 JSON 中。

环境仍是同一主机上的 WSL2 Fuelsim 与 Windows Abaqus，跨虚拟机边界的逻辑
CPU 固定不能保证同一物理核心。两次重复只支持这三个固定算例、本次环境的结论。
本次没有重新测量无摩擦版本，不能以不同批次时间精确归因摩擦增加的耗时。

相关单元、有限滑移摩擦、历史及重启测试共 8 项通过。
扩展检查脚本后，原 CAX4T 摩擦指标重新计算并与已保存报告完全一致。

## 复现

所有输入位于 `verification/fuelsim/`，精度输入命名为
`quasistatic_rz_performance_medium_<型号>_finite_friction.fsi`，计时输入在
`friction` 后增加 `_timing`。对应 Abaqus 输入位于上级目录。
可直接运行 `build/fuelsim -i <完整输入卡路径>`，也可以使用编排脚本：

```bash
/home/cooper/miniforge/envs/moose/bin/python \
  verification/abaqus/rz_performance/medium_cax_other_finite_friction/run_comparison.py \
  --root "$PWD" --executable "$PWD/build/fuelsim" --results /tmp/cax-other-friction-repeat
```

脚本先串行完成三个精度对比，然后串行完成全部计时。它逐字复制输入和网格到
独立目录，不生成或修改物理定义。Abaqus 使用 Windows PowerShell 和现有
`C:\SIMULIA\Commands\abaqus.bat`，从 WSL 的 `Ubuntu` 共享路径访问文件。
`--elements cax8t` 可选单个型号；`--phase accuracy` 只运行精度，
`--phase timing` 要求指定目录中已有对应的通过报告。

各型号子目录保存 `accuracy.json`、`summary.json`、`friction_diagnostics.json`、
压缩 Abaqus 参考和全部运行日志。总 `summary.json` 汇总三者；`provenance.json`
保存可执行文件、输入、网格、脚本与完整结果的 SHA256。
