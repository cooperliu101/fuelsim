# CAX4RT、CAX8T、CAX8RT 按需历史计算优化

本次修改让求解残量和切线矩阵的调用跳过随后会被丢弃的材料历史更新。
优化前版本为 `869112d`，已包含先前的 CAX4T 优化；优化后源文件与可执行文件
摘要见 `source_provenance.json`。编译器、依赖、Release 配置和链接时优化均保持不变。

## 本次结果

| 型号 | 原版外部均值（秒） | 优化版外部均值（秒） | 耗时减少 | 非线性迭代次数 |
|---|---:|---:|---:|---:|
| CAX4RT | 17.14 | 14.98 | 12.59% | 47 → 47 |
| CAX8T | 113.50 | 98.09 | 13.58% | 47 → 47 |
| CAX8RT | 69.24 | 62.29 | 10.03% | 47 → 47 |

三者均完成 20 个增量，没有时间步重试。CAX4RT 的 228 个数值数组、CAX8T 和
CAX8RT 各 423 个数值数组在全部 21 个时刻与原版完全一致。每个结果文件的
7 个非溯源文字数组也完全一致。Abaqus 逐点相对误差最大值分别为
`0.0000152323%`、`0.00000486034%` 和 `0.00000516515%`，各项原有指标均通过。

## 修改范围

- CAX8T 和 CAX8RT 的共同实现只在 `request.history` 为真时执行返回完整历史所需的
  第二次材料计算。主体按实际用途显式请求结果；时间步接受时仍生成完整材料历史。
- CAX4RT 将历史请求传入内部计算，并跳过不需要的切线系数处理。需要切线时，
  系数旋转只携带普通数值，因为随后只使用这些系数的值；真实应力仍保留完整转动导数。
- 应力计算所需的材料响应始终保留，材料参数、积分规则、自动微分播种宽度、
  时间步历史接受与失败恢复规则没有改变。旧内部调用签名已替换，没有增加兼容接口。
- 现有单元测试增加不同请求之间的精确比较，覆盖小应变、有限应变、塑性、蠕变和
  两种机制共同作用时的残量、切线、应力、全部材料历史及热量诊断。

## 验证与计时方法

完整构建使用 `cmake --build build --parallel 4`，统一回归使用
`ctest --test-dir build -j4 --output-on-failure`。全部 281 项测试通过，耗时
171.36 秒；中等规模算例没有加入 CTest。

三个有限应变算例均使用已提交的完整输入卡，每个算例保持 20 个载荷增量。
程序将卡片和对应网格逐字复制到独立工作目录，不生成或修改物理定义。
CPU 固定为逻辑处理器 0，MPI 使用一个进程，各线程环境变量设为 1，线性求解器
为 MUMPS。计时使用关闭输出的专用输入卡，按原版预热、优化版预热、原版、
优化版、优化版、原版依次运行。报告使用后四次中各版本两次正式运行的外部时间均值；
内部求解时间另存于 JSON，不与外部时间混用。构建和回归不与计时同时运行。

精度验证另外运行启用输出的原版和优化版，比较全部 21 个时刻的 Exodus 数组。
比较忽略创建时间等溯源文字，保留其他文字和所有数值字段，对 NaN 位置要求一致。
随后按原有 `medium_<型号>_finite_incremental` Abaqus 参考检查终态各项误差，
保持原有 0.01% 门槛及不活跃积分点检查。本次没有重新计时 Abaqus，性能结论仅为
本次原版和优化版之间的受控比较。

## 复现

先保存 `869112d` 的同配置可执行文件，再构建优化版本，并使用新的结果目录运行：

```bash
/home/cooper/miniforge/envs/moose/bin/python \
  verification/abaqus/rz_performance/medium_cax_other_finite_optimized/run_comparison.py \
  --root "$PWD" --baseline /absolute/path/to/baseline/fuelsim \
  --candidate "$PWD/build/fuelsim" --results /tmp/cax-other-repeat
```

`runs.json` 保存所有运行时间和迭代次数；`summary.json` 保存统计结果；
各型号的 `*_equivalence.json` 和 `*_accuracy.json` 分别保存完整数组等价性及
Abaqus 精度检查结果。`provenance.json` 保存输入、网格、可执行文件和完整结果
的 SHA256，压缩日志保留构建、回归和所有中等规模运行的原始输出。

两次正式运行只能说明这三个固定算例在本次环境下的收益，不代表所有材料或网格。
