# 有限滑移主表面传递的圆形区域识别

本记录识别了此前正权重单面投影不能复现的平面无摩擦原生算子；
算子识别本身不代表完整非线性精度通过。后续生产接入与实际误差见
`c3d20rt_disk_contact_validation.md`。

`h20_28_finite_disconnected_probe.inp` 保持主表面几何、全部固定约束、
次面位移扰动和材料不变，仅把 64 个主单元共享节点拆成 1280 个独立节点。
接触主面具有 512 个节点；原始节点映射由同名前缀 `_node_map.csv` 保存。
17 个原生分析步完整通过。分面结果按原节点位置相加后，主表面传递矩阵与
共享节点浅压入探测的相对差异为 5.4574e-13；次面平均矩阵差异为 4.5701e-14，
约束面积差异为 1.4512e-13。这证明该平面固定主面的拆分没有改变被测算子。

对角点约束，位于原面坐标 (0.38603095325, 0.04724894151) 的同一个采样点，
同时给 x 范围 [0.25, 0.375] 和 [0.375, 0.5] 的两个主面分配权重。
前一个面的等效作用点在该面之外。因此，负形函数系数来自相邻主面上的
外推求值，不能仅用单个有效投影面的内部形函数和正采样权重表示。

下列几何规则复现全部平面矩阵：

1. 保留原 H20.28 次面采样点和正积分权重。
2. 在每个采样点周围建立圆形区域，按照圆与各主面重叠的面积比例分配权重。
3. 在每个有重叠的主面上，都在原采样点求值其二次形函数，允许自然坐标外推。
4. 单位正方形次面的圆半径为 0.028276366456418445，与原采样点到外边界的
   最小距离相同。矩形次面按各自最短边长缩放；此半径规律当前只由平面矩形
   证据支持，更一般曲面与畸变几何尚需识别和验证。

`check_h20_disk_transfer.py` 使用圆与矩形交集的解析面积计算，没有把原生
传递矩阵作为运行时查找表。相对差异为：

| 主网格 | 全矩阵相对差异 | 最大系数绝对差 |
|---|---:|---:|
| 8×8，浅压入 | 4.1042e-10 | 3.4640e-11 |
| 16×16，原压入 | 8.8417e-6 | 5.6521e-7 |
| 32×32，原压入 | 1.4724e-5 | 8.3010e-7 |

后两者含此前识别的有限压入几何导数影响，未将上述残差全部归为舍入误差。

独立的六单元非匹配网格中，次面分别为 1.2×1 和 0.8×1，四个主面宽度均为
0.55。`check_c3d20rt_disk_transfer.py` 按每个次面最短边长分别计算圆半径，
复现 13×36 原生间隙矩阵，相对差异为 8.2243e-10，最大系数绝对差为
6.7590e-10。若把所有次面统一使用全局最短边长，矩阵相对差异为 0.00102615，
不能复现该独立参考。

生产接入必须同时保留圆形区域分配、外推形函数及其几何导数，且只形成一个
面平均约束。不能把多个支持面的贡献误计为多个独立接触约束；必须检查离散
守恒、投影候选归属、局部方向导数，再运行完整有限应变无摩擦算例。
