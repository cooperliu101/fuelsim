对于每个时刻的每个节点，先检查三分量反力向量相对误差是否小于 0.15%；
若不满足，再检查差向量的欧氏范数是否小于 10 N。零参考反力直接检查
绝对误差小于 10 N。两项满足任意一项即通过，不能用全局最大相对误差

0.1%。用户另批准将本算例切向力最大逐点相对容差设为 0.15%，累计滑移
最大逐点相对容差设为 0.6%；两者相对 L2、相对绝对峰值仍小于 0.1%，
零参考绝对容差不变。其他场保持原有要求。此前反力 150 N 和 0.5 N 门槛已被替代。

0.510769%，按上述本算例容差通过。完整 280 步全部检查通过（acceptance_passed=1）。

## 算例与参考

生产输入为 `../fuelsim/transient_c3d20rt_finite_contact_safeguarded.fsi`，
运行真实程序 `build/fuelsim -i <输入卡>`。该输入采用二十节点减缩积分单元
C3D20RT、有限应变、面到面机械接触、有限滑移和库仑摩擦。摩擦系数为 0.3，
法向罚刚度为 1e11，允许弹性滑移的特征长度比例为 1e-5。两区域网格不匹配，
共有六个体单元、88 个位移节点、13 个接触输出节点、每单元八个材料积分点。
同时保留热传导和热接触。材料、摩擦系数和罚刚度保持不变；用户批准的
验收容差见文首。配套无摩擦算例已缩短为两秒，见 `c3d20rt_frictionless_short_validation.md`。

七秒加载依次覆盖压紧、粘着、正向滑动、卸载、反向滑动和重新粘着。
Fuelsim 使用 280 个 0.025 秒时间步。Abaqus 参考输入为
`c3d20rt_finite_contact_friction.inp`，三组原始参考为同名前缀的
`_nodes.csv`、`_contact.csv` 和 `_points.csv`。
两者在 280 个时刻比较；Abaqus 在 4 至 4.05 秒使用过更小的内部时间步，
原始 `.sta` 记录有 285 次尝试记录。不能把“280 个输出时刻”称为两者内部
增量完全一致。当前小反力最差位置在 2.375 秒，早于这段时间步差异。

新增原生切向方向、局部滑移和剪应力提取入口为
`extract_c3d20rt_friction_diagnostics.ps1`。它先检查工作目录输入的哈希一致、
原生分析完成，再读取已有 ODB；不重新求解或改写参考输入。
工作目录记录在 `c3d20rt_friction_diagnostics_extraction.txt`。
新增 `_frames.csv` 与 `_shear.csv` 均包含完整 3640 个接触样本。

## 已识别的接触公式

1. 每个次表面采样点的第一切向方向由参考构形中的约定方向随表面变形传递。
   参考法向不接近全局 X 时取全局 X 在面内的投影，接近 X 的 0.1 度范围时
   改用全局 Z。不能把网格第一参数方向直接作为该材料方向。
   逐采样点当前面积加权平均两个单位切向方向，再构造约束使用的正交方向。
   `diagnose_c3d20rt_contact_frames.py` 在全部原生帧上得到第一切向最大向量差
   4.684e-9、法向最大向量差 5.777e-9。原生两个平均切向方向存在约 4.84e-7
   的非正交性；内部历史仍使用正交方向。
2. 切向力分配必须包括次表面转动引起的局部间隙项。设 n 指向主表面、
   g 为该采样点的几何间隙、t 为单位切向，则次表面节点的虚位移系数为
   `w * (N_j*t - g*(grad_surface(N_j) dot t)*n)`。
   主表面仍使用圆形区域分配后的 `w*N_primary*t`。这里的 g 是逐采样点间隙，
   不能替换为整条平均约束的间隙。
   `diagnose_c3d20rt_friction_force_geometry.py` 使用原生局部滑移和未调整的
   库仑返回关系，在第 1、40、160、171、208、280 帧独立重构切向力；
   六帧相对 L2 比值为约 3.18e-9 至 1.41e-6。诊断采用最近主面投影，
   生产路径采用圆形区域跨面分配，两者的曲面边界近似不能视为完全相同。
3. 仅将上述当前虚位移系数乘整个节点位移增量，会在共同有限刚体转动时
   累积虚假滑移。新增解析检查对接触两侧同时绕一般轴转动 0.2 弧度，
   发现最大滑移分量差为 8.83313e-7 m。后续实现先从节点增量中扣除
   接触方向所确定的共同转动，再计算相对滑移，并保留转动方向的完整导数。
   初始方向与随后各步使用同一参考采样平均规则。

库仑切向返回关系、允许弹性滑移长度和法向压力关系未作拟合。
参考切向方向的约定见
[Abaqus conventions](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMODRefMap/simamod-c-conventions.htm)，
切向罚刚度和弹性滑移的关系见
[Abaqus Coulomb friction](https://docs.software.vt.edu/abaqusv2025/English/SIMACAETHERefMap/simathe-c-coulombfric.htm)。
本算例使用较早版本的原生结果，上述新版文档只提供理论依据，逐项数值鉴定
依赖本目录的实际参考输出。
新增内部检查覆盖非零罚间隙下接触总力和总力矩平衡、曲面几何方向导数、
共同有限刚体转动，以及既有粘着、滑动、反向和历史恢复路径。

## 滑移诊断与未完成边界

`tests/c3d20rt_friction_history_replay.cpp` 逐帧指定 Abaqus 节点温度和位移，
只执行接触几何及历史更新，不求平衡，因此是内部诊断，不是用户算例验收。
`diagnose_c3d20rt_slip_increment.py` 比较当前虚位移、局部弦增量、共同转动、
主面投影点及积分面积的不同增量表达；没有据此拟合任何系数。
这些诊断仍有微米量级累计差异。更一般曲面上的圆形区域分配、主面投影
增量和参考程序的内部时间步历史尚须进一步独立鉴定。

手动诊断不加入自动回归，也不随默认构建编译。可从仓库根目录重现：

```bash
cmake --build build --target fuelsim_c3d20rt_friction_history_replay --parallel 2
build/fuelsim_c3d20rt_friction_history_replay \
  verification/fuelsim/transient_c3d20rt_finite_contact_safeguarded.fsi \
  verification/abaqus/c3d20rt_finite_contact_friction_nodes.csv
python3 verification/abaqus/diagnose_c3d20rt_contact_frames.py
python3 verification/abaqus/diagnose_c3d20rt_friction_force_geometry.py
python3 verification/abaqus/diagnose_c3d20rt_slip_increment.py
```

完整生产验收入口为以下命令。必须等待生产程序成功完成；检查器返回非零
表示没有通过，不得添加无摩擦例外选项。

```bash
env OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 build/fuelsim \
  -i verification/fuelsim/transient_c3d20rt_finite_contact_safeguarded.fsi
build/fuelsim_c3d20rt_contact_results \
```

本轮没有进行受控速度比较。工作区还存在其他 C3D20RT 和轴对称开发修改，

## 共同转动修正后的求解与回归

`c3d20rt_friction_objective_local_ctest.txt` 中两个局部测试均通过，包括
共同刚体转动不增加滑移、非零间隙的力与力矩平衡以及曲面摩擦导数。
按仓库依赖配置完成全部目标构建，统一回归
`c3d20rt_friction_objective_full_ctest.txt` 为 299/303，失败仍是四项
`fuelsim_b13_small_cax4t/cax4rt/cax8t/cax8rt_abaqus_tests`。
没有在本轮隔离重建干净基线，不能由此把这些失败归为与本轮无关的已证明结论。

参考校验初次失败是清单含有 `../../tests/production_c3d20rt_contact.cpp`，
而校验器只接受当前目录文件名。已删除这个格式无效的条目，检查器源文件哈希
改记入本算例的 provenance 文件。修复后原生参考哈希检查通过。

共同转动修正后的完整无摩擦计算仍完成 280 步，并按该算例此前批准的
有限例外通过，记录为 `c3d20rt_friction_objective_frictionless_metrics.txt`。
最大逐点反力误差约 0.912458%，滑移约 0.787188%，切向力严格为零。
这只是无摩擦回归通过，不是有摩擦严格验收通过。

有摩擦组合线搜索在原 40 次迭代上限下于 4.025 秒失败，记录为
`c3d20rt_friction_objective_run.txt`。固定 4 秒检查点为
`c3d20rt_objective_accepted_4.checkpoint`，完整单步输入为
`../fuelsim/transient_c3d20rt_finite_contact_objective_reverse.fsi`。
该输入在 100 次完整 Newton 迭代失败后，从同一原始状态改用回溯，
67 次迭代后完成反向时间步，日志为 `c3d20rt_friction_objective_reverse_run.txt`。
因此完整主输入只把迭代上限从 40 改为 100，保留原组合线搜索、
280 个固定时间步和全部严格误差门槛。此前完整输入逐字保存在
`c3d20rt_friction_previous_solver_input.fsi`。

直接在反向时间步的初始状态运行生产 `--check-jacobian`，中心差分检查返回
失败，y 方向相对差约 0.5354。逐接触贡献诊断
`c3d20rt_friction_objective_reverse_branch_probe.txt` 明确显示全部 13 个约束
在正、负扰动之间切换粘着和滑动，所处位置没有唯一的双侧导数。
该检查不能作为光滑分支的切线失败证据，也不能隐去而声称此状态的中心
差分通过；局部光滑分支、曲面几何和共同转动测试的通过结论仍限于各自测试。
把扰动参数从 0.01 缩小到 0.001，同一分支的单侧差分相对差最大值由
3.91462e-4 降为 3.89503e-5，约按扰动幅度下降，符合单侧差分截断误差特征。
较小扰动记录为 `c3d20rt_friction_objective_reverse_branch_small_probe.txt`。
