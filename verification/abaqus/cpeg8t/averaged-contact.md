# 平均接触与首步塑性验证

本轮按用户要求新增首步塑性的比较工况，并修复 `sections_contact` 和
`contact_cycle` 的力学离散差异。所有原有 Abaqus 非零量门槛仍为严格小于 0.5%，
零量仍使用各物理量原有绝对门槛，没有调整参考分母或删去节点、材料点。

## 首步塑性例题

`inelastic_initial_plastic.fsi` 仍使用三个独立矩形和 0.25 s 固定步长，
截面伸长从 0 线性增加到 0.003 m，初始厚度为 0.1 m，总时间 3 s。
三个区域分别为纯塑性、初始屈服应力 500 Pa 的塑性—蠕变材料，以及初始屈服应力
1000 Pa 的塑性—蠕变材料；其他材料参数沿用原例题。原网格块名 `creep` 在这个
新增例题中引用 `low_yield_coupled` 材料，不再表示纯蠕变。

首个增量末三个区域均发生塑性，两个耦合区域此后每个增量都同时发生塑性和蠕变。
检查覆盖 13 个时刻、27 个材料点、弹性/塑性/蠕变全部张量历史和等效标量，
以及全部节点反力和截面控制量。原生比较与独立后向 Euler 解析更新均通过；
最大非零逐点相对误差约 `4.77e-8`。

原 `inelastic_history` 的保持、卸载过程仍保留。Abaqus 在这些阶段切换时间积分
方法，所以旧参考仍记录为未通过；新例题不覆盖这一积分方法差异，也不修改生产材料算法。
用户随后明确接受首步塑性例题作为本项验收依据，因此非弹性验收记为通过，
旧例题仅保留为积分方式诊断；最新重验见[验收记录](small-gap-acceptance.md)。

## 从独立原生探测得到的接触规则

令二次边自然坐标为 `ξ∈[-1,1]`。三个节点面积区间为
`[-1,-2/3]`、`[-2/3,2/3]`、`[2/3,1]`，分别使用 `n=3、5、3` 个等权采样点。
在任一区间 `[a,b]` 上，采样位置和权重为：

```text
ξ_j = (a+b)/2 + (b-a) [j-(n-1)/2] / sqrt(n²-1),  j=0,...,n-1
w_j = (b-a)/n
```

该规则对三次及以下多项式精确。左端、右端和中点的平均权函数分别为
`max(-ξ,0)`、`max(ξ,0)`、`1-|ξ|`；当前边长测度及初始厚度进入权重。
相邻从侧边共享节点时，将两边属于该节点的加权积分合并，再计算一次平均间隙和罚力。

每个采样点沿从侧当前法向投影到主侧曲线。节点力使用形函数与该法向的乘积积分，
不能把法向提前提出积分，否则会破坏曲边节点力。压力由约束的平均间隙确定。

主侧单元边界附近，采样点在从侧切线方向采用有限宽度的区间分配。其半宽为
`L (1-1/sqrt(2))/12`，其中 `L` 为当前从侧边两个端点的距离。
对每条主侧边，按该区间与主侧端点投影区间的重叠比例分配权重，主侧二次形函数
在采样点的投影处求值；平滑区间内允许形函数向相邻主侧边外推。重叠比例、
投影、法向和测度的位移导数全部进入自动微分切线。

以上公式同时解释了此前约 18.22% 的接触刚度矩阵差异和跨单元节点力差异，
实现没有写入测得的矩阵系数或按生产例题误差拟合的参数。

独立证据包括：

- 原平直单边的正负位移扰动，验证完整平均间隙矩阵及接触刚度矩阵。
- 边中点偏移 0.002 m 的非均匀参数化探测，平均矩阵最大绝对差 `5.46e-11`。
- 64 个独立主侧小单元的扰动，三个平均间隙的转移权重最大绝对差 `2.49e-13`。
- 2000 个均匀滑移位置的五个主侧节点力，预测与原生结果最大绝对差 `5.95e-12 N`。

采样与平滑推导由 `diagnosis/check_averaging_rule.py` 独立计算。
`diagnosis/averaging_reference.json` 保留原生扫描与分块扰动的全部被检查量，
同时记录完整原生字段文件的 SHA-256；输入和精简参考另由
`diagnosis/averaging_reference.sha256` 校验。重算原生任务后可用脚本的
`--extract` 选项重新提取这些量，参考校验值须作为参考更新的一部分审查。

## 生产验证与边界

`sections_contact` 保留原来的不同截面伸长、两个转动和自由伸长约束，全部有效
节点、材料点和截面量通过原生比较。`contact_cycle` 保留原来的张开、再次接触、
截面厚度变化和滑移历史，156 项主侧节点力最大绝对差约 `2.84e-14 N`。
与逐点罚力精确积分的约 0.337 N 差异仍作为不同离散方法的诊断输出。

原有 `curved_contact` 继续通过全部节点反力与热反力比较，机械反力差约为舍入量级。
新增 `shared_contact` 使用两条相邻曲边作为从侧、两个单元作为主侧，刚体下移
产生非均匀间隙。五个从侧节点共用五个平均约束，全部反力、间隙和零体应力通过
原生比较，并通过单进程与两进程逐字段比较。

局部检查包含平直边、曲边、跨主侧边界、共用从侧节点、完整几何切线、刚体运动
客观性、张开时零力及零切线、合力和力矩守恒。全局内部检查继续验证两、四个
分区的贡献唯一归属、影子自由度完整性和方向导数；生产测试保留四进程滑移和重启。

热接触仍使用原有的分段三点积分。当前约束仍不支持摩擦、折角处有歧义的投影、
自接触或全部失去投影后的自然释放。上述通过范围不等于任意曲线都已完成原生鉴定。

独立构建目录完整回归为 **351/351 通过**，并发数 8，耗时 151.29 s。
源码快照基于 `e7adb95` 加本轮 CPEG8T 改动，排除了共享工作区中其他任务的修改，
也不包含同时提交的 C3D8T 专用优化 `cc7b48a`。逐字段生产结果、可执行文件校验值
和回归范围保存在 `averaged_validation.json`。
