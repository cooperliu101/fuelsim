# CPEG8T 未通过例题的逐项研究

本目录记录 2026-09-18 对组合工况中四项未通过比较的独立研究。
没有修改生产算法、生产输入卡或任何验收门槛，也没有把原有失败改记为通过。
研究使用补充验证时的隔离生产程序，程序摘要记录在 `mpi_differences.json`；
不代表随后主分支其他改动已经重新完成验证。

## 两侧变形时的投影区间重叠

结论：热接触最近点投影的区间归属限制会拒绝这个实际平衡构形，不能仅归因于
Newton 迭代中出现了不合理位移。`analyze_projection.py` 直接读取 Abaqus 的
收敛位移，重建两条主侧二次边的端点法线与从侧二次边的交点。

在首个 0.0625 s 状态，相邻主侧边的切线夹角为 0.000394122 rad。
同一从侧边的两个有效区间分别为 `[-1, 2.426904757e-5]` 和
`[2.065985973e-5, 1]`，自然坐标重叠量为 `3.609187843e-6`，对应实际长度
`2.165837024e-8 m`。它超过现有 `1e-10` 自然坐标检查量，不能按机器舍入消除。
16 个输出时刻、每时刻两条从侧边中，共 15 项存在重叠或覆盖空缺。
完整区间保存在 `projection_intervals.json`。
原始完整生产输入卡再次运行仍以同一投影重叠信息失败，摘要记录在
`production_reproduction.json`。

建议：主侧共用端点应在从侧上形成统一的分界，避免使用相邻两条主侧边各自的
端点法线定义两个互相冲突的区间。共用端点沿从侧法线投影可得到单一分界，
但这里只验证了几何重建；曲边多解、端部释放、移动分界导数仍需实现和验证。
不建议提高重叠容差来掩盖问题。

## 固定主侧、从侧变形滑移时的热反力

结论：主要差异来自热接触的温差平均方式，不是简单增加积分点就能消除。
原例最大节点热反力相对误差 0.883628%，仍超过原有 0.5% 门槛。

`create_thermal_probe.py` 冻结原生解在 0.0625 s 和 0.8125 s 的全部位移，
逐一将十二个温度角点从 300 K 改为 301 K。分别运行接触传热系数为
1000 和显式为零的两个原生输入；对应热反力相减，消去体导热贡献，得到
12×12 接触热矩阵。关闭传热必须显式写零，不能仅省略 `*Gap Conductance`。

原生矩阵对称且守恒，只有三个显著非零奇异值，对应三个从侧温度角点的约束。
当前逐点温差积分和增加到 64 点的普通积分，与首个原生矩阵仍相差约 5.14%
（矩阵差的 Frobenius 范数除以原生矩阵范数）。直接采用五个力学节点的平均
约束仍相差约 1.91%，不能把力学约束原样作为热约束。

独立重建中，每条从侧边的左、右半区分别属于两个温度角点，中点样本各分一半；
相邻边共用角点的贡献先合并。使用现有力学几何采样规则和主侧转移权重，定义
每个角点邻域的面积为 A，积分后的温度形函数差向量为 v，则恒定传热系数 h
对应的矩阵贡献为 `h * v * transpose(v) / A`。这里先形成邻域平均温差，
再形成热流，没有根据原生矩阵拟合系数。

| 冻结构形时刻 | 矩阵相对范数误差 | 最大矩阵项绝对差，W/K |
|---|---:|---:|
| 0.0625 s | 6.5987e-13 | 1.2776e-12 |
| 0.8125 s | 5.7417e-7 | 1.1045e-6 |

第二个状态仍有主侧转移附近的微小差异，尚未完全解释。此证据仅覆盖固定平直
主侧、变形曲边从侧、恒定传热系数；不能宣称任意曲边、变系数传热或生产切线
已经通过。全部对照公式和误差保存在 `analyze_thermal_probe.py` 与
`thermal_matrix_analysis.json`。

建议：将前两项作为同一项热接触离散改进处理，采用温度角点邻域平均，并统一
主侧边界归属。实施时需保留面积、投影、平均温差及传热定律的全部导数，随后
重新验证生产热反力、非恒定传热、守恒、局部切线和多进程装配。

## 多进程检查点续算的严格比较

结论：观察到可重复的进程数相关舍入差异，没有发现检查点恢复导致的大幅历史
偏差。相同 0.5 s 检查点分别用一、二、四个 MPI 进程续算；一进程和四进程各
重复两次，同一进程数下所有导出数值完全一致。

跨进程比较继续采用 `abs(error) <= 1e-12 + 1e-12*abs(reference)`。
两进程有 103 个数值、四进程有 86 个数值超过门槛，分别涉及 26 个字段名称。
四进程最大应力差为 `2.3078e-11 Pa`，最大节点位移差为 `1.0843e-19 m`；
温度完全一致，塑性张量最大差约 `2.08e-17`，蠕变张量约 `4.49e-20`。
最大应力差本身不一定超限，失败主要发生在较小非零应力和接近零的剪应力上。

`analyze_mpi.py` 使用完整静态输入卡和真实生产程序；`mpi_differences.json`
保存程序、检查点摘要、逐字段差值和失败样本。现有证据不能进一步区分全局装配
求和顺序与分布式直接分解的影响，不应把其中某一种直接认定为唯一原因。
严格比较仍失败，不能套用其他例题已经批准的零应力例外。

建议：若继续追求现有严格门槛，应先分别隔离装配和线性求解的舍入来源。
本次没有调整求解器或容差。

## 压力相关传热的张开行为

结论：原有 Fuelsim 仿射定律与本次 Abaqus 压力表的张开启停规则不同。
独立 `pressure_opening.inp` 固定下侧 300 K、上侧 400 K，接触面积
0.002 m²，施加统一间隙，不让体导热与未知界面温度干扰结论。

| 间隙，m | 原生压力，Pa | Abaqus 传热率，W | 现有仿射定律解析值，W |
|---|---:|---:|---:|
| 1e-4 | 0 | 0 | 220 |
| 1e-5、1e-6、1e-7、1e-8 | 0 | 220 | 220 |
| 0 | 0 | 220 | 220 |
| -1e-8 | 10 | 220.004 | 220.004 |
| -1e-4 | 100000 | 260 | 260 |
| 再张开至 1e-4 | 0 | 0 | 220 |

因此不能简单说 Abaqus 在所有正间隙下都停止传热，也不能仅按压力是否为零
增加开关。当前探测只把启停变化定位在 `1e-5` 至 `1e-4 m` 之间，尚未识别
阈值与网格尺寸、接触参数的关系。`pressure_activation.json` 保存原生结果和
现有定律的解析值；本探测没有再次运行新的 Fuelsim 间隙扫描输入卡。

建议：保留已验证的现有仿射定律；若需要对齐该 Abaqus 压力表，应先研究启停
距离，再明确增加哪一种传热定律，不能静默改变所有零压力状态的基础传热。

## 重现与证据边界

在仓库根目录用包含 NumPy 和 netCDF4 的 Python 执行以下脚本，可离线重建
投影、热矩阵及压力分析。原生输入、输出的 SHA-256 摘要在 `reference.sha256`。
`native_output_normalization.json` 另外记录原始 Windows 换行和仓库存储换行的
摘要；只转换换行，JSON 数值不变。

```bash
python verification/abaqus/cpeg8t/failure_diagnosis/analyze_projection.py
python verification/abaqus/cpeg8t/failure_diagnosis/analyze_thermal_probe.py
python verification/abaqus/cpeg8t/failure_diagnosis/analyze_pressure_probe.py
python verification/abaqus/cpeg8t/failure_diagnosis/analyze_mpi.py \
  --executable /path/to/fuelsim --mpiexec /path/to/mpiexec \
  --checkpoint /path/to/coupled_contact_split.chk --work /tmp/cpeg-mpi-study
```

重新生成原生输入可运行两个 `create_*_probe.py`。然后调用父目录 `run.ps1`，
以本目录为 `SourceDirectory`，依次指定 `thermal_matrix_on`、
`thermal_matrix_off`、`pressure_opening` 为 `JobName`；每项使用一个 CPU。
这些是手动研究资料，不加入日常 CTest，也不会自动启动 Abaqus。

本轮执行了三个原生探测任务、五次生产续算及离线重建分析。此前 354 项回归
属于补充验证基线；本轮没有修改生产实现，也没有重新运行整个回归套件。
