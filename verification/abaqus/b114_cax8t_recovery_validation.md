# CAX8T 节点接触应力恢复验证

生产程序在 CAX8T 的 secondary 节点约束侧增加两个以 Pa 为单位的结果字段：
`contact_recovered_pressure_<pair>` 对比 Abaqus `CPRESS`，
`contact_recovered_shear_<pair>` 对比 Abaqus `CSHEAR1`。
压力取正压缩，剪切应力沿当前 primary 边切向取正。Fuelsim 原始切向牵引使用
残量符号，因此恢复剪切应力采用原始切向牵引的反号。恢复不会修改求解残量、
Jacobian（残量对未知量的导数矩阵）、节点接触力、摩擦历史或接触状态。

## 规则与证据边界

每条二次边的节点依次为端点 0、端点 1 和中间节点 2。对任一原始节点牵引 v，
在自然坐标 -1、1、0 上拟合 v = a + b*xi，其中 a = (v0+v1+v2)/3，
b = (v1-v0)/2；恢复值为 a-b、a+b、a。这个规则等价于等权最小二乘投影，
没有按算例拟合的系数。相邻边在共享节点处作算术平均。

对平均结果应用接触对的原始牵引极值范围限制。主面中未参与活动约束的节点会
把零包含在该范围内；全接触、全部主面节点参与约束时，不能擅自把压力下限改成零。
压力限制与剪切应力限制分别计算，先恢复和限制原始符号的牵引，再转换物理剪切符号。
限制只用于后处理，不能用于掩盖非法材料值或几何值。

规则由本仓库 Abaqus/Standard 3DEXPERIENCE R2018x 实际结果识别。
[Abaqus 的节点接触输出说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEITNRefMap/simaitn-c-contactgeneralstd.htm)
明确说明接触应力输出包含平均、过滤和平滑，不能直接从恢复应力反推节点接触力；
该说明不公开这里的具体投影矩阵或极值规则，具体数值规则以本次鉴定为证据。
目前逐节点外部验证覆盖下列轴对称节点到面接触路径，不据此宣称复现其他 Abaqus
接触算法、任意折角或所有曲率下的内部恢复实现。

## 外部程序比较

所有例题均运行完整的生产输入卡，并对全部输出时刻和全部 secondary 节点比较。
下表为最大逐点相对误差，单位为百分数；相对 L2（整体二范数）和相对绝对峰值
误差也必须小于 0.1%。三项误差均保留原始参考值，不设置分母下限。

| 例题 | 恢复压力最大逐点误差 | 带符号恢复剪切应力最大逐点误差 |
| --- | ---: | ---: |
| B10.12 小应变摩擦、粘着及正反向滑动，10 时刻、30 节点样本 | 3.46647e-8% | 1.26084e-7% |
| B10.13 有限应变跨线段滑移及反转，10 时刻、30 节点样本 | 7.73314e-8% | 8.38428e-7% |
| B10.14 两条不等长边共享节点恢复鉴定，14 时刻、70 节点样本 | 6.01635e-11% | 4.42823e-11% |

B10.14 使用两个 secondary 单元和一个固定 primary 单元，两条接触边长度分别为
1 mm 和 1.5 mm，能够区分共享节点的算术平均与面积加权平均。依次施加均匀闭合、
五个独立节点压力脉冲、五个部分接触状态、一次完全分离和带正负剪切的重新接触。
节点位移全部规定，以隔离恢复算法。它独立比较原始节点力，并检查原始牵引乘
节点面积仍等于节点力，避免把恢复量回写到原始物理输出。

该规定状态例题的完整节点场和材料场使用以下绝对误差要求：温度 1e-11 K，
位移 1e-13 m，反力 1e-8 N，热反力 1e-11 W，应力 1e-4 Pa，应变 1e-13。
实际最大差分别为 0 K、6.78e-21 m、7.99e-11 N、5.61e-15 W、1.56e-7 Pa 和
9.77e-17。这样保留完全分离时的浮点残差，不把接近零的参考量强行转换成零。
恢复应力中参考绝对值不超过 1e-4 Pa 的 75 个压力或剪切样本单独比较绝对差，
其最大绝对差为 8.91e-9 Pa；其余样本按上表的三种相对指标验收。
B10.12 和 B10.13 的原有完整场相对验收要求保持不变。

## 复现

完整输入为 `transient_b114_cax8t_recovery.fsi` 与 `b114_cax8t_recovery.inp`。
`generate_b114_cax8t_mesh.py` 仅产生匹配的 Exodus 网格和 Abaqus 网格包含文件，
不会生成或修改物理输入卡。`b114_cax8t_recovery_run.txt` 保存真实 Abaqus 运行的
版本、单处理器设置、完成时间和输入、提取脚本校验值。节点和积分点参考均受版本管理。

```bash
ctest --test-dir build -j4 -R 'b11[234]_cax8t' --output-on-failure
ctest --test-dir build -j4 --output-on-failure
```
