# CAX2T_GPS 的环向平均应变与一致内力

## 算法变更

按照内体误差诊断后的实施要求，CAX2T_GPS 的环向机械应变改为单元参考体积
平均。平均只在一个 BAR2 径向单元内部进行，不跨径向单元或轴向切片。两个
材料点及其独立材料温度和历史继续保留，热膨胀仍使用两节点算术平均温度。

```text
小应变：epsilon_hoop_bar = (ur0+ur1)/(R0+R1)
有限应变：F_hoop_bar = 1 + (ur0+ur1)/(R0+R1)
delta_e_hoop = 2*(F_hoop_bar_new-F_hoop_bar_old)/(F_hoop_bar_new+F_hoop_bar_old)
```

有限应变先平均伸长比，再形成 Hughes-Winget 中间构形增量，不平均逐点增量，
也不以总对数应变代替累计历史。三个变形方向没有旋转；材料输入仍由四个应变
分量加温度进行五分量自动微分，通过闭式节点链组装 6×6 切线。

本次同时修改了材料应变、虚应变、内力与切线。径向节点虚环向梯度在小应变
下为 `1/(R0+R1)`，有限应变下再除以当前平均环向伸长比。有限应变每个材料
点的力学测度为参考测度乘 `F_r*F_z*F_hoop_bar`，即单元整体当前/参考体积比。
该测度和虚应变各自的位移导数均进入切线。

这一规则由矩形 CAX4T 的完整力学残量施加广义平面应变约束后得到。径向和
轴向增量在单元内恒定，平均完整迹的剩余面内修正恰为零；温度相关材料引起
的逐点应力仍须按参考权重乘整体体积比积分。只改应变、仍用逐点真实当前
体积装配力学，在不同材料点应力不同时并不等价。

热算子继续使用逐点真实当前半径、梯度和体积。当前、已接受与中间构形均
检查有效性，不以平均几何掩盖局部非法构形。截面轴向力的输出同步采用
`F_r*F_hoop_bar` 的面积比，与端截面内力一致；弹性应变能及塑性、蠕变耗散
诊断同步采用对应力学测度。材料历史接受和失败恢复流程保持原事务边界。

## 原双切片接触算例

没有改变原生产输入、网格、Abaqus 输入、材料、接触参数或参考数据。
检查器将全部十步、四个单元、160 个原生材料点的应力和弹性应变列为正式
验收，同时分别保留内体和外体各 80 个样本的指标。新增全部 80 个径向反力、
60 个共享轴向控制节点反力和 40 个轴向截面力的正式比较。

下面是最大逐点相对误差，均已换算为百分数，门槛仍为小于 **0.1%**：

| 量 | 环向平均修改前 | 修改后 |
| --- | ---: | ---: |
| 内体应力张量 | 11.9481058% | 1.068e-13% |
| 全部应力张量 | 11.9481058% | 6.704e-13% |
| 全部弹性应变张量 | 8.0007595% | 6.715e-13% |
| 全部径向节点反力 | 原为诊断 | 4.632e-12% |
| 全部轴向控制节点反力 | 原为诊断 | 6.704e-12% |
| 全部轴向截面力 | 原为诊断 | 5.280e-13% |

各字段的相对 L2 和相对绝对峰值也通过相同门槛。剪切分量及解析为零的
共享控制节点合力先核对原生绝对误差，再单独检查零量；没有设置相对误差
分母下限。粘着、正向滑动、反向运动、张开和再次接触的全部检查继续保留。

第一片闭合时，内侧径向反力由修改前的 `-16.896380517 N` 变为
`-24.663262121 N`，与原生 `-24.663262121 N` 一致。第一片弹性应变能从
`0.001917942893015 J` 变为 `0.001902409129806 J`，与原生应力和弹性应变
积分的结果一致。全部 20 个切片与时间步组合中，径向反力最大绝对差为
`2.802e-10 N`，弹性应变能最大绝对差为 `5.205e-18 J`。

当前结果见 [contact_stress_diagnosis.txt](contact_stress_diagnosis.txt)、
[inner_resultants.txt](inner_resultants.txt)。修改前的诊断与数值保留在
[inner_stress_diagnosis.md](inner_stress_diagnosis.md)及其明确标注的历史文件中。

## 局部验证

原有热膨胀、塑性和蠕变同时激活、非法试探及历史不变测试继续保留，增加：

- 非均匀径向位移下的独立平均应变、径向和轴向内力、应变能及能量导数。
- 非比例径向变形的两个有限应变增量及旧历史重建。
- 温度相关弹性模量和泊松比，证明材料点物性没有被单元平均温度替代。
- 真实当前热测度的逐节点热残量，证明没有误用力学平均测度。
- 小应变、有限应变全部六列切线与中心差分，以及普通残量与切线调用的一致性。
- 矩形 CAX4T 在相同运动约束下的材料应力、历史、机械残量及全部六列切线投影。

环向平均专用中心差分误差，小应变为 `1.021e-10`，有限应变为 `1.239e-9`，
均小于 `2e-7`。CAX4T 约束投影比较的最大误差分别为 `1.504e-15`、
`1.264e-15`，小于 `2e-11`。原有平均温度方向导数为 `7.451e-9`，有限应变
塑性与蠕变耦合方向导数为 `1.058e-8`，也通过原门槛。

## 非均匀有限应变原生验证

新增完整输入 `transient_gps_nonuniform_finite.fsi` 与
`gps_nonuniform_finite.inp`，复用原单圆环网格，使用十个固定时间增量。
两个径向位移在中途改变比例，轴向由伸长转为压缩；两端温度不同，弹性模量
为常数 `1e9 Pa`，泊松比为 `0.3`。Abaqus 使用一个 CAX4T、单核和
`NLGEOM=YES`，全机械位移及温度规定，保留全部节点与材料点原生输出。

该算例专门检查非均匀环向伸长比的累计历史、径向反力与
端面反力，以及生产导出的轴向截面力。能量变化使用原生应力和弹性应变按
前述力学测度重新积分，属于明确定义的原生场诊断，不宣称等同 Abaqus 自带
能量输出。两型号热积分规则不同，不把热反力及体热流列为相等验收指标。

准备外部参考时独立探测了线性温度相关弹性模量。该探测显示，此次原生
CAX4T 的弹性模量与对应角点温度一致，而 Fuelsim 现有契约使用材料点温度。
这一差异另行保存在 [温度相关弹性探测](nonuniform_elastic_temperature_probe/README.md)，
本次没有扩大修改材料取温规则。正式非均匀有限应变参考因此采用常数弹性模量，
温度相关物性与平均力学测度的联合作用由上述局部测试检查。

正式非均匀有限应变比较保留全部 40 个原生节点及 40 个材料点样本，最大逐点
应力相对误差为 `1.377e-12%`，弹性应变为 `8.229e-13%`，径向反力为
`7.735e-12%`，轴向截面力为 `3.468e-12%`，能量变化为 `2.572e-12%`。
全部非零字段的三项相对指标均小于 0.1%，零参考量独立通过绝对误差检查。

## 复现

```bash
cmake --build build --parallel 4
ctest --test-dir build -j4 --output-on-failure
cmake --build build-elements --parallel 4
ctest --test-dir build-elements -j4 --output-on-failure
python verification/abaqus/gps_1d/analyze_contact_stress.py \
  build/blackbox/fuelsim_gps_contact_abaqus/verification/fuelsim/transient_gps_contact_small_results.e
python verification/abaqus/gps_1d/analyze_inner_resultants.py \
  build/blackbox/fuelsim_gps_contact_abaqus/verification/fuelsim/transient_gps_contact_small_results.e
```

两份 Python 脚本只读取结果，不求解或生成输入卡。新增有限应变算例通过现有
生产执行与 C++ 结果检查入口运行，没有为自动回归引入 Python 依赖。
