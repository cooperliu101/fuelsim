# CAX2T_GPS 的配对径向端节点材料温度

本文保留提交 `276cc34` 的阶段结果。其中插值温度与一致热容的描述属于该阶段，
后续已按用户要求对齐 CAX4T 的热算子；当前热规则及验证见
[热算子更新记录](thermal_operator_update.md)。

2026-09-13 按用户要求，将 1.5 维框架中 CAX2T_GPS 的两个力学材料积分点
分别改为采用对应径向端节点温度。小应变和有限应变同时生效，适用于弹性模量、
泊松比、塑性初始屈服应力和硬化系数，以及 Norton 蠕变系数和应力指数。

## 温度定义与一致导数

```text
内侧材料积分点：T_material(0) = T0
外侧材料积分点：T_material(1) = T1
平均膨胀温度：T_expansion = (T0 + T1)/2
热算子积分点温度：T_thermal(q) = N0(q)*T0 + N1(q)*T1
```

材料的时间和空间位置仍为当前时间及参考积分点位置，配对由参考单元的局部
编号确定。材料温度对节点温度的导数由 `N_i(q)` 改为 `delta_qi`，同时进入
总应变的本征应变补偿和应力温度导数，避免只改变物性数值而遗漏一致切线。
本构继续采用四应变分量加温度的五分量局部自动微分，并经闭式节点链装配
6×6 矩阵。

平均温度对两个节点温度的导数均为 `1/2`。有限应变原本直接使用已接受的
平均热应变恢复总应变，因此继续保持这一处理，形成新旧平均热应变之差。
不能照搬 CAX4T 的中间补偿写法，把这一旧平均温度改成单个端节点温度。
稳态弹性历史同样扣除平均热应变。

导热系数、热容物性及新旧温度变化率继续按 Gauss 积分点插值温度求值，
热容使用一致矩阵；两套几何测度及其导数保持原定义。结果文件中的
`temperature_q` 仍表示温度场在物理积分点的插值值，不表示力学材料参数的
取温。平均热膨胀、接触及多切片轴向耦合均继续使用原有框架。

## 验证范围

局部检查覆盖小应变和有限应变下两个不同端节点温度、两个加载增量、温度
相关弹性及塑性和蠕变同时作用，独立验证参数取温、平均热膨胀、温度列与
中心差分的一致性，以及已接受历史不被试探计算修改。热算子另与保持插值
温度的一致热容解析结果比较。

两端径向温度沿轴向恒定时，与矩形 CAX4T 约束到相同广义平面应变后的
材料取温一致，因此恢复温度相关弹性模量及泊松比的机械残量和切线投影检查。
该比较仅包括机械残量行及其温度、位移导数，不要求两个型号热算子一致。

新增完整生产输入
[`transient_gps_material_temperature_finite.fsi`](../../fuelsim/transient_gps_material_temperature_finite.fsi)
通过实际 `fuelsim -i` 运行，复用原有
[温变弹性模量的 Abaqus 原生参考](nonuniform_elastic_temperature_probe/README.md)。
几何为半径 4–5 mm、高度 10 mm 的单圆环，十个固定增量；两端温度由 600 K
分别升至 700、640 K，规定非比例径向运动及轴向伸缩。弹性模量由 600 K
下的 1 GPa 线性降至 700 K 下的 0.8 GPa，泊松比为常数 0.3。

全部 40 个原生节点时刻样本和 40 个原生材料点时刻样本参与机械比较，包括
温度、位移、应力、弹性应变、径向反力、端面反力、轴向截面力和应变，以及
弹性能变化。非零场沿用相对 L2、相对绝对峰值和最大逐点相对误差小于 0.1%
的门槛，零量采用独立 SI 绝对误差。参考输入和结果保持原始字节。

该原生参考直接鉴定有限应变下的温度相关弹性模量；小应变、温度相关泊松比
和非弹性参数由上述局部检查覆盖。不同热离散形成的热流与热反力不作为
跨型号相等指标。物理参数、加载历史和误差门槛均不按结果调整。

## 局部实际结果

独立单元库完整构建后，`ctest --test-dir build-elements -j4 --output-on-failure`
通过 **17/17**。原始局部输出见
[material_temperature_local_checks.txt](material_temperature_local_checks.txt)。
两温度列逐列比较残量中心差分，四条路径均通过原定 `2e-7` 门槛：

| 路径 | 温度列最大归一化差分误差 |
| --- | ---: |
| 小应变弹性 | 4.27449e-11 |
| 小应变塑性与蠕变同时作用 | 3.81773e-11 |
| 有限应变弹性 | 4.04310e-11 |
| 有限应变塑性与蠕变同时作用 | 8.83476e-11 |

温度相关弹性下，CAX4T 约束后的机械残量与切线对 CAX2T_GPS 的最大归一化
投影误差为小应变 `1.54102e-15`、有限应变 `9.96755e-16`。另外从应力和弹性
应变独立反推弹性模量及泊松比，并检查塑性一致性和 Norton 后向 Euler 方程。
逐参数改用插值温度的候选值时，六个参数的差异均可辨认；平均热膨胀历史、
小应变/有限应变热算子的插值温度解析检查同时通过。
