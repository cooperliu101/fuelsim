# 平均温度更新后，内体应力差异的原因

## 结论与证据范围

当前双切片接触算例的内体应力差异来自环向机械应变的离散方式：
CAX2T_GPS 在每个径向材料点直接计算 `u_r/r`，Abaqus CAX4T 对环向应变进行
单元体积平均。热膨胀已经使用相同的单元平均温度，剩余差异能够由环向应变
差异完整重建。它同时影响径向反力和弹性应变能，因此不能仅解释为输出位置不同。

本次只读取平均温度更新后的生产 Exodus 结果和原生 Abaqus CSV，复核公式、
反力和能量，没有修改生产算法、输入卡、网格、参考数据或验收门槛，也没有重新
运行两个求解器。生产结果的 SHA256 为
`cf610e7c7a548b7ddb418759c1ca7fd9f1f83af376220fd81e8f5775507e811a`。

当前内体全部 80 个原生材料点样本的应力相对 L2 为 **10.2986302%**，相对绝对
峰值和最大逐点相对误差均为 **11.9481058%**。这些指标按应力张量范数计算，
并非逐个应力分量的最大相对误差。内体仍未达到外部参考的 0.1% 门槛。

## 为什么内体会产生不同的环向应变

每个切片的内体只有一个径向单元，内外半径为 4、5 mm。闭合接触时，内体两个
径向节点都向外移动 20 μm；径向位移沿半径恒定，径向应变为零。所有圆周都
随之增长，因而环向应变并不为零：半径较小的圆周，增长比例更大。
这种轴对称径向运动不能解释为整个物体的刚体平移。

第一切片高 10 mm，第二切片高 20 mm。这里环向应变的变化发生在径向单元
内部，不是由两个切片的轴向连接产生。只合并 Abaqus 中间截面节点的独立
[连接对照](connection_check.txt)也表明，在同样全部指定机械位移的条件下，
应力变化只有浮点误差量级。

记内外半径为 `r0,r1`，中间半径为 `rm=(r0+r1)/2`，相同径向位移为 `u`。
两种离散在本例中的公式是：

```text
CAX2T_GPS: epsilon_hoop(q) = u/r_q
CAX4T:    mean_epsilon_hoop = sum(dV_q*u/r_q)/sum(dV_q) = u/rm
dV_q = 2*pi*r_q*H*dr_q
```

CAX2T_GPS 的实现见 `elements/src/cax2t_gps.cpp` 的 `evaluate_cax2t_gps`；
CAX4T 的平均及面内修正见 `elements/src/cax4t.cpp`。CAX4T 同时处理完整应变迹
与环向应变，剩余修正分给径向和轴向分量。对于本例的矩形单元及规定运动，
这两个面内修正恰好为零，所以这里只剩环向分量的差别；不能推广为一般情况下
三个正应变平均分配同一修正。

最大逐点张量误差的一处样本为 `t=4 s`、Abaqus 单元 3 的材料点 1，半径为
4.211324865 mm。两程序对应值如下：

| 量 | Fuelsim | Abaqus |
| --- | ---: | ---: |
| 热膨胀使用的平均温度 / K | 681.544805391 | 681.544805391 |
| 总环向应变 | 0.004749099307 | 0.004444444444 |
| 径向应力 / MPa | 0.701244850 | 0.525482429 |
| 轴向应力 / MPa | 0.701244850 | 0.525482429 |
| 环向应力 / MPa | 4.354398163 | 3.944285848 |

该点环向机械应变相差 6.8547344%。外侧材料点半径为 4.788675135 mm，
直接环向应变则比平均值低 6.0282881%。相同规定径向位移的其他时间点也出现
同样差异；列出 `t=4 s` 不意味着误差由此时的摩擦反向运动产生。

## 为什么应力百分比比应变差异更大

材料为常数线性各向同性热弹性，杨氏模量 `E=1e9 Pa`，泊松比 `nu=0.3`。
设 `lambda=E*nu/((1+nu)*(1-2*nu))` 为拉梅常数，`G=E/(2*(1+nu))` 为剪切模量。
由于两程序的径向、轴向应变及热应变相同，令 `delta_e` 为环向应变之差，则：

```text
delta_sigma_rr   = lambda*delta_e
delta_sigma_zz   = lambda*delta_e
delta_sigma_hoop = (lambda+2*G)*delta_e
```

上述点得到应力差 `[0.175762421, 0.175762421, 0.410112315] MPa`，对应三个
分量的相对差异为 **33.4478207%、33.4478207%、10.3976317%**。前两个比例
较大，是因为 Abaqus 径向、轴向应力由约 `+2.564102564 MPa` 的机械部分与
`-2.038620135 MPa` 的热膨胀部分相加，只剩 `0.525482429 MPa`；相同应力差
除以这个较小的合成应力，比例便放大。这是实际应力差异，不能作为零参考误差忽略。

使用两种应变公式及当前平均膨胀温度重建全部十步、四个单元、160 个原生
材料点样本，应力差分解的最大剩余分量误差为 **3.260e-9 Pa**。
因此，本例剩余应力差异已经由该机械应变离散差别解释。
逐项结果见 [contact_stress_diagnosis.txt](contact_stress_diagnosis.txt)。

## 平均应力相同，为什么反力仍可能不同

在本例的常数线性材料及相同单元热应变条件下，环向应变差的体积加权平均为零。
因此两个程序的体积平均应力相同，截面轴向合力也相同。第一片闭合时的平均
正应力为 `[0.525482429, 0.525482429, 3.944285848] MPa`，轴向截面力为
14.857665656 N。全部 20 个“切片与时间步”组合中，平均应力最大绝对差为
`5.498e-9 Pa`，轴向截面力最大绝对差为 `7.816e-14 N`。

径向节点内力还包含形函数除以半径形成的权重，不能由平均应力单独确定。
从两程序实际反力输出读取，Abaqus 同一半径的上下节点反力相加后，第一片
闭合时得到：

| 径向位置 | Fuelsim 反力 / N | Abaqus 反力 / N | Fuelsim 减 Abaqus / N |
| --- | ---: | ---: | ---: |
| 内侧，4 mm | -16.896380517 | -24.663262121 | +7.766881605 |
| 接触侧，5 mm | 3407.869199311 | 3414.082704594 | -6.213505284 |

接触侧反力含有两程序相同的 3141.592653590 N 法向接触贡献；扣除这一项后，
单元体内力分别为 266.276545721、272.490051005 N。接触力较大使总反力相对
差异只有 0.182%，但体内力的相对差异为 2.280%。第二片高度加倍，相应反力
及差值加倍；第 6、7 步径向位移为零，差异降至浮点误差量级。
这里的径向反力是轴对称径向自由度的广义力，其求和不能直接当作整个圆环在
笛卡尔坐标中的合外力，也不能据此推断两侧接触力不守恒。

以实际应力和弹性应变积分 `0.5*sum(sigma:epsilon_elastic*dV)`，第一片闭合时：

- Fuelsim 弹性应变能为 `0.001917942893015 J`。
- Abaqus 弹性应变能为 `0.001902409129806 J`。
- 差值为 `1.553376320911e-5 J`，相对于 Abaqus 高 **0.816531153%**。

这个差值有独立的闭式表达式。`N_i` 表示径向节点形函数，`delta_e_q=u/r_q-u/rm`：

```text
delta_energy = 0.5*(lambda+2*G)*sum(dV_q*delta_e_q^2)
delta_R_i = (lambda+2*G)*sum(dV_q*delta_e_q*(N_i/r_q - 1/(r0+r1)))
delta_energy = 0.5*u*(delta_R_0 + delta_R_1)
```

这表明直接采用 `u/r` 的单元保留了一个正的环向应变变化能量项，也产生了不同
的径向刚度。独立脚本检查全部 20 个切片与时间步组合，径向反力差公式的最大
误差为 `2.803e-10 N`，能量差公式的最大误差为 `4.019e-18 J`。数据见
[inner_resultants.txt](inner_resultants.txt)。上述能量关系针对本例的小应变、
常数线性材料、相同单元热应变与规定运动，不作为有限应变或非线性材料的通式。

## 径向网格与后续建议

这里单元径向厚度 `h=1 mm`，中间半径 `rm=4.5 mm`，`h/rm=0.2222`。
两点 Gauss 积分位置为 `r_q=rm±h/(2*sqrt(3))`。在恒定径向位移下，内侧点
相对于平均环向应变的差异为：

```text
(epsilon_hoop(q)-mean_epsilon_hoop)/mean_epsilon_hoop
    = [h/(2*sqrt(3))]/[rm-h/(2*sqrt(3))]
```

若只对原来的 4—5 mm 区间作等分，以上公式预测的最大环向应变相对差异为：

| 径向单元数 | 公式预测的最大环向应变差异 |
| ---: | ---: |
| 1 | 6.8547% |
| 2 | 3.5156% |
| 4 | 1.7807% |
| 8 | 0.8962% |

这些是恒定规定径向位移下的代数预测，本次没有运行加密网格算例，也不能把
它们直接当作应力误差或网格收敛验收。增加轴向切片数量并不减小这里的径向
`h/rm`。原有连续轴向链算例采用 `u_r` 正比于 `r`，环向应变本来就是常数，
因此其通过结果不能证明当前恒定径向位移算例的逐点应力也应一致。

平均温度本身不自动要求环向机械应变也必须平均。对于一般径向线性位移
`u_r=a+b*r`，径向应变为常数 `b`，环向应变为 `b+a/r`，仍随半径变化。
目前的直接应变定义与 CAX4T 的平均应变定义是不同的单元离散选择。

如果后续目标是让粗径向网格下的 CAX2T_GPS 与 CAX4T 保持相同力学离散，建议
把环向平均应变作为独立的单元算法变更讨论和实施：材料应变、虚应变对应的
内力、切线矩阵及有限应变历史必须一起保持一致，并按规定完成局部方向导数、
解析和原生参考验收。仅把输出应力平均，无法证明反力和刚度已经一致。
