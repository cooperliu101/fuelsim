# 两切片接触算例的体应力差异原因（修改前记录）

本文记录提交 `6e7f6dc` 时的积分点膨胀温度规则。随后按用户要求，CAX2T_GPS
已经改为两个径向节点的算术平均膨胀温度；当前行为和验收见
[平均温度更新记录](mean_temperature_update.md)。以下旧指标不代表当前程序。

2026-09-12，重新运行原始 `fuelsim_gps_contact_abaqus` 生产测试，并从未修改的
Fuelsim Exodus 与已追踪的 Abaqus 节点、材料点 CSV 重建全部十步、四单元、
每单元四个原生材料点，共 160 个配对样本。生产算法、物理输入和验收门槛均未改动。

结论是两种离散规则共同造成差异：热膨胀使用的温度不同，环向机械应变是否平均
也不同。最大 57.7350269% 来自外体纯受约束热膨胀，不能主要归因于非均匀环向
应变。先前文档只强调后者，遗漏了最大差异的直接原因。

## 两边计算了什么

本例每个物体的径向位移在单元内相同，轴向位移也是常数，故径向、轴向与剪切
机械应变均为零。内体有非零环向机械应变，外体全部机械应变为零。

Fuelsim 的 CAX2T_GPS 在径向 Gauss 点计算 `epsilon_hoop=u/r_q`，并使用该点的
插值温度 `T_q` 计算热膨胀。参见 [cax2t_gps.cpp](../../../elements/src/cax2t_gps.cpp)
第 76--86 行及材料调用。Abaqus CAX4T 的本例结果则对应环向应变的参考体积平均，
以及四个角点温度的算术平均；Fuelsim 已有 CAX4T 也实现了这两条独立规则，参见
[cax4t.cpp](../../../elements/src/cax4t.cpp) 第 188--222 行与第 250--280 行。
其他材料物性的温度规则不能由热膨胀规则类推。

矩形环形单元中，`r_mid=(r_inner+r_outer)/2`。由于位移 `u` 为常数，按 `r dr`
加权的环向应变平均恰好是 `u/r_mid`。本算例 CAX4T 的径向和轴向应变修正量
为零；不能把它误写成三个正应变等分的三维修正。两边弹性应变可以独立写成：

```text
Fuelsim: [0, 0, u/r_q,   0] - alpha*(T_q   -600)*[1,1,1,0]
Abaqus:  [0, 0, u/r_mid, 0] - alpha*(T_mean-600)*[1,1,1,0]
```

分量依次为径向、轴向、环向、张量剪切。使用线弹性关系
`sigma = 2*G*epsilon_elastic + lambda*trace(epsilon_elastic)*I` 即可重建应力；
`E=1e9 Pa`、`nu=0.3`、`alpha=1e-5/K`。这里的公式直接解释原生结果，
没有从误差拟合任何系数。

## 最大差异为何恰好是 57.735%

最大样本是时间 5 s、原生单元 2、积分点 1，即第一片外体靠内侧的材料点。
外体其他时间和材料点也有相同幅度的相对误差，具体最大编号由浮点数尾差决定，
不能解释为该时刻摩擦状态改变造成的突变。

外体内壁为 `629.8702604847631 K`，外壁为参考温度 `600 K`。
两边节点温度一致，重新构造的 Gauss 点温度与生产输出的最大差仅 `1.14e-13 K`，
所以问题不在求出的温度场，而在热膨胀从温度场取哪个温度。

| 量 | Abaqus CAX4T | Fuelsim 靠内侧点 | Fuelsim 靠外侧点 |
| --- | ---: | ---: | ---: |
| 热膨胀温度 / K | 614.935130 | 623.557932 | 606.312329 |
| 径向应力 / MPa | -0.373378 | -0.588948 | -0.157808 |
| 轴向应力 / MPa | -0.373378 | -0.588948 | -0.157808 |
| 环向应力 / MPa | -0.373378 | -0.588948 | -0.157808 |

外体完全约束，三向热应力系数为 `-E*alpha/(1-2*nu)=-25000 Pa/K`。
线性温度插值的两个 Gauss 位置在 `xi=±1/sqrt(3)`，而外壁温升为零，因此
`|T_q-T_mean|/(T_mean-600)=1/sqrt(3)=57.7350269%`。
三个应力分量都按相同比例变化，张量范数误差与弹性应变误差也都是该值。
每个应力分量的绝对差约 `0.215570 MPa`，不是接近零的分母放大造成的现象。

## 内体的两项差异会部分抵消

令 `d_hoop=u*(1/r_q-1/r_mid)`、`d_T=T_q-T_mean`，差值方向为 Fuelsim 减 Abaqus：

```text
delta_sigma_rr = delta_sigma_zz = lambda*d_hoop - 25000*d_T
 delta_sigma_hoop = (lambda+2*G)*d_hoop - 25000*d_T
```

第一步内体靠内侧材料点的机械应变差异贡献为
`[+0.175762,+0.175762,+0.410112] MPa`，热膨胀贡献为
`[-0.266378,-0.266378,-0.266378] MPa`，合计
`[-0.090615,-0.090615,+0.143735] MPa`。因此两项误差不能按百分比简单相加。

| 原始应力比较范围 | 相对 L2 | 相对绝对峰值 | 最大逐点张量相对误差 |
| --- | ---: | ---: | ---: |
| 全部材料点 | 11.5391782% | 11.4951734% | 57.7350269% |
| 内体 | 6.7923739% | 11.4951734% | 13.0665731% |
| 外体 | 57.7350269% | 57.7350269% | 57.7350269% |

这里的相对绝对峰值是最大误差张量范数除以最大参考张量范数，与仓库正式检查器
一致；不是两边最大应力值之差。剪切分量在张量范数中取权重二，全部原生材料点
都保留，没有节点外推、筛除点或给相对误差分母设置下限。

## 独立重建与后处理替换

按上述两套公式重建全部 160 个材料点，Fuelsim 最大应力分量复算差为
`2.794e-9 Pa`，Abaqus 为 `2.503e-9 Pa`；最大弹性应变分量复算差分别为
`1.139e-18`、`1.003e-18`。将实际应力差拆成机械和热两项后，最大剩余分量
为 `3.027e-9 Pa`。这两项已解释本算例所有样本的差异。

以下仅对保存的节点数据应用不同公式，不是修改程序后的求解结果：

| 后处理公式 | 应力相对 L2 | 应力最大逐点相对误差 |
| --- | ---: | ---: |
| 保留原始两套规则 | 11.5391782% | 57.7350269% |
| 只统一热膨胀温度为平均温度 | 10.1614070% | 11.9481058% |
| 只统一环向应变为平均值 | 14.9321873% | 57.7350269% |
| 同时统一两者 | 7.40e-14% | 6.70e-13% |

仅统一环向应变使整体误差增大，是因为移除了内体中的部分抵消；不能据此认为
环向平均更不准确。同时统一两者证明误差分解完整，也不代表已经开发或验收了
采用新规则的一维单元。

此前 [只合并中间节点的原生对照](connection_check.txt) 中，应力变化仅
`2.794e-9 Pa`，已经排除节点是否共享的解释。本次也无需归因于摩擦返回映射、
接触罚刚度、塑性或蠕变；本例没有激活后两种材料机制。

## 结论的适用边界与建议

本次证据表明，原始粗网格的逐点应力差异是两种单元的应变和热膨胀离散定义不同，
没有发现需要通过更改接触求解器来修复的应力缺陷。原有接触量验收和体场未达标
诊断仍保留。连续链算例采用恒温和均匀径向应变，因此两条差异都消失；它的良好
结果不能推广为原始非均匀体场也已经达标。

建议保持 CAX2T_GPS 已定义的材料点温度与直接应变规则，用解析解和相同离散假设
的参考验证其体场。若另要求逐点复现 CAX4T，需要先明确是否采用其专用平均规则，
并同步处理应力、内力和一致切线，不能仅修改输出应力。单纯加密径向网格也不能
保证最大逐点相对误差降到 0.1%：对冷边界恰为无应力参考温度的完全约束单元，
最后一个单元的上述温度比仍为 `1/sqrt(3)`，即使绝对应力差随网格加密减小。
