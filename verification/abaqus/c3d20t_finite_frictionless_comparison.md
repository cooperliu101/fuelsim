# 同一无摩擦接触算例的 C3D20T 与 C3D20RT 对照

为核实是否需要修正共用面到面接触路径，把原无摩擦算例的两套程序均改为
C3D20T。六单元、88 节点网格、材料、有限应变、法向压入、切向移动及反向路径、
热接触、摩擦系数零、280 个 0.025 秒输出间隔全部保持相同。

Fuelsim 输入为 `../fuelsim/transient_c3d20t_finite_contact_frictionless.fsi`。
当前解析器没有显式 `element = c3d20t` 键值；该卡使用 HEX20 网格的默认
二十七点积分设置。检查器逐单元确认输出 `material_point_count=27`，
并读取每步全部 162 个材料积分点，不能把默认入口本身当成积分点数量的证明。
Abaqus 输入为 `c3d20t_finite_contact_frictionless.inp`，显式选择 C3D20T。

两套程序均完成至 7 秒。Fuelsim 接受全部 280 步，没有拒绝时间步，
累计 565 次 Newton 迭代。以下为各自与匹配 Abaqus 参考比较的最大逐点相对误差：

| 字段 | C3D20T | C3D20RT |
|---|---:|---:|
| 温度 | 0.012316% | 0.012316% |
| 热反力 | 0.443848% | 0.443814% |
| 接触压力 | 0.198932% | 0.194101% |
| 接触间隙 | 0.451312% | 0.406657% |
| 法向接触力向量 | 0.218779% | 0.202793% |
| 位移向量 | 0.233593% | 0.324299% |
| 应力张量 | 0.480451% | 0.320541% |
| 接触总热流 | 0.003433% | 0.003433% |

完整相对 L2、相对绝对峰值、逐点误差及零参考绝对误差见
`c3d20t_finite_contact_frictionless_metrics.txt` 和
`c3d20rt_finite_contact_frictionless_metrics.txt`。误差门槛不变。
两套 Fuelsim 单元的无摩擦累计滑移输出均为零，与 Abaqus 几何滑移不同；
这项输出能力差异另行保留，不能解释为物理黏着，也不能解释法向接触误差。

结论：同一算例改用 C3D20T 后仍不满足 0.1%，仅切换体积分规则不能解决问题。
该结果支持继续检查共用接触路径，但不能据此声称已经证明具体算法错误的位置。
本次没有修改生产接触算法，也没有完成同条件性能比较。
