# 应力上升与保持：屈服前蠕变及塑性与蠕变同时激活

按用户最新要求，四项原有测试 B7.2/CAX4T、B9.5/CAX4RT、B10.6/CAX8T、
B12.6/CAX8RT 已加入 J2 塑性。沿用原编号与文件名，但当前内容不再是独立
纯蠕变，也不是先前的极短预加载恒应力路径。此次改造覆盖先蠕变、随后塑性
和蠕变在同一个材料点、同一个时间步内同时产生增量。小应变综合例题的进一步
对齐仍暂停。

## 完整加载与材料

试样为半径和高度均为 1 mm 的单个轴对称单元，温度保持 600 K，无热膨胀。
杨氏模量为 200 GPa，泊松比 0.3。Norton 蠕变为 `dc/dt=1e-28*q^3`；
塑性初始屈服应力为 50 MPa，线性各向同性硬化模量为 200 GPa。
轴向拉应力在 1 s 内线性从零升至 100 MPa，然后保持到 2 s。双方均采用十个
固定 0.2 s 时间步，实际生产输入完整保存在各 `.fsi`，原生输入保存在 `.inp`。

| 时间/s | 应力/MPa | 塑性行为 | 蠕变行为 |
| --- | ---: | --- | --- |
| 0.2、0.4 | 20、40 | 未屈服 | Fuelsim 隐式；Abaqus 显式，首步因步初应力为零而增量为零 |
| 0.6、0.8、1.0 | 60、80、100 | 每步都有正塑性增量 | 两侧均有正蠕变增量，且符合隐式公式 |
| 1.2—2.0 | 100 | 塑性累计值保持 | 蠕变继续增长；恒应力下无法仅用增量区分显式与隐式 |

## 可独立计算的离散解析解

外载直接决定单轴应力 q，因此可以在不重算有限元问题的情况下计算两种历程：

```text
q_n = 1e8*min(t_n,1)
p_n = max(0,(q_n-5e7)/2e11)
Fuelsim: Δc_n = Δt*1e-28*q_n^3
Abaqus:  前两个加载步 Δc_n = Δt*1e-28*q_(n-1)^3
         随后塑性激活的加载步 Δc_n = Δt*1e-28*q_n^3
         保持段 q_n=q_(n-1)，两式相同
ε_elastic = [-ν*q/E, q/E, -ν*q/E, 0]
ε_plastic = [-p/2, p, -p/2, 0]
ε_creep = [-c/2, c, -c/2, 0]
u_r = r*(-ν*q/E-(p+c)/2), u_z = z*(q/E+p+c)
底部轴向反力 = -π*(0.001)^2*q
```

张量顺序为径向、轴向、环向、径向—轴向剪切。两侧塑性累计值由相同应力与
硬化关系决定，因此相同；蠕变保留了屈服前时间积分产生的历史差异。

| 时间/s | 等效塑性累计值，两侧相同 | Fuelsim 隐式累计蠕变 | Abaqus 分段积分累计蠕变 |
| --- | ---: | ---: | ---: |
| 0.2 | 0 | 1.6e-7 | 0 |
| 0.4 | 0 | 1.44e-6 | 1.6e-7 |
| 0.6 | 5e-5 | 5.76e-6 | 4.48e-6 |
| 0.8 | 1.5e-4 | 1.6e-5 | 1.472e-5 |
| 1.0 | 2.5e-4 | 3.6e-5 | 3.472e-5 |
| 2.0 | 2.5e-4 | 1.36e-4 | 1.3472e-4 |

0.6、0.8、1.0 s 三步的等效塑性增量分别为 5e-5、1e-4、1e-4，蠕变增量
分别为 4.32e-6、1.024e-5、2e-5。这些非零增量直接证明“同时触发”，不能
仅用终态两种应变非零替代。最终蠕变绝对差为 1.28e-6，相对 Abaqus 约
0.95012%；0.4 s 的相对差仍约为 800%。保持段没有消除既有蠕变历史差异。

## 验收方式

保留四个原有生产测试入口，不新增重复自动算例。检查器读取实际
`fuelsim -i <case.fsi>` 输出与已追踪的原生参考，逐时间步、每节点及每活跃
材料点比较各自的离散解析解。检查温度、完整位移、底部合反力、完整应力与
弹性/塑性/蠕变张量、两种等效非弹性历史、每步塑性与蠕变增量，以及零热反力。
所有已定义非零场的三种相对误差仍须小于 0.1%，零参考量另按原绝对门槛检查。

每个材料点必须恰有三个时间步同时满足塑性与蠕变增量大于 1e-8；四种单元
对应每侧 12、3、27、12 个“材料点—时间步”样本。该额外激活断言不能替代
逐步解析解检查。跨程序位移和蠕变差异仍输出为 `cross_solver_diagnostic_*`，
保留首步零参考绝对差，不设置分母下限，也不声称两侧彼此通过 0.1%。

此测试与原 B7.0/B9.3/B10.4/B12.4 的直接塑性加载不同，增加了屈服前蠕变
和进入耦合阶段的历史覆盖。测试通过表示两种历程分别符合各自离散解。

## 原生证据

四份最终输入均重新运行 Abaqus，包含完整 PE/PEEQ 和 CE/CEEQ 输出。
成功状态和输入散列已核对；B9/B10/B12 运行记录还核对了对应提取器散列。
B7 旧运行器只记录输入散列，不把事后计算的提取器散列当作运行器记录。
节点、材料点、运行记录和逐字段比较沿用原正式文件名，由 `SHA256SUMS`
记录当前参考版本。原纯蠕变的最终 17.24% 差异已不适用于这次耦合历程。
