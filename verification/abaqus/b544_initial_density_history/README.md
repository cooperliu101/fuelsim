# B5.44 原始温度表、初始常密度历史参考

本目录逐字保存 2026-09-13 以初始单值密度 2000 kg/m³ 运行的 Abaqus R2018x 输入、四份原生 CSV、日志及来源记录。它保留原 300 K/700 K 材料表和默认沙漏控制；不包含早期温度相关密度。

当前正式参考沿相同材料直线补足 280 K/800 K 温度表，并显式保持初温 300 K 对应的沙漏刚度 400000 Pa，见[完整报告](../b544_initial_density_validation.md)。本目录用于原始对比及规定历程隔离实验的溯源，不覆盖或改写原生结果。

`SHA256SUMS` 可通过 `sha256sum -c SHA256SUMS` 验证本目录文件。
