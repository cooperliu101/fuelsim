相对误差三项的最大值，已经换算为百分数。门槛为 **小于 0.1%**。零参考量
按各字段 SI 单位的独立绝对误差验收，不设置相对误差分母下限。

两个轴向链算例的芯块和包壳中间控制节点均不施加位移约束，由整体平衡求解。
检查器独立预测中间位移、各切片不同的轴向应变、全部材料与接触积分点、端部
反力、机械功、摩擦耗散及对应参考或当前体积下的弹性能变化。有限应变材料
算例在十个增量的两个积分点共二十次同时产生塑性与蠕变；累计 Hughes-Winget
应变最大绝对误差为 `6.94e-18`，另以 `1e-12` 为门槛，不能用总对数应变替代。

接触历程覆盖粘着、正向滑动、反向重新粘着、反向滑动、张开、张开期间移动及
再接触。除逐点接触量外，还从 Fuelsim 两侧全部轴向控制节点的实际反力独立
检查合力和守恒。原生参考数据、输入、提取脚本、执行日志及校验和在
[Abaqus 参考目录](abaqus/gps_1d/README.md)，本次 `SHA256SUMS` 全部通过。

接触算例的热膨胀已按用户要求改为每个径向单元的两节点算术平均温度，
两个材料点采用相同膨胀温度，其他物性仍按积分点温度求值。环向应变按参考
体积平均后，全部内外体十步的 160 个原生应力和弹性应变样本、80 个径向
反力、60 个共享轴向控制节点反力及 40 个截面力全部纳入 0.1% 正式验收。
内体最大逐点应力相对误差由 11.9481058% 降至 `1.068e-13%`。
当前误差和增量历史检查见 [环向平均更新记录](abaqus/gps_1d/mean_hoop_update.md)。

改动前 57.735% 体场差异的原因分析作为
[历史记录](abaqus/gps_1d/contact_stress_diagnosis.md)保留，不代表当前程序。
有限应变接触仍由多切片独立解析与局部切线验收；新增非均匀有限应变原生
算例鉴定体单元平均伸长比历史及反力，不据此宣称有限应变接触已完成 Abaqus
全场鉴定。温度相关弹性模量的取温差别另存为
[原生探测](abaqus/gps_1d/nonuniform_elastic_temperature_probe/README.md)，不扩大本次算法范围。

补充的原生连续链采用均匀径向应变和恒温条件，自由中间端面的位移、各片应变、
应力、反力和摩擦传力比较见 [chain_metrics.txt](abaqus/gps_1d/chain_metrics.txt)。
只合并原受控接触算例的中间节点，应力变化仅 `2.794e-9 Pa`；这一对照排除了
节点未共享导致修改前 57.735% 差异的解释，详见

## 状态与程序入口

- 实际生产程序运行至时间 5 写检查点，再由另一张完整输入卡继续至时间 10，
  全部续算输出帧与连续运行对应帧一致。
- 有限应变双轴向链使用同一张输入卡分别进行单进程和双进程计算，全部节点、
  单元及全局结果一致；连接表、控制属性、变量名和 NaN 分布严格相同。
- 内部测试覆盖两个材料积分点、最后一个轴向自由度、最后一个接触积分点、
  时间误差、接受与失败恢复、区间平均热源以及检查点字节恢复。
- 局部体单元和接触同时检查中心差分方向导数、独立残量重复调用、非法几何
  拒绝及守恒。稳态受载局部测试另外确认非零弹性应变正确写入结果历史。

检查点格式已由 18 更新为 **19**，不提供旧版本兼容读取。完整运行输入均直接
提交为 `.fsi` 文件；测试调度只逐字复制文件，并执行 `fuelsim -i <case.fsi>`。
外部比较检查器不链接生产核心或求解器，也不重新求解物理问题。

## 适用范围与复现

该降维模型支持小应变及对角有限应变，各实体沿轴向完整耦合。圆柱接触保持
匹配参考切片配对，尚不支持跨切片大滑移、非匹配轴向分片或端面接触；模型
也不包含轴向导热、二维剪切和弯曲，摩擦耗散不自动转为热源。网格、输入和
方程定义见[一维框架说明](../docs/axisymmetric-1d.md)。

按仓库 AGENTS.md 配置依赖后运行：

```bash
cmake --build build --parallel 4
ctest --test-dir build -j4 --output-on-failure
cmake --build build-elements --parallel 4
ctest --test-dir build-elements -j4 --output-on-failure
```
