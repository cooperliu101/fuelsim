# 截面模态生产求解与三维板比较

此目录包含完整、可直接运行的 `.fsi` 输入卡。所有结构计算均运行
`fuelsim -i <case.fsi>`；Python 程序只生成网格、调度不变的输入卡或读取结果，
不装配、不重新求解力学问题。新增三维参考来自 Fuelsim C3D20T，不能当作新的
Abaqus 工程鉴定。

## 输入与实际求解范围

在原有稳态 Cartesian 三维输入中增加：

```text
[SectionModes]
  count = 12
[]
```

省略该节仍运行完整三维实体求解。生产入口目前要求一个沿正 z 方向固定挤出的
HEX20 Exodus 网格，自动从端面提取 QUAD8 截面，从单元端点提取轴向网格。
截面可以是不规则四边形网格，并可由多个共享节点的命名材料块组成；本目录的
矩形只是一种验证几何，生产求解器没有矩形网格生成代码。轴向单元必须完整覆盖
同一截面，材料区域与连接不能随 z 改变。重复坐标但不相连的截面、漏单元、重叠
轴向区间、曲折轴线和不匹配端面会明确报错。

材料继续使用现有接口，但本轮只接受固定温度、无本征应变的线弹性小应变。
`[Executioner]` 只接受 `type=steady`、`load_steps=1`。求解器采用直接 LU/MUMPS；
允许的 Solver 字段为 `linear_solver`、`preconditioner`、`direct_factorization`、
`absolute_tolerance`、`relative_tolerance`、`maximum_iterations`，一次线性求解即完成。
残量验收作用于经过对角尺度变换的线性系统。其他迭代、非线性或时间推进选项不能
被静默忽略。压力和牵引必须采用参考构形；支持节点集或边集上的物理位移约束。
温度约束必须等于区域初温。体力、接触、热载荷、重启动和检查点尚不支持。

`count` 范围为 3 至 64，还须满足截面可提供的独立方向数量。基始终嵌套增加：

| 幅值序号，从 1 开始 | 含义 |
| --- | --- |
| 1—3 | 轴向伸长、厚度方向弯曲、宽度方向弯曲 |
| 4 | Saint-Venant 扭转及求得的轴向翘曲 |
| 5—6 | 两个独立剪切转角；关闭时保留原有经典弯曲剪切相消 |
| 7—9 | 独立泊松松弛幅值，横向场来自三个经典截面辅助问题 |
| 10 起 | 按有限特征值升序选取的自动畸变模态及凝聚翘曲 |

上表适用于本例 ν=0.3 的非退化截面。零或相关的泊松修正不占用幅值。
每个轴向节点、每个模式保存 q、q′、q″ 三个自由度；一维单元采用五次 Hermite
插值和六点积分。三维剪切、轴向翘曲导数和泊松修正的高阶导数均保留。
横向截面节点从不成为全局未知量。

自动有限谱与非刚体剪切零空间分开处理。离线 API 可以返回零空间中的模式，
当前默认生产基没有包含整个零空间，也没有包含任意独立轴向翘曲场；因此有限谱
的数量增加不构成逼近任意三维位移场的完备性证明。自动谱的离线密集部分限制为
512 个横向自由度，稀疏翘曲因子分解仍由 PETSc 管理。

## 输出

模态输入必须给定 `Outputs.csv` 和 `Outputs.history`，暂不写模态 Exodus 结果。
汇总 CSV 包含模式分类数量、轴向节点数、实际未知量数、约束数、应变能、外功及
平衡残量。外功包括非零给定位移的约束反力做功。

历史 CSV 使用固定表头，以 `kind` 指明有效字段：

- `node`：原始 Exodus 节点编号，从零开始，坐标及三个重构位移。
- `point`：每个轴向和截面材料积分点的坐标、体积积分权重及六分量应变、应力。
- `section`：轴向积分位置的 N、Mx、My、扭矩及每单位轴长应变能。
- `amplitude`：轴向节点编号、z、从零开始的模式编号及 q、q′、q″。

不同记录类型中不适用的公共字段为零，新增的专用字段为空。应变分量按
`[xx,yy,zz,xy,yz,xz]` 排列，剪应变为张量剪应变。
取 X、Y 相对材料加权中心，截面内力约定为
`N=∫σzz dA`、`Mx=∫Yσzz dA`、`My=−∫Xσzz dA`、
`Tz=∫(Xσyz−Yσxz)dA`，对应正 z 截面。

## 四类同条件比较

共同几何：H=0.002 m，W=0.02 m，L=0.2 m；x∈[−0.001,0.001]，
y∈[−0.01,0.01]，z∈[0,0.2]。E=70 GPa，ν=0.3，固定温度 300 K。
所有根部 z=0 节点的三个物理位移均为零，不用广义梁夹持替代三维夹持。

基准网格沿 x/y/z 为 2/4/8 个 HEX20，共 64 个实体单元、453 个位移节点，
完整三维机械未知量为 1359。提取的截面有 37 个 QUAD8 节点、8 个单元和72个
截面积分点，轴向有9个端节点。3/4/6/8/12 个模态对应81/108/162/216/324个
机械未知量。温度在三维程序中全部固定，不计入上述机械未知量比较。
模态约束另使用单独报告的拉格朗日乘子，实际线性系统维数为幅值自由度数加独立约束数。
模态模型仍逐点保留 8×6×72=3456 个材料响应位置，没有降维材料状态。

| 算例 | 物理载荷 |
| --- | --- |
| axial | 端面均布轴向牵引 1 MPa，合力 40 N |
| bending | 端面 x 正负两半分别施加 ±10 kPa 轴向牵引，合力为零，My=−0.0002 N·m |
| transverse | x 正面均布向内压力 10 Pa，横向线载荷 −0.2 N/m |
| nonuniform | x 正面、y≥0 半宽施加 −20 Pa 的 x 方向牵引，横向合力不变，并产生扭转 |

弯曲算例是纯端部力偶；其端面牵引为两段常数，不是线性的解析弯曲应力分布，
端部局部差异也参与比较。前三类比较 3 和 12 个模式，非均匀载荷比较
3、4、6、8、12 个模式，输入卡分别完整提交。

位移比较覆盖全部共同源节点。轴向应力按体积权重计算相对 L2 误差，覆盖三维
模型每个单元的全部27个原生材料点；模态应力由其3×3×6积分样本作精确多项式
插值到相同物理位置。这个插值只适用于本例仿射、均匀线弹性的网格。
弯矩由相同位置上的 σzz 积分后比较。应变能分别使用各自全部原生积分点；
三维应变通过线弹性柔度从输出应力恢复。轴向拉伸的解析弯矩为零，只记录绝对
弯矩误差，不设置相对误差分母下限。完整结果还保留六分量应力误差和轴力误差。

2026-09-15 的实测结果如下。表内均为相对误差百分比，空项为零参考弯矩：

| 算例 | 模式数 | 位移 | 轴向应力 | 弯矩 | 应变能 |
| --- | ---: | ---: | ---: | ---: | ---: |
| axial | 3 | 0.401216 | 5.155284 | — | 0.247824 |
| axial | 12 | 0.186160 | 1.983439 | — | 0.103408 |
| bending | 3 | 4.000743 | 14.093191 | 15.329790 | 1.603314 |
| bending | 12 | 0.548270 | 2.796824 | 2.527992 | 0.269514 |
| transverse | 3 | 6.744723 | 28.517519 | 30.876785 | 7.490312 |
| transverse | 12 | 1.305283 | 9.524403 | 9.684098 | 1.447303 |
| nonuniform | 3 | 6.751396 | 28.527526 | 30.876789 | 7.732771 |
| nonuniform | 4 | 6.744702 | 28.526669 | 30.876789 | 7.459749 |
| nonuniform | 6 | 5.516622 | 23.726753 | 25.601177 | 6.081820 |
| nonuniform | 8 | 0.774324 | 10.343922 | 9.926721 | 0.865352 |

这些结果证明了三种经典模式之外的运动学补充有作用，但没有证明所有误差随模式数
单调下降，也没有达到所有场小于0.5%的工程精度。两种模型的轴向近似空间不同，
模态刚度的变分改善不保证相对某个粗三维网格的位移误差单调减少。

## 三维参考的独立网格检查

手动验证卡 `transverse_refined_solid.fsi` 使用4/8/32网格，共1024个HEX20单元，
16299个机械未知量。相比基准三维网格，共同节点位移变化2.44552%，应变能变化
2.72371%，因此原64单元三维结果不能视为高精度真值。

12模式模型与这个加密三维模型比较，位移误差1.17204%，应变能误差1.31583%，
轴向应力误差3.40496%，弯矩误差3.11301%。后两项保留加密三维模型全部27648个
原生材料点，在这些位置重构同一个粗截面模态解。
相对载荷平衡解析弯矩 `My(z)=−0.2(L−z)^2/2`，粗三维、加密三维和12模式模型
的相对L2误差分别为10.2102%、2.16293%、2.01990%。这说明基准比较中的大弯矩误差
也含有三维参考的应力离散误差；还需要进一步独立网格收敛，不能据此宣称模态模型
已经通过三维精度鉴定。重复网格扫描按仓库规则保留为手动验证，不加入CTest。

## 运行与验收

```bash
build/fuelsim -i verification/section_modal/nonuniform_12.fsi
ctest --test-dir build -j8 -R 'fuelsim_(section_modal_|modal_beam_tests|section_distortion_tests)' --output-on-failure

# 可选：重建受追踪的网格；不会生成或修改输入卡。
python verification/section_modal/mesh.py
build/fuelsim -i verification/section_modal/transverse_refined_solid.fsi
python verification/section_modal/refinement.py build/blackbox/section_modal_transverse verification/section_modal
```

测试调度和结果检查需要 Python、NumPy、netCDF4，与验证网格工具使用同类依赖；
生产库没有增加 PETSc、ADlite 和 Exodus 之外的依赖。CTest 将完整输入卡和网格
逐字复制到 `build/blackbox/section_modal_<case>/`，保留每次生产运行日志、CSV及三维
Exodus结果，并生成 `<case>_comparison.csv`。本目录 `results/` 保存本次测量摘要。

自动测试检查原始物理位移约束、平衡残量、外功与应变能、积分点与截面内力输出
的一致性、嵌套空间的柔度不减及全节点/全材料点覆盖。非零端位移算例单独检查
给定位移及反力功；双进程算例比较完整位移、应力和能量。模型精度表是独立的
诊断结果，没有通过调整误差门槛把尚未收敛的模式截断标记为鉴定通过。

使用命名 Conda 环境中的 PETSc 配置时，CMake 优先选择基础 Conda 环境里的验证
解释器，并检查所需读取模块。其他安装布局可以显式设置 `FUELSIM_SECTION_PYTHON`。
