# 降低圆筒径向热流误差的研究

## 结论

此前 DCAX4 的 16 单元圆筒最大积分点热流误差为 3.45051%。该误差来自一阶
温度插值的空间离散，不是非线性求解未收敛。通过加密网格、改变径向网格分布，
或者使用已有的 DCAX8 二阶温度单元，都可以降低误差。本轮没有改动生产算法、
材料、载荷、热流输出定义或原有 0.5% 验收门槛。

所有结果均由实际生产程序运行完整静态输入卡获得，比较全部节点温度、温升、
全部积分点径向热流、两个零横向热流分量及热端总反力。非零量的相对二范数、
峰值和最大逐点误差要求均小于 0.5%，零热流单独使用 `1e-7` W/m² 绝对门槛。
报告使用原始积分点热流，没有用平均、平滑或节点恢复后的热流替换它。

| 单元和径向网格 | 单元数 | 约束前温度自由度数 | 最大积分点热流误差 | 上述指标是否全部满足门槛 |
|---|---:|---:|---:|---|
| DCAX4，均匀网格，原算例 | 16 | 34 | 3.450507% | 否 |
| DCAX4，均匀网格 | 64 | 130 | 0.891552% | 否 |
| DCAX4，均匀网格 | 128 | 258 | 0.448385% | 是 |
| DCAX4，等比径向网格 | 16 | 34 | 2.021423% | 否 |
| DCAX4，等比径向网格 | 64 | 130 | 0.497990% | 是，余量很小 |
| DCAX8，均匀网格 | 4 | 23 | 1.358244% | 否 |
| DCAX8，均匀网格 | 8 | 43 | 0.413694% | 是 |
| DCAX8，均匀网格 | 16 | 83 | 0.115504% | 是 |

这些误差限于此次固定圆筒的节点和积分点比较，不等同于任意几何、材料和边界
条件的精度保证。自由度数量可用于比较模型规模，本轮没有测量或宣称运行速度优势。

## 误差来源的独立推导

圆筒内外半径为 0.01、0.03 m，高度 0.01 m，导热系数为 10 W/(m K)，
内外温度为 400、300 K，上下端绝热，没有体热源。解析解为：

```text
T(r) = 400 - 100*ln(r/0.01)/ln(3)
q(r) = 1000/(r*ln(3))
Q = 20*pi/ln(3)
```

令第 i 个径向区间为 `[a_i,b_i]`，宽度为 `h_i=b_i-a_i`，中间半径为
`m_i=(a_i+b_i)/2`，并令 `S=sum(h_i/m_i)`。轴向温度不变时，DCAX4 的
径向温度梯度在每个区间内为常数。轴对称权重中的半径是一次函数，其积分已被
当前高斯积分精确计算。将各区间的离散热阻相加，得到离散解析式：

```text
Q_FE = 20*pi/S
q_FE,i = 1000/(S*m_i)
q_FE,i/q(r_q) = (ln(3)/S)*(r_q/m_i)
```

其中 `r_q` 为实际输出积分点半径。脚本直接利用网格坐标代入这些解析式，
没有链接生产库，也没有建立第二个数值求解器。
五个 DCAX4 算例的原始热流与该公式一致，最大相对差异低于 `3.1e-13`。
因此，此算例的离散公式和实际程序输出已经互相核对。

误差可以分成两部分：`ln(3)/S` 是整个圆筒的热流量偏差，`r_q/m_i` 是
单元常梯度无法逐点表示 `1/r` 的偏差。原 16 单元网格的总热量误差仅为
0.052545%，但局部热流最大误差为 3.45051%，后者占主导。
最大误差位于最靠内壁单元内、半径约 0.01098584 m 的高斯点。
这也解释了为什么节点温度已经较准确，热流仍可能不满足要求。

收紧求解器残量门槛或增加此矩形单元的积分点，不能消除已经精确复现的
常梯度插值误差。若要保留 DCAX4 的现有离散，直接有效的措施是改网格。

## 网格分布和建议

均匀网格的 `h_i/m_i` 在内壁附近最大，所以误差先集中在那里。
等比径向网格采用 `r_i=0.01*3^(i/N)`，使各单元的相对径向厚度保持一致；
单元在内壁附近更小，在外壁附近更大。其两类高斯点相对热流误差在各径向
区间基本相同，避免将大部分单元用于原本较容易解析的外侧区域。

实测 64 个等比单元刚好低于门槛，但 0.497990% 与 0.5% 很接近，不宜把它
作为其他问题的默认精度保证。若必须保持 DCAX4，128 个均匀径向单元是此次
已经验证且余量更大的方案。

若允许使用二阶单元，优先采用 16 个 DCAX8 径向单元：此次最大积分点热流
误差为 0.115504%，温度自由度只有 83 个。8 个 DCAX8 单元也已满足当前门槛。
切换必须使用包含边中点的 QUAD8 网格并显式选择 `dcax8`，不能只在四节点网格的
输入卡中修改型号名称。已有 DCAX8 原生比较继续约束该生产离散，本轮研究只
增加解析解与加密资料，没有改变单元公式。
