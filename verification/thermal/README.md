# 独立温度求解与 Abaqus 2025 对比

所有 Fuelsim 算例运行实际入口 `fuelsim -i <case.fsi>`。输入卡是完整静态文件，
检查脚本只逐字复制输入卡、启动程序、读取 Exodus 输出并比较已保存的原生参考。
日常 CTest 不启动 Abaqus。`mesh.py` 只生成网格及 Abaqus 网格 include；
`run_abaqus.ps1` 在 Windows Abaqus 2025 上逐个使用一个 CPU 重算参考，
`extract.py` 从原生 ODB 导出节点温度、节点热反力和积分点热流及坐标。

## 几何、载荷和验收

四种型号均使用四个径向或 x 方向单元。轴对称半径为 0.01—0.03 m，
高度 0.01 m；三维长 0.02 m、宽和高均为 0.01 m。
材料导热系数为 10 W/(m K)，初始密度为 1000 kg/m³，比热为 100 J/(kg K)。

| 算例 | 边界与时间 | 比较范围 |
|---|---|---|
| 四个 `*_steady` | 左侧向内热流 1000 W/m²，体热源 100000 W/m³；右侧对流系数 100 W/(m² K)，环境 300 K | 全部节点温度、热反力及全部积分点热流 |
| 四个 `*_transient` | 初始 300 K，左侧初始及边界 400 K；右侧同上；后向欧拉步长 2 s，终止 20 s | 十个时刻全部节点温度、温升、热反力及全部积分点热流 |
| `dcax8_contact` | 两个独立节点的相邻环，半径 0.01—0.02—0.03 m，高 0.01 m；内外定温 400/300 K，界面导热系数 1000 W/(m² K) | 两侧全部节点和积分点，匹配二次轴对称边界传热 |
| 两个 `*_capacity` | 单个畸变一阶单元，全部节点从 300 K 在 1 s 内升至 400 K；无体热源 | 每个节点热反力，核对默认热容权重；全部热流为零 |

默认一阶热容按型号分别处理：DCAX4 使用 `integral(N_i*dV)` 节点权重，
DC3D8 使用角点配对的高斯点体积权重。两者均为节点对角热容。
二阶 DCAX8、DC3D20 使用一致热容矩阵，所有中间节点均有温度未知量。
畸变探测的具体坐标见对应 `*_capacity_mesh.inp`；它能区分三维高斯点配对权重、
形函数体积分权重和角点 Jacobian 权重。该探测使用常数材料和固定几何，
不据此鉴定温度相关比热在 Abaqus 中的更新规则。

非零字段同时检查相对二范数误差、峰值误差和最大逐点误差，门槛均为 0.5%。
零参考点单独检查绝对误差，不设置相对误差分母下限；零热流绝对门槛为
1e-7 W/m²，零热反力为 1e-7 W。原生 ODB 字段为单精度，正常温度差约 1e-5 K。
每次检查在构建目录保存原始生产日志和 `comparison.json`，不截取代表节点。
首次完成的十一项原生比较全部通过，逐项误差保存于
[validation_summary.json](validation_summary.json)。最大逐点相对误差分别为：
温度 4.54e-8、相对 300 K 的温升 1.10e-6、热反力 5.29e-8、非零热流 1.10e-7。

## 内部数值检查与边界

四个局部单元测试检查非线性导热、比热温度导数、热容矩阵结构、固定初始质量、
残量重复调用、方向差分及二次温度插值。状态测试检查接受、恢复、失败回滚、
检查点及温度时间误差。均匀升温生产算例还检查时间函数定温边界的更新。
单进程与双进程比较使用同一完整 DC3D20 瞬态输入卡，比较全部输出场。

局部界面测试覆盖非匹配轴对称直边与三维二次面、投影唯一性、守恒和温度切线。
外部界面对比目前仅覆盖匹配轴对称二次边，不能推广为任意非匹配曲面的验证。
本组原生算例为常数材料；温度相关材料的导数由局部测试约束。
首版不支持辐射、潜热、各向异性导热、变形及压力相关界面导热。

## 运行

```bash
ctest --test-dir build -R 'fuelsim_(dcax|dc3d|thermal)' -j8 --output-on-failure
```

参考文件的 SHA256 校验清单独立保存为 `SHA256SUMS`，防止无意替换参考。
