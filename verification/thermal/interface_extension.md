# 非匹配曲面与非均匀瞬态界面的组合验证

这两项补充此前分别验证的曲面/非匹配界面，以及均匀温度场的自适应重启。
全部计算使用生产程序与完整静态输入卡。没有修改生产离散、求解算法或字段容差。
新增两个 Abaqus 2025 原生算例均比较全部输出时刻、全部节点温度与热反力，
以及全部材料积分点的热流。纯热原生比较由此前 34 项增加至 36 项。

## 非匹配二次曲面

`study_dc3d20_curved_nonmatching` 使用三个二十节点六面体，共 52 个温度节点、
81 个材料积分点。一个从侧二次面跨越两个相邻主侧二次面；主侧沿 y 方向
划分为两个单元，共用节点；界面两侧保持独立源节点。
界面坐标满足：

```text
x = 0.01 + 0.001*((y/0.01-0.5)^2 + 0.6*(z/0.01-0.5)^2)
0 <= y,z <= 0.01 m
```

该曲面具有两个方向的曲率，粗细两侧描述同一二次曲面。
热端温度为 `400+50*y/0.01+50*z/0.01` K，冷端为 300 K，其余外表面绝热。
体导热系数为 10 W/(m K)，界面导热系数为 1000 W/(m² K)。
因此两个切向均有非均匀温度和非零热流，不能用仅径向或均匀温度的结果代替。

原生比较的最大逐点相对误差为 **0.00006356%**，温度最大绝对误差为
`1.517e-5` K。所有非零字段继续分别要求相对二范数、峰值和最大逐点误差
小于 0.5%，零参考量继续单独使用绝对门槛。

八个从侧二阶节点邻域全部有有效投影，没有未投影邻域。
热端反力为 `5.007669631391688` W，冷端反力为 `-5.007669631391696` W，
总差约 `8.0e-15` W；程序输出的界面总热量与热端反力独立比较通过。
跨两个主侧面的完整原生字段比较和两端热量检查共同约束漏计或重复传热。

此结论限于这一个完整重合、沿单个切向作 2:1 划分的二次曲面。
它不代表任意非匹配曲面、部分重叠、不同曲率逼近、移动界面均已验证。

## 多材料界面与时变热源

`study_interface_variable_source` 使用两个边长 0.01 m 的八节点立方体。
两区域的导热系数、初始密度和比热分别为 `(10,1000,100)`、`(20,2000,200)`，
采用 SI 单位，界面导热系数为 1000 W/(m² K)。热端固定 400 K，冷端对流系数
100 W/(m² K)、环境温度 300 K；除热端节点外，初始温度为 300 K。

两区域体热源分别为 `10^6*p(t)` 和 `2*10^6*p(t)` W/m³。
`p(t)` 经过 `(0,1)、(1,2)、(2,0.5)` 三点，区间内线性变化。
两区域均显式采用现有 `heat_source_time_evaluation=interval_average`，
即精确平均当前时间步内的热源。固定时间步为 0.1 s，终止时间 2 s，
全部二十个时刻与 Abaqus 比较，最大逐点相对误差为 **0.0008193%**。

初次输入省略该选项时使用默认步末采样，和 Abaqus 的步内平均不同，温升最大
相对误差为 4.2953%。诊断输入、网格和失败比较保留在
`interface_extension_diagnosis/`。这里只显式选择已有的载荷积分方式，
没有改变默认行为，也没有通过减小参考温升、修改输出字段或放宽门槛消除差异。

检查器从节点温度独立积分每个区域的储热；两区域的质量乘比热分别为
0.1、0.4 J/K。固定步长下还从两侧面平均温差计算界面热量、从外表面温度
计算对流热量，并分别核对两个区域的能量平衡。
这项检查不只依赖程序输出的全局平衡值，也不在脚本中重新求解温度问题。

## 自适应重试、磁盘重启和进程数变化

三个完整输入卡 `study_interface_adaptive_full`、`study_interface_adaptive_first`
和 `study_interface_adaptive_resume` 保持上述几何、材料、边界和时变热源。
采用一个整步与两个半步的误差控制，接受两个半步的解。
初始步长为 1 s，温度相对时间误差容差为 `1e-5`，绝对容差为 `1e-4` K。
完整计算到 2 s；分段计算在 1 s 写入检查点，再启动新的进程恢复。

实际发生 **8 次时间误差超限后的缩步重试**，最终接受 **103 步**。
最大界面温差为 41.2654 K，全域温度范围始终不小于 73.8221 K，
确认此次检查确实包含空间温度梯度及非零界面传热。

逐时刻比较所有节点与积分点输出、物理时间序列和全部工程历史列：

| 比较方式 | 最大温度差 |
|---|---:|
| 单进程连续计算与单进程分段重启 | 0 K |
| 单进程与双进程连续自适应计算 | `2.274e-11` K |
| 单进程写检查点、双进程恢复，与连续计算 | `2.558e-11` K |

全部字段和历史沿用相对 `1e-11`、绝对 `1e-9` 的一致性要求，时间网格直接
逐点比较，不插值到共同网格；两种进程数的失败重试次数也必须相同。
单进程到双进程的恢复使用原始检查点文件，未在脚本中编辑或重建状态。

每个接受时间步还独立检查初始质量对应的储热增量、精确积分的时变热源及
界面和全局能量平衡。总热源输入为 8.25 J；自适应储热计算最大差约
`5.06e-12` W，全局热率不平衡低于 `5.47e-12` W，界面热率不平衡低于
`2.52e-16` W。两个半步的源项平均检查可以识别只保留第二个半步诊断的错误。

该瞬态组合使用固定平面 DC3D8 界面，未将非匹配曲面与自适应重启进一步
组合到同一个模型。纯热问题没有机械历史，不能替代塑性、蠕变历史恢复测试。

## 执行与证据

```sh
env OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  taskset -c 0-3 ctest --test-dir build \
  -R 'fuelsim_thermal_interface_(curved|transient)_extension' -j4 --output-on-failure
```

双进程组在 CTest 中占用两个调度名额，所有计算限制在四核范围。
日常测试读取已提交的原生参考，不启动 Abaqus。
逐字段结果保存在 `interface_curved_summary.json` 和 `interface_transient_summary.json`，
输入和原生证据由 `SHA256SUMS` 保护。最终构建和回归记录见 `validation.md`。
