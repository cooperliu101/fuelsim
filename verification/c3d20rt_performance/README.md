# C3D20RT 接触计算性能验证

日期：2026-09-16。基线提交：`35c96291d4a45216d0e985865d6e818b5d0089ca`。
C3D20RT 是二十节点、减缩积分的三维温度—位移耦合单元。

## 结论与适用范围

现有有限应变接触首增量例题的外部总耗时中位数从 **4.927 秒降到 4.501 秒**，
减少 **8.65%**，对应 **1.095 倍**加速。两个版本均接受一个时间步，
执行 14 次非线性迭代、22 次残量计算和 14 次导数矩阵计算，没有失败重试。
该结果证明这个接触建立过程的加速，不代表所有 C3D20RT 模型或完整摩擦加载历程的加速。
这里比较的是修改前后的 Fuelsim，不是与 Abaqus 的运行速度比较。

## 例题与运行条件

- 主例题使用完整的
  [`transient_c3d20rt_finite_contact_first_increment.fsi`](../fuelsim/transient_c3d20rt_finite_contact_first_increment.fsi)。
  网格有 6 个二十节点单元、88 个几何节点和 296 个全局自由度。
  两个区域初温分别为 300 K 和 400 K，包含间隙传热、有限滑移机械接触和摩擦。
  摩擦系数为 0.3，法向罚刚度为 `1e11`。计算一个 0.025 秒时间增量；
  受控边界的 x、y 位移分别达到 `-5e-4 m` 和 `1.25e-4 m`。
- 两个对照例题分别为
  [`transient_c3d20rt_finite_coupled.fsi`](../fuelsim/transient_c3d20rt_finite_coupled.fsi)
  和 [`transient_c3d20rt_small_coupled.fsi`](../fuelsim/transient_c3d20rt_small_coupled.fsi)。
  它们使用一个单元，计算塑性与蠕变共同作用下的十个时间增量，不含接触。
- 使用同一台 Windows 下的 WSL2 Linux 主机，处理器为 Intel Core i9-13980HX；固定 CPU 0、一个求解进程，
  `OMP_NUM_THREADS=OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=1`，采用输入卡原有的 MUMPS 直接求解器。
- 两个版本均使用 GCC 14.3.0 C++ 编译器、Release 优化构建、`-O3 -DNDEBUG`、链接时优化开启，
  使用同一套 Conda PETSc、ADlite 0.2.3 和串行 Exodus 依赖。
- 输入卡及网格逐字复制到各自隔离目录。原有控制台、Exodus、工程历史与检查点输出均保留。
  时间步、材料、载荷、接触参数、求解控制和验收门槛均未调整。
- 每个版本先预热一次，再交替测量五次，逐轮交换前后顺序。
  外部时间由 Python 单调时钟包围整个生产程序进程测得，包含启动和文件输出。
  正式计时期间不运行编译或 CTest。

## 实测结果

单位为秒，表中均为去掉预热后的中位数。

| 例题 | 修改前外部总耗时 | 修改后外部总耗时 | 修改前内部总耗时 | 修改后内部总耗时 |
|---|---:|---:|---:|---:|
| 有限应变接触首增量 | 4.927099 | 4.500709 | 3.843289 | 3.485061 |
| 有限应变塑性与蠕变 | 1.664820 | 1.704632 | 0.963856 | 0.956906 |
| 小应变塑性与蠕变 | 1.691280 | 1.659342 | 0.929846 | 0.949377 |

接触例题的五次外部时间范围分别为 `4.855187–4.978986` 和 `4.451832–4.578849`，
五组配对测量均更快。程序内部总耗时来自生产输出 `total_seconds`，与外部计时分别报告。
两个无接触对照的时间范围重叠，外部与内部时间没有一致收益，因此不声称这些例题加速。
它们前后均为 10 个接受时间步、50 次非线性迭代、60 次残量计算和 50 次导数矩阵计算。

## 修改内容与耗时依据

修改位于 [quad8_face.cpp](../../elements/src/quad8_face.cpp)，复用已经存在的双精度实现：

1. 八节点面形函数的两个局部坐标都没有自动微分导数时，用双精度计算形函数及其一、二阶导数。
2. 圆形支撑区域与主面的重叠计算，在全部坐标都没有自动微分导数时，使用已有双精度路径。

形函数入口仍返回 `Quad8ShapeValues`，其六组数组的元素类型为 `adlite::Scalar`。
双精度分支逐项写回形函数、一阶导数的两个方向及二阶导数的三个分量；
这些赋值只转换存储类型，不重复计算形函数。这样可以保留现有调用边界。

只检查导数数组是否为空；即使当前导数值恰好为零，只要保留了导数数组，仍使用原自动微分路径。
没有剥离需要传播的导数，也没有增加新的数学公式、模板或公共接口。
投影迭代次数、收敛判断、接触候选选择、几何检查和历史更新规则保持原样。
这段面计算同时服务于 C3D20RT 和 C3D20T，验收覆盖两种单元。

临时分段计时中，主例题的投影函数累计约 1.274 秒，自动微分重叠计算累计约 0.873 秒；
形函数计算约 35.8 万次，累计约 0.365 秒，后者包含在投影等调用的时间中，不能相加。
这些数据只用于定位耗时。诊断代码已移除，表中性能数据来自没有诊断代码的生产程序。

## 复现与证据

先在独立目录构建上述基线提交，保持编译器、依赖、Release 和链接时优化配置一致，
再构建修改后的程序。运行：

```bash
python benchmarks/run_c3d20rt_comparison.py \
  /path/to/baseline/fuelsim build/fuelsim \
  /tmp/c3d20rt-comparison --cpu 0 --repeats 5
```

输出目录必须尚不存在。脚本只复制完整输入卡和网格，不生成或修改问题定义。
可加 `--case finite_contact_first_increment` 只重复主例题。

- [逐次计时和迭代次数](runs.csv)，其中 `repeat=-1` 为预热，不参与统计。
- [输入卡与网格校验值](inputs.sha256)。
- [实测二进制校验值](executables.txt)。其中路径是本次运行的本机路径。
- [逐字段数值比较](field-comparison.csv)。读取前后版本完整 Exodus 时间历程中的
  `vals_*` 和 `time_whole` 数组，逐项比较；同时检查数组形状、有限值位置及 NaN 位置。
  接触例题比较 1608 个数组，两个材料例题各比较 798 个数组，所有有限数值差异均为零。

## 最终数值验收

最终版本构建完成后，在允许 MPI 通信初始化的环境中执行：

```bash
env OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  taskset -c 0-7 ctest --test-dir build -j8 --output-on-failure
```

**326/326 通过**，总时间为 154.38 秒。覆盖八节点曲面形函数与投影导数、
C3D20RT 和 C3D20T 局部单元、Abaqus 对比、曲面接触、摩擦历史、
检查点恢复、失败事务及多进程等价性。所有比较保持原有验收门槛；
原有按专门约定容差验收的例题继续使用其既有门槛。

该回归时间不是性能对照数据；性能结论只使用上文固定单核交替运行的独立测量。
