# C3D20RT 圆形传热支撑计算优化

日期：2026-09-16。比较基线：`a5fcaff`。
C3D20RT 是二十节点、减缩积分的三维温度—位移耦合单元。

## 问题与修改

接触离散用一个小圆形区域分配接触面上的传递权重。修改前，即使这个圆形区域完全位于
主表面内，或者与主表面完全分离，计算导数时仍会执行完整的自动微分圆形区域与多边形交叠积分，
最后才返回面积比例为 1 或 0、导数为零的结果。

临时分段计时发现，在六单元接触首增量例题中：

| 调用 | 次数 | 累计耗时，秒 |
|---|---:|---:|
| 只需要数值的曲面投影 | 87597 | 0.430599 |
| 需要导数的曲面投影 | 7196 | 0.426620 |
| 圆形区域重叠计算入口 | 82809 | 0.716341 |

计时项目可能有调用包含关系，只用于定位开销，不相加作为总时间；诊断代码已删除。

本次在两个调用位置明确区分计算路径：

1. 双精度重叠计算同时返回面积比例，以及是否进入原有的恒定分支。
2. 不需要导数，或者已进入恒定分支时，直接使用双精度结果。
3. 部分重叠时，继续使用原自动微分公式。恒定面积比例相乘的投影权重、间隙、
   表面测度和温度仍保留各自的导数。

恒定分支仍由原来的“边界没有交点，且没有多边形顶点位于圆内”判据确定。
**不根据浮点面积恰好等于 0 或 1 来跳过导数，也没有新增容差。**
投影迭代、积分规则、接触候选选择和历史更新没有修改。
实现位于 [quad8_face.cpp](../../../elements/src/quad8_face.cpp)，同时服务 C3D20RT 和 C3D20T。

## 已有例题与测量条件

主例题为完整的
[`transient_c3d20rt_finite_contact_first_increment.fsi`](../../fuelsim/transient_c3d20rt_finite_contact_first_increment.fsi)，
网格为 6 个单元、88 个几何节点、296 个全局自由度，包含有限应变、间隙传热、
有限滑移接触和摩擦。计算一个 0.025 秒增量；具体几何与载荷见[首轮记录](../README.md)。
另外用已有的小应变和有限应变塑性—蠕变单单元例题检查无接触路径。

比较固定 CPU 0、一个进程，设置
`OMP_NUM_THREADS=OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=1`，使用输入卡原有的 MUMPS 直接求解器。
输入卡和网格逐字复制到隔离目录，保留全部输出。两个二进制使用同一编译器、依赖、
Release 优化和链接时优化配置。计时期间不运行编译或其他测试。

每个版本预热一次，然后交替运行五次；外部时间包围完整生产进程，包含启动和输出。

```bash
python benchmarks/run_c3d20rt_comparison.py \
  /path/to/a5fcaff/fuelsim build/fuelsim /tmp/c3d20rt-constant-disk --cpu 0 --repeats 5
```

## 数值验证

增加的局部测试检查完全覆盖时总传递权重为 1、其导数总和为零，但单个投影权重的导数仍非零；
对应传热残量及导数矩阵与完全覆盖的普通积分一致。完全分离时传递权重及其导数为零。
原有部分重叠的中心差分、跨面导数和热流守恒测试继续保留。

## 正式计时结果

下表单位为秒，均为去掉预热后的五次中位数。

| 例题 | 修改前外部总耗时 | 修改后外部总耗时 | 修改前内部总耗时 | 修改后内部总耗时 |
|---|---:|---:|---:|---:|
| 有限应变接触首增量 | 4.237222 | 3.576671 | 3.246040 | 2.554182 |
| 有限应变塑性与蠕变 | 1.653005 | 1.682208 | 0.960275 | 0.968034 |
| 小应变塑性与蠕变 | 1.653725 | 1.688543 | 0.958320 | 0.951952 |

接触例题外部总耗时减少 **15.59%**，对应 **1.185 倍**加速，五组配对测量均更快。
修改前时间范围为 `4.188829–4.288520`，修改后为 `3.525846–3.613856`。
两版均接受一个时间步，没有失败重试，执行 14 次非线性迭代、22 次残量计算和 14 次导数矩阵计算。

两个无接触对照的外部中位数分别增加约 1.8% 和 2.1%，测量范围重叠，
内部时间没有同向变化，因此不声称这些例题加速。它们均为 10 个接受时间步、
50 次非线性迭代、60 次残量计算和 50 次导数矩阵计算。

该结论限于修改前后的 Fuelsim 接触首增量，不代表完整摩擦历程或所有 C3D20RT 模型的加速，
也不是与 Abaqus 的速度比较。

证据：[逐次计时](runs.csv)、[输入与网格校验值](inputs.sha256)、[二进制校验值](executables.txt)。

读取两版完整 Exodus 输出中的时间、节点场和单元场，比较 3204 个数组：
接触例题 1608 个，两个材料例题各 798 个。全部有限数值逐项一致，
数组形状、有限值位置和 NaN 位置相同，见[逐字段比较](field-comparison.csv)。

完整 Release 构建成功。统一回归 **326/326 通过**，实际总时间为 152.59 秒：
