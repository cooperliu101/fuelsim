# 测试迁移边界

## 本轮替换的测试

以下替换保持原来的九个 CTest 名称和条目数量，覆盖十一条生产求解路径。
B5.9 原来就在一个条目中比较三种网格，现在仍在同一条目中执行。

| 测试 | 显式输入卡，位于 verification/fuelsim | 生产结果验收 |
| --- | --- | --- |
| B5.11 | transient_b511_small_norton.fsi | 小应变完整积分的十阶段 Norton 蠕变；全部节点、积分点历史和能量。 |
| B5.16 | transient_b516_finite_norton.fsi | 有限应变完整积分的同一蠕变路径。 |
| B5.36 | transient_b536_finite_c3d8rt_norton.fsi | 有限应变减缩积分的同一蠕变路径。 |
| B5.42 | transient_b542_small_c3d8rt_norton.fsi | 小应变减缩积分的同一蠕变路径。 |
| B5.44 | transient_b544_distorted_bending.fsi | 十步畸变板件的全部节点、积分点热力字段及能量，保持原有限条件验收门槛。 |
| B5.9 | transient_b59_coarse.fsi、transient_b59_refined.fsi、transient_b59_distorted.fsi | 三种网格的全部四阶段场量、热平衡及弯曲指标。 |
| B6.0 稳态 | steady_b60_fuel_plate_c3d8rt_finite_bending.fsi | 最终温度与自由节点完整位移向量，对照追踪的 Abaqus 参考。 |
| B6.0 瞬态 | transient_b60_fuel_plate_c3d8rt_finite_ramped_bending.fsi | 十步路径的最终温度与完整位移向量，保持该参考解的终态验收范围。 |
| B6.1 | transient_b61_fuel_plate_c3d8rt_finite_inelastic_bending.fsi | 五步路径的全部节点、积分点材料历史、能量及塑性和蠕变激活。 |

原 Norton、B5.44 和 B6.1 专用求解测试源及构建目标已经移除；验收转移到
不链接生产库的结果检查器。B6.0 的工程基准程序保留作手动验证工具，但不再
承担这两个 CTest。B5.9 原程序只执行共享节点归属和分区域稳态界面残量检查。
这些内部断言使用原来的检查方式和门槛，不再重新求解瞬态参考路径。

## 保留原形式的边界

以下是仍含内部求解或外部参考比较的主要组合测试。保留不意味着它们已经完成
生产入口迁移，也不意味着其内部求解能够被一个只读结果检查器替代。

| 测试或文件 | 保留依据 |
| --- | --- |
| B5.14 有限应变弹性 | 逐节点直接施加伸长、剪切和旋转状态。当前生产位移约束映射 Exodus 边集，不支持该路径所需的独立节点组位移；不能用整面常值约束替换。 |
| M2.1 制造解热传导 | 直接设置空间变化的初始节点温度，再检查空间与时间收敛阶。当前输入卡只有区域常数初温，不能保持原制造解的初始条件。 |
| B4.3 有限应变接触 | 除场量外，还用独立的高摩擦局部接触计算累计滑移，并检查局部切向基。生产算例本身无摩擦，该辅助历史不等于输出中的生产摩擦历史。 |
| B4.8 多接触路径 | 完整中间接触历史、连续与分段重启的逐项相等、局部方向导数及 MPI 非重复贡献区间均属于原测试验收；结果文件不能证明全部内部断言。 |
| B5.23 综合路径 | 逐步独立装配热接触残量，检查节点热率、两侧守恒以及摩擦耗散重构；当前输出没有对应的逐节点热接触残量分解。 |
| B5.26、B5.38、B5.39、B5.40 接触开闭或摩擦反向路径，以及 B5.27 工程接触 | 比较辅助程序需要把 Abaqus 全节点历史代入内部问题，重新计算热接触残量并提交参考状态。仅运行原输入卡并读取生产结果不能完成这一共享参考状态检查。 |
| M5.4 瞬态增广接触 | 在提交时刻观察内部乘子及接触历史，并检查失败回滚和两个半时间步的事务。 |
| H20.33、H20.36 内部摩擦事务 | 已有独立生产入口场量比较；内部程序继续核对逐阶段完整接触历史和分段重启，不执行重复的外部场量对标。 |
| solver_tests、hex8_solver_tests、hex20_solver_tests、multi_region_tests | 运行时自由度布局、贡献所有权、工作区复用、失败注入、候选归属、局部残量及历史检查仍由原程序执行。 |
| checkpoint_results_tests、m3_load_boundary_tests、MPI 等价性程序 | 检查不透明快照、完整历史、时间步回滚、求解器分工和注入的输入输出故障，不能由常规生产终态证明。 |

其余局部单元、材料、热容、表面载荷和接触搜索测试直接检查任意指定状态下的
算子、导数或非法状态处理，继续保留原形式。不能因为这些测试读取外部参考，
就把局部算子鉴定宣称为完整生产路径鉴定。

本轮没有为了迁移增加节点组边界语法、扩大生产诊断字段、改变物理模型或
修改参考解。若将上述组合测试进一步拆开，应同时保留其内部断言，并证明不重复
求解相同物理路径；不能直接删除组合测试以降低条目数量。
