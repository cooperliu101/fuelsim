# 测试迁移边界

判断依据是原测试实际验证的量，而不是文件名是否包含 Abaqus、MOOSE 或 solver。
能用现有输入卡表达、并由生产结果保持原验收断言的路径，使用
`fuelsim -i <case.fsi>`。必须访问内部状态的部分保留普通 C++ 自检程序，
不合并成新的内部检查分发器，也不以一次终态比较代替历史事务或局部导数检查。

- B4.3 删除另外设置极高摩擦系数的局部滑移重放。生产输入的摩擦系数为零，

  原精确贡献区间断言由现有 MPI 求解器内部检查承担，不在纯结果检查器中

  曾为 76.032 N，单进程为 184.320 N。按用户确认，在提交前用完整收敛解

  模拟两个进程只更新局部投影再提交，要求完整节点反力与接触历史精确相同。
- B5.24、B5.25 以及 B5.27 的手动参数扫描移至 `benchmarks/`；对应目标
  使用 `EXCLUDE_FROM_ALL`，不在统一 CTest 中重复求解已经迁移的路径。

| M5.4 瞬态增广接触 | 在提交时刻观察内部乘子及接触历史，并检查失败回滚和两个半时间步的事务。 |

| solver_tests、hex8_solver_tests、hex20_solver_tests、multi_region_tests | 运行时自由度布局、贡献所有权、工作区复用、失败注入、候选归属、局部残量及历史检查仍由原程序执行。 |
| checkpoint_results_tests、m3_load_boundary_tests、MPI 等价性程序 | 检查不透明快照、完整历史、时间步回滚、求解器分工和注入的输入输出故障，不能由常规生产终态证明。 |

其余局部单元、材料、热容、表面载荷和接触搜索测试直接检查任意指定状态下的
算子、导数或非法状态处理，继续保留原形式。不能因为这些测试读取外部参考，
就把局部算子鉴定宣称为完整生产路径鉴定。

本轮没有为了迁移增加节点组边界语法、扩大生产诊断字段、改变物理模型或
修改参考解。局部算子外部对比仍未全部迁移；其中任意逐节点位移路径需要
节点集边界输入能力，空间变化的初温也需要额外输入能力，不能用整面常值
或区域常数偷偷替代。是否扩展生产输入接口，需要另行确认。

## 本批验收记录

`cmake --build build --parallel 4` 与两项移至 `benchmarks/` 的手动目标构建均通过。
`ctest --test-dir build -j4 --output-on-failure` 为 220/220 通过，实际耗时 103.01 秒；
该时间不是固定 CPU 的性能对比。外部对比读取仓库内已追踪的 Abaqus/MOOSE 参考，
没有重新运行外部求解器或改写参考结果。

B4.8 单进程与双进程的 3,440 个有效节点场、接触和反力输出值逐项相同，
最大绝对差与原定义的最大缩放差均为零。修复前第二步源节点 3 的反力差为
108.288 N；修复后两个输出均为 184.320 N。完整与分段续算的节点场和摩擦
历史精确相同；分别模拟两个贡献分区的提交检查也通过。

后续按功能覆盖审查移除了 H20.26、H20.27、H20.28 三个只分析已保存 Abaqus
数据的 CTest 注册，并把 H20.29 软罚刚度路径改为手动参数敏感性资料。三个
识别程序使用 `EXCLUDE_FROM_ALL` 保留为按需构建目标，并已分别构建和运行通过。
验证矩阵将这一组存档识别结论从 `verified` 改为 `measured`，不再把离线数据
分析描述为当前 Fuelsim 回归覆盖。

八节点六面体内部材料求解从九条缩为四条代表路径。完整积分保留纯塑性和纯蠕变，
减缩积分保留小应变耦合和有限应变耦合，并在有限应变耦合路径继续检查活跃塑性、
蠕变和单材料点检查点精确恢复。八节点与二十节点六面体的双进程求解器入口只运行
并行贡献、瞬态恢复、集体输出、共享节点装配和接触历史提交所需路径；串行入口继续
执行全部几何搜索、边界构形和局部接触检查。B5.9 自动测试保留粗网格和畸变网格，
规则加密网格及规则加密与畸变响应敏感性比较改为手动资料。

默认构建和三个按需识别目标均通过。六项直接受影响的定向测试通过，统一回归为
`216/216` 通过，实际耗时 `99.01 s`。该耗时没有固定处理器和系统负载，只记录本次
功能验收结果，不作为与历史 `103.01 s` 的性能比较。
