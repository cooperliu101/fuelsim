# Fuelsim 测试入口

测试分成两个边界清楚的类别。

用户可运行的端到端算例只执行生产程序：

```bash
fuelsim -i verification/fuelsim/<case>.fsi
```

每张 `.fsi` 输入卡都是版本库中完整、可直接阅读和手工运行的文件。CTest 只把
输入卡逐字复制到 `build/blackbox/<case>/verification/fuelsim/`，并为每个算例
提供独立输出目录，因此这些测试可以通过 `ctest -j4` 并行运行。生产程序退出后，
`fuelsim_production_result_tests` 只读取 Exodus、CSV 和外部参考结果；它不链接
`fuelsim_core`、`fuelsim_io` 或 `fuelsim_solver`，也不会再次求解。

局部自动微分 Jacobian、材料状态提交与回滚、接触候选所有权、网格映射以及
PETSc 并行贡献所有权等不能仅由最终结果文件证明的契约，继续由普通 C++ 内部
测试覆盖。这些程序不是用户算例入口，也不得代替生产程序的端到端测试。

新增端到端算例时，应当提交显式输入卡，为输出指定算例专用文件名，并通过
`run_fuelsim_case.cmake` 调用生产程序和只读结果检查器。不得在 C++、CMake 或
Shell 中拼装输入卡正文。

目前已有 88 个外部参考或解析解算例以及两个显式无摩擦基准通过生产程序运行，包括二十节点六面体的
塑性、蠕变和耦合三条路径、轴对称有限应变的两组压力载荷，以及增广拉格朗日
接触。材料历史不被残量或 Jacobian 计算修改、回滚后恢复原状态的断言，保留在
`fuelsim_hex20_history_contract_tests` 内部测试中。其余尚未迁移的端到端测试仍
保留原有实现，不能把当前进展视为整个仓库已经迁移完成。

八节点六面体的小应变、有限应变各三个材料分支已经拆成六张生产输入卡。
每个算例的内部历史测试依赖其生产检查点，不再自行求解；它检查初始材料状态
在残量、Jacobian 和回滚操作中不变，并核对活跃材料历史的检查点重新读写。
这些测试还逐项比较 Exodus 输出中的完整材料张量、节点场和提交前反力，防止
仅增加变量名称却遗漏正确的数据映射。五个 H20.29 平面接触算例和两个轴对称
多接触算例的外部比较也已经迁移，误差计算共用不依赖生产库的普通 C++ 实现。

三种 B3.9 八节点六面体接触算例、H20.24 非匹配接触的 Abaqus/MOOSE 三方
比较，以及 B3.7 双接触对摩擦算例均读取生产输出。B3.9 的局部接触切线与
作用力守恒检查单独保留，不再自行求解。M5.1 使用完整、显式的无摩擦输入卡
比较摩擦对轴向位移的影响；M5.2 的初始候选所有权由内部测试检查，并与生产
输出的最终所有权比较，保持跨越至少两条主侧线段的断言。

轴对称综合瞬态、两种燃料包壳接触、五种非弹性材料加载、七种非共轴有限应变
路径、两芯块接触、时间表对流与圆柱压力解析解也已迁移。非共轴历史仍按每个
单元的参考积分测度平均，比较全部一百个时间步；纯蠕变共享状态材料重放独立
保留在 `fuelsim_rz_creep_replay_contract_tests`，不调用求解器。两芯块的失去
投影守卫、跨线段唯一归属与接触力守恒检查也单独保留。时间控制内部测试继续
检查不透明状态快照、完整回滚、时间误差估计与失败重试。

共享节点板件的四十步非弹性路径和三维粘着摩擦也读取生产输出；后者用另一张
完整无摩擦输入卡比较切向位移。共享节点映射、共享界面四个场的残量守恒，
以及非匹配二十节点接触的跨面约束、局部切线和作用力守恒，分别保留为读取
生产终态的内部检查，不再另行求解。非匹配接触的内部检查复用三方对比输入卡
和网格，不再在测试程序中生成另一套网格及边界条件。

二十节点热接触、分片圆柱和二次曲面圆柱接触、曲面双方向粘着摩擦，以及
八节点稳态和瞬态滑移也通过显式输入卡运行。曲面几何、局部接触切线和
作用力守恒仍由独立内部测试验证；滑移检查点直接读取生产程序保存的活跃
摩擦历史，再以指定的下一步步长写出并恢复，逐项比较全部摩擦事务字段。
滑移检查点与输出的总滑移必须完全相等；输出重新计算库仑返回映射后的弹性
滑移只允许四倍机器精度乘该分量绝对值的舍入误差，不加绝对值下限。首次检查
的最大差约为 `1.3e-26 m`。检查点重新读写的全部历史仍要求完全相等。
已被生产程序禁止的二十节点机械节点到面旧路径不再构建额外算例可执行程序；
其源代码和外部参考仍作为历史资料保留，不算作已迁移的有效生产算例。

双切向摩擦的四步路径也由生产程序运行，另有两张完整输入卡分别在第二步保存
检查点、续算后两步；最终输出和全部内部接触历史与连续计算完全相等。粘着与
滑移的局部导数检查直接读取生产检查点，不再自行求解。

二十节点部分接触比较直接读取输出文件中的面节点列表，仍要求四个部分接触面、
十一个活跃约束和十六个正恢复压力节点。非匹配与曲面摩擦路径在完整输入卡中
显式使用原测试实际采用的 0.1 秒步长，每十步输出一次，比较七个加载阶段的完整位移、接触力、
滑移及粘滑转换。逐阶段的检查点历史精确比较仍保留为内部事务测试；这两个内部
测试需要运行连续与分段事务来读取未输出的完整状态，不执行外部求解器对标，
也不代替生产入口测试。曲面几何、粘滑导数和作用力守恒检查仍保留。

二十节点热力耦合、无摩擦接触和有摩擦接触三个综合路径也已迁移。每个路径
执行二十个固定时间步；结果检查器按输出中的 27 个积分点当前坐标逐单元唯一
匹配 Abaqus 历史，保留温度、完整位移、等效应力、塑性与蠕变的全部误差门槛。
两个接触路径继续检查约束压力与恢复压力，以及各自规定的接触力和滑移。
内部检查读取生产检查点，独立验证混合阶节点映射、当前积分点坐标输出及接触
导数，不再重新求解。

B5.5 单时间步热力耦合与 B5.8 四时间步温度相关材料算例使用显式输入卡及同一份
受版本管理的双单元网格。结果检查器读取全部节点反力、积分点热流、应力和应变，
保留三项相对误差及零参考点绝对差门槛；B5.8 还逐步检查热量守恒。
八节点派生输出另有独立解析测试，覆盖完整积分、减缩积分、小应变、有限应变
及整体转动。材料历史内部测试逐项核对输出中的守恒诊断和位移、温度约束标记。
网格导出工具只写网格，不生成输入卡；自动测试直接读取提交的网格文件。

B5.31 与 B5.34 的减缩积分瞬态路径也直接运行生产程序，约束反力按输出的边界
标记选择比较节点。每个单元初始化和最终提交后只有一个材料点的要求，单独由
读取生产检查点的内部测试证明，并检查八个输出编号确实重复同一材料点应力。
B5.34 保留原来的鉴定范围，不把应变诊断扩大为应变已鉴定的结论。

M5.2 大滑移瞬态的连续计算、半程检查点和续算采用三张完整输入卡。结果检查器
保持原来的节点场缩放差小于 `1e-13` 门槛，接触投影状态、所属线段及压力要求
完全相等。独立内部检查确认检查点恢复的控制步长完全等于 `0.05 s`；半程时间
允许一个浮点间隔的累加舍入误差，首次检查为 `0.49999999999999994 s`。

八节点塑性加载、卸载和反向加载、单调塑性—蠕变耦合，以及三条非共轴加载
共十一条路径分别使用完整输入卡。每个时间步均比较节点反力、全部材料张量、
等效塑性与蠕变历史、积分体积和累计能量，保留原有三个相对误差指标及零参考
绝对差门槛。百时间步路径仍仅对弹性应变的规定分量采用原记录的逐点绝对差
例外，不扩大到其他字段；超过 25 度的转动由实际输出位移计算。原来的复合
求解测试程序已删除，其验收行为由生产输入卡和只读结果检查器承担。

另有以下生产程序测试验证运行方式：

- `fuelsim_production_hex20_mpi_equivalence` 使用消息传递接口（MPI）启动两个
  进程，读取同一张耦合材料输入卡，与单进程运行的最终节点场及全部材料积分点
  输出比较。非零字段的最大绝对差不得超过对应参考字段绝对峰值的 `1e-10`。
  这个单轴加载算例理论为零的横向、剪切应力单独使用 `1e-5 Pa` 绝对门槛；首次
  验证的最大应力差为 `4.47e-7 Pa`。不修改相对误差分母，也不改变外部对标门槛。
  新输出的理论零横向反力使用 `1e-5 N` 绝对差门槛，材料剪切应变分量使用
  `1e-14` 绝对差门槛；迁移时观察到的最大差分别为 `9.52e-8 N` 和 `8.24e-19`。
- `fuelsim_production_hex20_restart` 先执行完整、显式的
  `transient_hex20_coupled_checkpoint.fsi`，在 `0.5 s` 保存检查点，再执行
  `transient_hex20_coupled_restart.fsi` 续算至 `1 s`。最终节点场、27 个材料
  积分点输出与连续计算逐项完全一致，且摘要必须确认只接受了剩余的五个时间步。
  这里比较的是输出字段；未输出的内部历史仍由内部检查点测试验证。

上述运行方式测试通过 CTest 的前置测试依赖自动获得单进程参考结果。两进程测试占用
两个调度槽，并与其他两进程测试互斥；各算例的输出目录仍然独立。检查点测试只
按明确文件名清除本测试旧输出，不清除输入卡，也不生成输入卡正文。
